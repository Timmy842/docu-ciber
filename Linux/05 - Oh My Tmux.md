Atajos de Tmux:

- Inciar Tmux -> tmux new -s [Nombre de sesion]
- Cambiar nombre de ventana -> Crtl + b   , (Coma)
- Crear una ventana nueva -> Crtl + b   c
- Moverse entre ventanas -> Crtl + b  [Numero de la ventana]
- Dividir Horizontalmente -> Crtl + b  Shift + "" (Doble comilla)
- Dividir Verticalmente -> Crtl + b Shift + 5
- Alternar entre terminales de una ventana -> Crtl + b  O
- Cerrar panel -> Crtl + b  x
- Renombrar Sesion -> Crtl + b Shift + $
- Ajustar el size de los paneles Crtl + b  (Manteniendo Crtl usar las flechas)
- Entrar modo Copia -> Crtl +b  AltGr + [ (Corchete Izquierdo)
- Seleccionar que copiar -> Crtl + (Espacio) y usar las flechas
- Copiar -> Alt + W
- Pegar -> Crtl +b  AltGr + ] (Corchete Derecho)
- Detachear Sesiones -> Crtl + b  D
- Ver lsitado de sesiones -> tmux list-sessions
- Meterse a una sesion -> tmux attach -t [Nombre de la sesion]
