Lista de comandos basicos para Linux:

- whoami -> sirve para saber que usuario eres
- id -> para ver primero que identificador de usuario tenemos, el identificador de grupo, y a que grupos pertenece el usuario
- exit -> para salir de la sesion actual de root
- which -> para ver la ruta absoluta
- command -v -> lo mismo que which, ya que a veces no esta disponible which
- cat -> sirve para listar el contenido de un archivo
- echo -> para ver en pantalla contenido de variables
-  | (pipear) -> sirve para operar un output de un comando que este antes. Ejemplo: cat /etc/group | grep "floppy"
- grep -> Sirve para buscar en el contenido de un fichero. -n: para mostrar delante la linea en la que se encuentra.
- pwd -> para localizar en que directorio nos encontramos
- ls -> para listar los directorios y archivos del directorio en el que te encuentras. -l: permite listar permisos usuario etc
- cd -> para cambiar de directorio indicando la ruta
