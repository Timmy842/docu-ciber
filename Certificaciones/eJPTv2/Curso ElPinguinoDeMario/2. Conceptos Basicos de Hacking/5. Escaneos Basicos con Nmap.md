# Escaneos Basicos con Nmap

> [!info] Idea principal
> Nmap sirve para descubrir puertos abiertos, servicios, versiones y otra informacion importante de una maquina objetivo.

## Para que Sirve Nmap

Nmap es una de las herramientas mas importantes en la fase de reconocimiento y enumeracion.

Con Nmap puedo descubrir:

- Si una maquina esta activa.
- Que puertos tiene abiertos.
- Que servicios corren en esos puertos.
- Versiones de servicios.
- Informacion basica del sistema.
- Posibles vectores de ataque para investigar despues.

> [!warning] Importante
> Usar Nmap solo en maquinas propias, laboratorios o entornos donde tengas permiso.

## Escaneo Basico

Para empezar, puedo escanear un host especifico con:

```bash
nmap 192.168.0.236
```

Este comando hace un escaneo basico de los puertos mas comunes.

### Que hace este escaneo

Por defecto, Nmap suele escanear los **1000 puertos TCP mas comunes**.

Ejemplo de resultado:

```text
PORT   STATE SERVICE
22/tcp open  ssh
80/tcp open  http
```

Esto significa:

- `PORT`: puerto encontrado.
- `STATE`: estado del puerto.
- `SERVICE`: servicio que probablemente esta corriendo.

## Estados de Puertos

Nmap puede mostrar varios estados:

- `open`: el puerto esta abierto y acepta conexiones.
- `closed`: el puerto responde, pero no hay ningun servicio escuchando.
- `filtered`: un firewall o filtro esta bloqueando la respuesta.
- `open|filtered`: Nmap no puede confirmar si esta abierto o filtrado.
- `closed|filtered`: Nmap no puede confirmar si esta cerrado o filtrado.

> [!tip] Lo mas importante
> En laboratorios, normalmente me centro primero en los puertos marcados como `open`.

## Escaneo Recomendado para Enumeracion

Un comando mas completo seria:

```bash
nmap -p- --open -sS -sC -sV --min-rate 2000 -n -vvv -Pn 192.168.0.236 -oN escaneo
```

Este comando busca todos los puertos TCP abiertos y obtiene informacion util de los servicios encontrados.

## Explicacion del Comando Completo

### `-p-`

Escanea todos los puertos TCP, desde el `1` hasta el `65535`.

```bash
nmap -p- 192.168.0.236
```

Sin esta opcion, Nmap solo revisa los puertos mas comunes.

> [!info] Por que es importante
> A veces un servicio interesante no esta en un puerto comun. Por ejemplo, una web podria estar en `8080`, `5000` o `8443`.

### `--open`

Muestra solo los puertos abiertos.

```bash
nmap --open 192.168.0.236
```

Esto ayuda a limpiar la salida y centrarse en lo importante.

### `-sS`

Realiza un escaneo TCP SYN, tambien conocido como **half-open scan**.

```bash
nmap -sS 192.168.0.236
```

Es rapido y muy usado en Linux, pero normalmente requiere privilegios de administrador.

> [!note] Si no uso sudo
> Si ejecuto Nmap sin permisos suficientes, puede que Nmap use otro tipo de escaneo como `-sT`.

### `-sC`

Ejecuta los scripts por defecto de Nmap contra los servicios encontrados.

```bash
nmap -sC 192.168.0.236
```

Estos scripts pueden mostrar informacion extra, como:

- Titulos de paginas web.
- Informacion de SMB.
- Banners de servicios.
- Configuraciones basicas.

### `-sV`

Intenta detectar la version de los servicios.

```bash
nmap -sV 192.168.0.236
```

Ejemplo:

```text
22/tcp open  ssh     OpenSSH 8.2p1 Ubuntu
80/tcp open  http    Apache httpd 2.4.41
```

> [!tip] Por que es util
> Saber la version exacta ayuda a buscar vulnerabilidades conocidas o documentacion especifica del servicio.

### `--min-rate 2000`

Indica a Nmap que intente enviar al menos `2000` paquetes por segundo.

```bash
nmap --min-rate 2000 192.168.0.236
```

Esto acelera el escaneo.

> [!tip] eJPT
> Un `--min-rate 2000` suele ser recomendable para laboratorios tipo eJPT porque acelera bastante sin ser demasiado agresivo.

> [!warning] Cuidado
> En redes inestables o maquinas lentas, un valor muy alto puede provocar resultados menos fiables.

### `-n`

Evita la resolucion DNS.

```bash
nmap -n 192.168.0.236
```

Esto hace que el escaneo sea mas rapido porque Nmap no intenta resolver nombres de dominio.

### `-vvv`

Activa salida muy detallada.

```bash
nmap -vvv 192.168.0.236
```

Sirve para ver mas informacion mientras el escaneo esta en marcha.

### `-Pn`

Le dice a Nmap que trate el host como activo, aunque no responda a ping.

```bash
nmap -Pn 192.168.0.236
```

Esto es util cuando una maquina bloquea ICMP/ping.

> [!warning] Importante
> `-Pn` puede hacer que el escaneo tarde mas, porque Nmap no descarta el host aunque no responda al descubrimiento inicial.

### `-oN escaneo`

Guarda el resultado en un archivo normal llamado `escaneo`.

```bash
nmap 192.168.0.236 -oN escaneo
```

Esto es muy util para tomar apuntes y revisar la informacion despues.

## Flujo Recomendado de Escaneo

> [!example] Metodo practico
> Primero descubro puertos abiertos, despues enumero versiones y scripts sobre esos puertos.

## Fase 1: Descubrir Todos los Puertos Abiertos

```bash
sudo nmap -p- --open -sS --min-rate 2000 -n -vvv -Pn 192.168.0.236 -oN puertos
```

Este escaneo busca rapidamente todos los puertos TCP abiertos.

## Fase 2: Enumerar Servicios Detectados

Cuando ya se que puertos estan abiertos, hago un escaneo mas detallado solo contra esos puertos.

Ejemplo si estan abiertos `22`, `80` y `445`:

```bash
nmap -p 22,80,445 -sC -sV -n -vvv 192.168.0.236 -oN servicios
```

Esto suele ser mas limpio y fiable que lanzar scripts contra los 65535 puertos desde el principio.

## Escaneo UDP Basico

Nmap tambien puede escanear puertos UDP:

```bash
sudo nmap -sU --top-ports 100 192.168.0.236 -oN udp
```

### Que significa

- `-sU`: escaneo UDP.
- `--top-ports 100`: escanea los 100 puertos UDP mas comunes.

> [!warning] Nota sobre UDP
> Los escaneos UDP suelen ser mucho mas lentos que los TCP.

## Deteccion de Sistema Operativo

Para intentar detectar el sistema operativo:

```bash
sudo nmap -O 192.168.0.236
```

Tambien puedo combinarlo con otros parametros:

```bash
sudo nmap -O -sV 192.168.0.236
```

> [!note] Fiabilidad
> La deteccion de sistema operativo no siempre es exacta, pero puede dar pistas utiles.

## Guardar Resultados

### Formato normal

```bash
nmap 192.168.0.236 -oN escaneo.txt
```

### Formato grepable

```bash
nmap 192.168.0.236 -oG escaneo.gnmap
```

### Formato XML

```bash
nmap 192.168.0.236 -oX escaneo.xml
```

### Todos los formatos

```bash
nmap 192.168.0.236 -oA escaneo
```

Esto genera:

- `escaneo.nmap`
- `escaneo.gnmap`
- `escaneo.xml`

## Comandos Utiles

### Escaneo basico

```bash
nmap 192.168.0.236
```

### Escaneo de todos los puertos TCP abiertos

```bash
sudo nmap -p- --open -sS --min-rate 2000 -n -vvv -Pn 192.168.0.236 -oN puertos
```

### Escaneo de versiones y scripts

```bash
nmap -p 22,80,445 -sC -sV -n -vvv 192.168.0.236 -oN servicios
```

### Escaneo completo en un solo comando

```bash
nmap -p- --open -sS -sC -sV --min-rate 2000 -n -vvv -Pn 192.168.0.236 -oN escaneo
```
