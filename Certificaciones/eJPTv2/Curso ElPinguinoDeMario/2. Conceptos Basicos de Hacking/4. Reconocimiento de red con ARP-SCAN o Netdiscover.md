
> [!info] Idea principal
> El reconocimiento de red sirve para descubrir que dispositivos estan activos dentro de una red local antes de empezar una enumeracion mas profunda.

## Objetivo

Con estas herramientas puedo identificar:

- IPs activas en la red.
- Direcciones MAC.
- Fabricantes de tarjetas de red.
- Posibles maquinas virtuales.
- Sistemas aproximados usando el valor TTL.

> [!warning] Importante
> Realizar este tipo de reconocimiento solo en redes propias, laboratorios o entornos donde tengas permiso.

## Paso 1: Identificar la Interfaz de Red

Antes de escanear necesito saber que interfaz de red estoy usando.

```bash
ifconfig
```

Tambien puedo usar:

```bash
ip a
```

Ejemplo de interfaz comun:

```text
eth0
```

## arp-scan

`arp-scan` permite descubrir hosts activos en la red local usando peticiones ARP.

### Comando Basico

```bash
sudo arp-scan -I eth0 --localnet
```

### Explicacion del Comando

- `sudo`: ejecuta el comando con privilegios elevados.
- `arp-scan`: herramienta para escanear por ARP.
- `-I eth0`: indica la interfaz de red que se va a usar.
- `--localnet`: escanea la red local completa asociada a esa interfaz.

### Ejemplo de Salida

```text
Interface: eth0, type: EN10MB, MAC: 00:0c:29:48:bf:ba, IPv4: 192.168.0.8
Starting arp-scan 1.10.0 with 256 hosts

192.168.0.1     02:10:18:3a:ab:04       (Unknown: locally administered)
192.168.0.15    b8:be:f4:bd:4b:52       (Unknown)
192.168.0.157   00:d8:61:e6:13:1a       (Unknown)
192.168.0.203   00:0c:29:67:65:d7       (Unknown)
192.168.0.230   b8:27:eb:c2:45:b6       (Unknown)
192.168.0.236   00:0c:29:fa:dd:2a       (Unknown)

Ending arp-scan 1.10.0: 256 hosts scanned. 12 responded
```

> [!tip] Pista sobre maquinas virtuales
> Algunas direcciones MAC pueden dar pistas sobre el tipo de dispositivo. Por ejemplo, las MAC asociadas a `VMware, Inc.` suelen indicar maquinas virtuales.

## Netdiscover

`netdiscover` tambien sirve para descubrir equipos activos en una red local usando ARP.

### Comando Basico

```bash
sudo netdiscover -i eth0 -r 192.168.0.0/24
```

### Explicacion del Comando

- `sudo`: ejecuta el comando con privilegios elevados.
- `netdiscover`: herramienta de descubrimiento de red.
- `-i eth0`: indica la interfaz de red.
- `-r 192.168.0.0/24`: define el rango de red a escanear.

### Ejemplo de Salida

```text
Currently scanning: Finished!   |   Screen View: Unique Hosts

IP            At MAC Address     Count     Len  MAC Vendor / Hostname
-----------------------------------------------------------------------------
192.168.0.1     02:10:18:3a:ab:04      1      60  Unknown vendor
192.168.0.157   00:d8:61:e6:13:1a     16     960  Micro-Star INTL CO., LTD.
192.168.0.203   00:0c:29:67:65:d7      4     240  VMware, Inc.
192.168.0.230   b8:27:eb:c2:45:b6      5     300  Raspberry Pi Foundation
192.168.0.236   00:0c:29:fa:dd:2a      1      60  VMware, Inc.
```

> [!note] Diferencia rapida
> `arp-scan` suele ser muy directo y rapido para listar hosts. `netdiscover` es comodo porque muestra una vista ordenada con fabricantes y hosts unicos.

## Distinguir Linux y Windows con TTL

Despues de encontrar una IP activa, puedo hacer un `ping` para ver el valor TTL:

```bash
ping 192.168.0.203
```

Valores comunes:

- `TTL 64`: normalmente Linux.
- `TTL 128`: normalmente Windows.

> [!warning] Nota
> El TTL no confirma al 100% el sistema operativo, pero sirve como pista inicial.

## Descubrimiento con Nmap

Otra forma de encontrar maquinas activas es usar Nmap con `-sn`.

```bash
nmap -sn 192.168.0.0/24
```

### Que hace `-sn`

El parametro `-sn` realiza un descubrimiento de hosts sin escanear puertos.

Sirve para saber que maquinas estan activas antes de hacer un escaneo mas profundo.

## Exportar Resultados con Nmap

Nmap permite guardar los resultados en archivos para revisarlos despues o incluirlos en los apuntes.

### Exportar en formato normal

```bash
nmap -sn 192.168.0.0/24 -oN resultado.txt
```

### Exportar en varios formatos

```bash
nmap -sn 192.168.0.0/24 -oA descubrimiento_red
```

Esto genera varios archivos con el mismo nombre base:

- `descubrimiento_red.nmap`
- `descubrimiento_red.gnmap`
- `descubrimiento_red.xml`

## Checklist Rapido

- [ ] Identificar la interfaz de red con `ifconfig` o `ip a`.
- [ ] Escanear la red con `arp-scan`.
- [ ] Confirmar hosts con `netdiscover`.
- [ ] Usar `ping` para revisar el TTL.
- [ ] Usar `nmap -sn` para descubrimiento adicional.
- [ ] Guardar resultados importantes para los apuntes.
