> [!info] Idea principal
> Despues de descubrir los puertos abiertos de una maquina, puedo usar scripts de Nmap para buscar vulnerabilidades conocidas en esos servicios.

## Que es NSE

Nmap tiene un motor de scripts llamado **NSE**:

```text
Nmap Scripting Engine
```

NSE permite ejecutar scripts para obtener informacion adicional sobre los servicios detectados.

Con estos scripts puedo:

- Enumerar servicios con mas detalle.
- Detectar configuraciones inseguras.
- Buscar vulnerabilidades conocidas.
- Identificar posibles CVE.
- Obtener informacion util para una explotacion posterior.

> [!warning] Importante
> Usar estos escaneos solo en maquinas propias, laboratorios o entornos donde tengas permiso.

## Flujo Recomendado

> [!example] Metodo practico
> Primero descubro puertos abiertos, despues enumero versiones y finalmente lanzo scripts de vulnerabilidades contra puertos concretos.

## Paso 1: Descubrir Puertos Abiertos

Antes de buscar vulnerabilidades, necesito saber que puertos estan abiertos.

```bash
sudo nmap -p- --open -sS --min-rate 2000 -n -vvv -Pn 192.168.0.236 -oN puertos
```

## Paso 2: Enumerar Versiones

Despues, enumero los servicios y versiones:

```bash
nmap -p 23 -sC -sV -n -vvv 192.168.0.236 -oN servicios
```

Esto ayuda a saber que servicio exacto esta corriendo en el puerto.

## Paso 3: Buscar Vulnerabilidades con Scripts

Una vez identificado el puerto, puedo usar la categoria `vuln` de Nmap:

```bash
nmap --script "vuln" -p23 192.168.0.236
```

Este comando ejecuta scripts relacionados con vulnerabilidades contra el puerto `23`.

## Explicacion del Comando

- `nmap`: ejecuta Nmap.
- `--script "vuln"`: ejecuta scripts de la categoria de vulnerabilidades.
- `-p23`: escanea solamente el puerto `23`.
- `192.168.0.236`: IP de la maquina victima.

> [!tip] Consejo
> Es mejor lanzar scripts de vulnerabilidades contra puertos concretos que contra todos los puertos, porque el resultado suele ser mas limpio y rapido.

## Escanear Varios Puertos

Si encuentro varios puertos abiertos, puedo indicarlos separados por comas:

```bash
nmap --script "vuln" -p21,22,23,80,445 192.168.0.236
```

## Combinar con Versiones

Tambien puedo combinar deteccion de versiones con scripts de vulnerabilidades:

```bash
nmap -sV --script "vuln" -p23 192.168.0.236
```

Esto puede ayudar a que Nmap detecte mejor el servicio y aplique scripts mas adecuados.

## Buscar Scripts Disponibles

Los scripts de Nmap suelen estar en:

```bash
/usr/share/nmap/scripts/
```

Puedo buscar scripts relacionados con un servicio usando `ls`:

```bash
ls /usr/share/nmap/scripts/ | grep ftp
```

Ejemplos:

```bash
ls /usr/share/nmap/scripts/ | grep smb
ls /usr/share/nmap/scripts/ | grep http
ls /usr/share/nmap/scripts/ | grep telnet
```

## Ejecutar un Script Especifico

Si quiero ejecutar un script concreto:

```bash
nmap --script nombre-del-script -pPUERTO IP
```

Ejemplo:

```bash
nmap --script telnet-encryption -p23 192.168.0.236
```

## Interpretar Resultados

Cuando Nmap encuentra algo interesante, puede mostrar:

- Nombre de la vulnerabilidad.
- Descripcion del problema.
- CVE asociado.
- Referencias externas.
- Nivel de riesgo aproximado.

Ejemplo de CVE:

```text
CVE-2011-2523
```

> [!note] Que es un CVE
> Un CVE es un identificador publico para una vulnerabilidad conocida. Sirve para buscar informacion, exploits y parches relacionados.

## Buscar Exploits con Metasploit

Si Nmap muestra un CVE o una vulnerabilidad interesante, puedo abrir Metasploit:

```bash
msfconsole
```

Dentro de Metasploit puedo buscar por CVE:

```text
search CVE-2011-2523
```

O buscar por nombre del servicio:

```text
search telnet
```

Si encuentro un modulo, puedo seleccionarlo con:

```text
use exploit/ruta/del/modulo
```

> [!warning] Importante
> Que Nmap muestre una posible vulnerabilidad no significa que siempre sea explotable. Hay que confirmar version, configuracion y contexto.

## Comandos Utiles

### Escaneo de vulnerabilidades en un puerto

```bash
nmap --script "vuln" -p23 192.168.0.236
```

### Escaneo de vulnerabilidades con deteccion de version

```bash
nmap -sV --script "vuln" -p23 192.168.0.236
```

### Escaneo de vulnerabilidades en varios puertos

```bash
nmap --script "vuln" -p21,22,23,80,445 192.168.0.236
```

### Guardar resultados

```bash
nmap -sV --script "vuln" -p23 192.168.0.236 -oN vulnerabilidades
```

## Checklist Rapido

- [ ] Descubrir puertos abiertos.
- [ ] Enumerar versiones con `-sV`.
- [ ] Lanzar scripts `vuln` contra puertos concretos.
- [ ] Revisar si aparece algun CVE.
- [ ] Buscar informacion del CVE.
- [ ] Comprobar si existe modulo en Metasploit.
- [ ] Validar manualmente antes de asumir que es explotable.
