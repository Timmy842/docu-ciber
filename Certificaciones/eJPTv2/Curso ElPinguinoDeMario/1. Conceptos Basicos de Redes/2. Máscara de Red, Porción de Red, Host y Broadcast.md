# 🧮 Máscara de Red, Porción de Red, Host y Broadcast
 
> [!abstract] Resumen
> Una IP por sí sola no dice nada. Es la **máscara** la que parte esa IP en dos:
> - **Porción de red** → identifica *a qué red* perteneces.
> - **Porción de host** → identifica *qué dispositivo* eres dentro de esa red.
> Y de ahí salen dos direcciones especiales: la de **red** y la de **broadcast**.
 
---
 
## 🎭 ¿Qué es la Máscara de Red?
 
La **máscara de subred** (*subnet mask*) es un número de 32 bits que indica **cuántos bits de la IP pertenecen a la red y cuántos al host**.
 
La regla es simple:
- Bit a **`1`** → pertenece a la **red**.
- Bit a **`0`** → pertenece al **host**.
Y los `1` van siempre **seguidos y desde la izquierda**. No puede haber huecos.
 
```
Máscara:  255.255.255.0
Binario:  11111111.11111111.11111111.00000000
          └──────── red (24 bits) ───────┘└host─┘
```
 
> [!tip] Notación CIDR
> El `/24` no es más que **el número de unos** de la máscara.
> `255.255.255.0` → 24 unos → **`/24`**
 
| Máscara decimal | CIDR | Bits de host | Hosts útiles |
|---|---|---|---|
| `255.0.0.0` | /8 | 24 | 16.777.214 |
| `255.255.0.0` | /16 | 16 | 65.534 |
| `255.255.255.0` | /24 | 8 | 254 |
| `255.255.255.128` | /25 | 7 | 126 |
| `255.255.255.192` | /26 | 6 | 62 |
| `255.255.255.224` | /27 | 5 | 30 |
 
---
 
## 🌐 Porción de Red vs. Porción de Host
 
Tomemos el ejemplo `192.168.1.50 /24`:
 
```
IP:       192.168.1.50    →  11000000.10101000.00000001.00110010
Máscara:  255.255.255.0   →  11111111.11111111.11111111.00000000
                              └──── PORCIÓN DE RED ────┘└─ HOST ─┘
```
 
- **Porción de red** = `192.168.1` → es **igual para todos** los dispositivos de esa red.
- **Porción de host** = `.50` → es **único** para cada dispositivo.
> [!info] Analogía postal
> - **Red** = el código postal + calle (el barrio donde vives).
> - **Host** = el número de tu portal (te distingue de los vecinos).
> Dos dispositivos en la misma red comparten la porción de red; si no coinciden, no se ven directamente y necesitan un router.
 
---
 
## 🔢 Cómo se calcula: el AND lógico
 
La dirección de red se obtiene haciendo un **AND bit a bit** entre la IP y la máscara (`1 AND 1 = 1`, todo lo demás `= 0`):
 
```
IP:       11000000.10101000.00000001.00110010   (192.168.1.50)
Máscara:  11111111.11111111.11111111.00000000   (255.255.255.0)
─────────────────── AND ────────────────────
Red:      11000000.10101000.00000001.00000000   (192.168.1.0)
```
 
Resultado: la **dirección de red es `192.168.1.0`**.
 
---
 
## 📌 Dirección de Red y de Broadcast
 
Dentro de cada red hay dos direcciones que **no se pueden asignar a un host**:
 
> [!warning] Direcciones reservadas
> - **Dirección de Red** → todos los bits de host a **`0`**. Identifica a la red en sí.
> - **Dirección de Broadcast** → todos los bits de host a **`1`**. Sirve para enviar un mensaje *a todos los hosts a la vez*.
 
Para `192.168.1.0/24`:
 
```
Red:        192.168.1.0      → ...00000000  (host = todo 0)
Primer host:192.168.1.1
...
Último host:192.168.1.254
Broadcast:  192.168.1.255    → ...11111111  (host = todo 1)
```
 
| Elemento | Valor | ¿Asignable? |
|---|---|---|
| Dirección de red | `192.168.1.0` | ❌ No |
| Primer host útil | `192.168.1.1` | ✅ Sí |
| Último host útil | `192.168.1.254` | ✅ Sí |
| Broadcast | `192.168.1.255` | ❌ No |

## 🧠 Fórmulas clave
 
> [!example] Cálculos rápidos
> Siendo **`n`** = número de bits de host:
> - **Hosts totales** = `2^n`
> - **Hosts útiles** = `2^n − 2` (restas red y broadcast)
> - **Dirección de red** = IP `AND` máscara
> - **Broadcast** = dirección de red + (bits de host todos a 1)
 
**Ejemplo con /26** (`255.255.255.192`, 6 bits de host):
```
2^6 = 64 direcciones por bloque
64 − 2 = 62 hosts útiles
Bloques: .0  .64  .128  .192
 
Red 192.168.1.64/26
  Red:        192.168.1.64
  Hosts:      192.168.1.65 – 192.168.1.126
  Broadcast:  192.168.1.127
```
 
---
 
## ⚡ Truco: el "número mágico"
 
Para subnetear rápido sin binario, resta el octeto de la máscara a 256:
 
```
Máscara /26 → 255.255.255.192
256 − 192 = 64  →  los bloques saltan de 64 en 64
Subredes: .0 / .64 / .128 / .192
```
 
> [!tip] Identificar la red de una IP al vuelo
> ¿En qué red está `192.168.1.100/26`?
> Bloques de 64: 0, 64, **128**... → 100 cae entre 64 y 127
> → Red `.64`, broadcast `.127`, hosts `.65–.126`.
