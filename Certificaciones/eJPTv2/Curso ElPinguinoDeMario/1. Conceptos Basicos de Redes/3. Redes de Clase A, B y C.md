# Redes de Clase A, B y C
 
> [!abstract] Resumen
> Antes de CIDR, las IPv4 se repartían en **clases** según su primer octeto. Cada clase tenía una **máscara fija** y un tamaño de red predefinido:
> - **Clase A** → redes enormes, pocas redes.
> - **Clase B** → redes medianas.
> - **Clase C** → redes pequeñas, muchísimas redes.
 
> [!warning] Contexto importante
> El direccionamiento **classful** está **obsoleto** desde 1993 (lo sustituyó **CIDR**, *classless*). Pero se sigue estudiando porque aparece en exámenes, certificaciones y explica el porqué de muchas máscaras "por defecto" que aún ves hoy.
 
---
 
## 🧩 ¿De dónde sale la clase?
 
La clase se determina mirando **los primeros bits del primer octeto** de la IP. Esos bits fijos marcan el rango y la máscara por defecto.
 
| Clase | Bits iniciales | 1er octeto (rango) | Máscara por defecto | CIDR |
|---|---|---|---|---|
| **A** | `0` | 1 – 126 | `255.0.0.0` | /8 |
| **B** | `10` | 128 – 191 | `255.255.0.0` | /16 |
| **C** | `110` | 192 – 223 | `255.255.255.0` | /24 |
| **D** | `1110` | 224 – 239 | — (multicast) | — |
| **E** | `1111` | 240 – 255 | — (reservada) | — |
 
> [!tip] Truco para identificar la clase al vuelo
> Solo mira el **primer octeto**:
> - `1–126` → **A**
> - `128–191` → **B**
> - `192–223` → **C**
> - `224+` → multicast/experimental
> *(El 127 se salta: está reservado para loopback, `127.0.0.1`.)*

## 🅰️ Clase A
 
```
0NNNNNNN.HHHHHHHH.HHHHHHHH.HHHHHHHH
└─ red ─┘└────────── host ──────────┘
```
 
- **Red**: 8 bits (el primero fijo a `0`) → 7 bits útiles.
- **Host**: 24 bits.
- **Máscara**: `255.0.0.0` (`/8`).
| Característica | Valor |
|---|---|
| Nº de redes | 126 |
| Hosts por red | 16.777.214 (`2²⁴ − 2`) |
| Rango | `1.0.0.0` – `126.255.255.255` |
| Ejemplo | `10.20.30.40` |
 
> [!example] Para qué se usaba
> Para organizaciones gigantescas (grandes ISPs, instituciones históricas). El rango privado `10.0.0.0/8` (Clase A) es el que verías en redes corporativas grandes.
 
---
 
## 🅱️ Clase B
 
```
10NNNNNN.NNNNNNNN.HHHHHHHH.HHHHHHHH
└────── red ──────┘└──── host ─────┘
```
 
- **Red**: 16 bits (los dos primeros fijos a `10`) → 14 bits útiles.
- **Host**: 16 bits.
- **Máscara**: `255.255.0.0` (`/16`).
| Característica | Valor |
|---|---|
| Nº de redes | 16.384 |
| Hosts por red | 65.534 (`2¹⁶ − 2`) |
| Rango | `128.0.0.0` – `191.255.255.255` |
| Ejemplo | `172.16.5.10` |
 
> [!example] Para qué se usaba
> Empresas y universidades de tamaño medio-grande. El rango privado `172.16.0.0/12` cae aquí.
 
---
 
## 🅲️ Clase C
 
```
110NNNNN.NNNNNNNN.NNNNNNNN.HHHHHHHH
└──────── red ───────────┘└─ host ─┘
```
 
- **Red**: 24 bits (los tres primeros fijos a `110`) → 21 bits útiles.
- **Host**: 8 bits.
- **Máscara**: `255.255.255.0` (`/24`).
| Característica | Valor |
|---|---|
| Nº de redes | 2.097.152 |
| Hosts por red | 254 (`2⁸ − 2`) |
| Rango | `192.0.0.0` – `223.255.255.255` |
| Ejemplo | `192.168.1.50` |
 
> [!example] Para qué se usaba
> Redes pequeñas. Es la clase más familiar: tu router doméstico casi seguro usa `192.168.x.x/24` (rango privado Clase C).
 
---
 
## 🏠 IPs privadas por clase (RFC 1918)
 
Aunque las clases estén obsoletas, los rangos privados se siguen describiendo así:
 
| Clase | Rango privado | CIDR |
|---|---|---|
| **A** | `10.0.0.0` – `10.255.255.255` | /8 |
| **B** | `172.16.0.0` – `172.31.255.255` | /12 |
| **C** | `192.168.0.0` – `192.168.255.255` | /16 |
 
---
 
## 🚫 Direcciones especiales que se "comen" rangos
 
> [!note] No todo el espacio es asignable
> - `0.0.0.0/8` → "esta red" / origen desconocido.
> - `127.0.0.0/8` → **loopback** (`127.0.0.1` = tu propia máquina). Por eso la Clase A llega solo hasta 126.
> - **Clase D** (`224–239`) → **multicast**.
> - **Clase E** (`240–255`) → reservada/experimental.
 
---
 
## 💥 Por qué murió el sistema classful
 
> [!info] El problema
> Las clases eran **demasiado rígidas**:
> - Si necesitabas 300 hosts, una Clase C (254) se quedaba corta → te daban una **Clase B entera (65.534)** y desperdiciabas ~65.000 direcciones.
> - Esto agotaba el espacio IPv4 a toda velocidad.
>
> **La solución → [[CIDR]]**: máscaras de longitud variable (`/27`, `/19`, etc.) que ajustan el tamaño de la red a la necesidad real, sin clases.

> [!quote] Idea para fijar
> Mira el **primer octeto** y sabrás la clase: **A** hasta 126, **B** hasta 191, **C** hasta 223. Cuanto más alta la clase, **más redes pero menos hosts** en cada una. Hoy todo esto lo gestiona **CIDR** de forma flexible, pero las clases explican el "por qué" de las máscaras por defecto.
