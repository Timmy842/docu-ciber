# Fuerza Bruta con John The Ripper

> [!info] Idea principal
> John The Ripper hace fuerza bruta **offline**: en vez de lanzar intentos contra un servicio en la red, trabaja sobre un **hash** que ya tengo en mi maquina. El flujo siempre es el mismo: *extraer el hash* → *pasarselo a John con un diccionario* → *recuperar la contraseña en claro*.

> [!warning] Importante
> Usar estas tecnicas solo sobre ficheros propios, laboratorios o entornos con permiso.

## Online vs Offline

Es la diferencia clave con [[4. Hydra - Ataque a Contraseñas]]:

| | Hydra (online) | John (offline) |
|---|---|---|
| Contra que ataca | Un servicio en red (SSH, FTP, MySQL) | Un hash o fichero cifrado local |
| Velocidad | Limitada por la red y el servidor | Limitada solo por mi CPU/GPU |
| Ruido | Genera logs y puede bloquear la cuenta | **Silencioso**, nadie se entera |
| Requisito | Conectividad con el objetivo | Haber conseguido antes el hash |

> [!tip] Se complementan
> Lo habitual es encadenarlos: saco hashes de una base de datos con [[8. Fuerza Bruta contra DBs]], los crackeo offline con John, y las contraseñas resultantes las pruebo contra SSH o FTP.

> [!note] El binario se llama `john`
> Cuidado con la errata tipica de escribir `jhon`. El comando correcto es **`john`** (y `zip2john`, `keepass2john`...).

---

## La Familia `*2john`

John no entiende un `.zip` ni un `.kdbx` directamente. Primero hay que **extraer el hash** del fichero con el conversor correspondiente. Todos siguen el mismo patron:

```bash
<formato>2john archivo > hash
```

| Conversor | Para que sirve |
|---|---|
| `zip2john` | Archivos `.zip` con contraseña |
| `rar2john` | Archivos `.rar` |
| `7z2john` | Archivos `.7z` |
| `keepass2john` | Bases de datos KeePass `.kdbx` |
| `ssh2john` | Claves privadas SSH con passphrase (`id_rsa`) |
| `pdf2john` | PDF protegidos |
| `office2john` | Documentos de Word/Excel/PowerPoint |
| `unshadow` | Combina `/etc/passwd` + `/etc/shadow` |

## Caso 1: Crackear un ZIP con Contraseña

### Paso 1: Extraer el hash

```bash
zip2john archivo.zip > hash
```

> [!note] Que hace realmente
> Lee la cabecera cifrada del ZIP y genera una linea con el formato que John entiende (nombre del fichero + el hash). El `>` guarda esa salida en el fichero `hash`.

### Paso 2: Crackear con diccionario

```bash
john --wordlist=/usr/share/wordlists/rockyou.txt hash
```

John va probando cada palabra de `rockyou.txt` hasta dar con la correcta. Cuando acierta la muestra en pantalla.

### Paso 3: Ver la contraseña encontrada

```bash
john --show hash
```

### Paso 4: Descomprimir el ZIP

```bash
unzip -P password1 archivo.zip
```

> [!tip] La `-P` va en mayuscula
> En `unzip`, `-P` (mayuscula) es la contraseña. La `-p` minuscula significa otra cosa (volcar a stdout). Si la contraseña lleva caracteres raros, ponla entre comillas simples.

---

## Caso 2: Crackear una Base de Datos KeePass

Mismo procedimiento, cambiando solo el conversor.

```bash
keepass2john archivo.kdbx > hash
john --wordlist=/usr/share/wordlists/rockyou.txt hash
```

> [!success] Por que merece tanto la pena
> Una base de datos de KeePass es el **llavero completo** de la victima. Romper esa unica contraseña maestra da acceso de golpe a todas las credenciales que guarda dentro.

> [!note] Si el `.kdbx` usa fichero llave
> Cuando KeePass esta configurado con *key file* ademas de contraseña, `keepass2john` necesita indicarselo con `-k fichero.key`. Sin ese fichero, la fuerza bruta no sirve de nada.

---

## Caso 3: Crackear un Hash Suelto

A veces no hay fichero: solo tengo una cadena de hash (sacada de una base de datos, de un fichero de configuracion, de una web...).

### Intento directo

```bash
john --wordlist=/usr/share/wordlists/rockyou.txt hash
```

John intenta **detectar el formato automaticamente**. Muchas veces funciona sin mas.

### Si no lo detecta: identificar el tipo de hash

```bash
hash-identifier
```

> [!warning] `hash-identifier` es interactivo
> No se le pasa el fichero como argumento: se ejecuta a secas y **pide el hash por teclado**. Se le pega la cadena y devuelve los formatos posibles ordenados por probabilidad.
>
> Si prefieres pasarle un fichero directamente, usa `hashid`:
> ```bash
> hashid -m hash
> ```

### Pistas rapidas para identificar a ojo

| Longitud | Formato probable | `--format=` |
|---|---|---|
| 32 caracteres hex | MD5 | `Raw-MD5` |
| 40 caracteres hex | SHA-1 | `Raw-SHA1` |
| 64 caracteres hex | SHA-256 | `Raw-SHA256` |
| Empieza por `$1$` | MD5 crypt | `md5crypt` |
| Empieza por `$6$` | SHA-512 crypt (Linux) | `sha512crypt` |
| Empieza por `$2y$` | bcrypt | `bcrypt` |
| Empieza por `$P$` | phpBB / WordPress | `phpass` |

### Forzar el formato

```bash
john --format=Raw-MD5 --wordlist=/usr/share/wordlists/rockyou.txt hash
```

> [!tip] Ver todos los formatos soportados
> ```bash
> john --list=formats
> ```

## El Fichero `john.pot` (el fallo mas comun)

> [!bug] "Lo lanzo otra vez y no me dice nada"
> John guarda todo lo que ya ha crackeado en `~/.john/john.pot`. Si vuelves a lanzarlo sobre el mismo hash, responde:
> ```text
> No password hashes left to crack (see FAQ)
> ```
> **No es un error**: significa que ya lo tenia resuelto. Para ver el resultado:
> ```bash
> john --show hash
> ```
> Y si quieres crackearlo otra vez desde cero, borra la entrada del pot:
> ```bash
> rm ~/.john/john.pot
> ```

## Modos de Ataque

| Modo | Comando | Cuando usarlo |
|---|---|---|
| Wordlist | `john --wordlist=rockyou.txt hash` | El habitual, primera opcion siempre |
| Wordlist + reglas | `john --wordlist=rockyou.txt --rules hash` | Genera variantes (`password` → `Password1`, `p4ssw0rd`) |
| Single | `john --single hash` | Usa el nombre de usuario como base. Muy rapido, probar antes que nada |
| Incremental | `john --incremental hash` | Fuerza bruta pura. Ultimo recurso, puede tardar años |

> [!tip] Orden recomendado
> 1. `--single` (segundos).
> 2. `--wordlist` con `rockyou.txt`.
> 3. `--wordlist` + `--rules`.
> 4. `--incremental` solo si la contraseña es corta y no queda otra.

## Comandos Utiles

### Crackear un ZIP

```bash
zip2john archivo.zip > hash
john --wordlist=/usr/share/wordlists/rockyou.txt hash
unzip -P password1 archivo.zip
```

### Crackear KeePass

```bash
keepass2john archivo.kdbx > hash
john --wordlist=/usr/share/wordlists/rockyou.txt hash
```

### Crackear una clave privada SSH

```bash
ssh2john id_rsa > hash
john --wordlist=/usr/share/wordlists/rockyou.txt hash
```

### Crackear usuarios de Linux (`/etc/shadow`)

```bash
unshadow /etc/passwd /etc/shadow > hash
john --wordlist=/usr/share/wordlists/rockyou.txt hash
```

### Forzar formato

```bash
john --format=Raw-MD5 --wordlist=/usr/share/wordlists/rockyou.txt hash
```

### Ver contraseñas ya crackeadas

```bash
john --show hash
```

### Identificar un hash

```bash
hash-identifier          # interactivo: pega el hash cuando lo pida
hashid -m hash           # acepta fichero directamente
```

### Acelerar usando varios nucleos

```bash
john --fork=4 --wordlist=/usr/share/wordlists/rockyou.txt hash
```

## Flujo Resumido

> [!example] Pasos tipicos
> 1. Conseguir el fichero protegido o el hash.
> 2. Si es un fichero, extraer el hash con el `*2john` correspondiente.
> 3. Lanzar `john --wordlist=rockyou.txt hash`.
> 4. Si no detecta el formato, identificarlo con `hash-identifier` o `hashid`.
> 5. Repetir forzando `--format=`.
> 6. Ver el resultado con `john --show hash`.
> 7. Usar la contraseña (abrir el ZIP, el KeePass) y **probarla en otros servicios**.

## Checklist Rapido

- [ ] Confirmar que tengo permiso sobre el fichero o el hash.
- [ ] Identificar el tipo de fichero y elegir el conversor `*2john`.
- [ ] Generar el fichero `hash` y comprobar que no esta vacio.
- [ ] Probar `--single` antes del diccionario.
- [ ] Lanzar con `rockyou.txt`.
- [ ] Si falla, identificar el hash y forzar `--format=`.
- [ ] Si dice "No password hashes left to crack", mirar `john --show`.
- [ ] Si sigue sin salir, añadir `--rules`.
- [ ] Anotar la contraseña y probarla en SSH, FTP y demas servicios.
