# Hydra - Ataque a Usuarios

> [!info] Idea principal
> Es el caso contrario al ataque de contraseñas: cuando ya conozco una **contraseña** valida pero no se a que **usuario** pertenece, uso Hydra con una lista de usuarios (`-L`) contra esa unica contraseña (`-p`) para descubrir el login correcto.

## Cuando Usar Este Ataque

En el laboratorio anterior ([[4. Hydra - Ataque a Contraseñas]]) tenia un usuario conocido y probaba muchas contraseñas. Aqui la situacion se invierte:

- Consigo una contraseña filtrada (documento, mensaje, credencial reutilizada...).
- No se a que usuario del sistema pertenece.
- Pruebo esa contraseña contra una lista de usuarios probables.

> [!tip] Diccionario de usuarios
> Kali trae listas de usuarios habituales en `/usr/share/wordlists/metasploit/`, muy utiles para este tipo de ataque. Por ejemplo `unix_users.txt`.

## Sintaxis Basica

```bash
hydra -L lista_usuarios -p contraseña servicio://IP
```

### Parametros Usados

- `-L`: lista de usuarios (archivo) — lo contrario a `-l` (un unico usuario).
- `-p`: una unica contraseña conocida.
- `servicio://IP`: protocolo y objetivo (por ejemplo `ssh://192.168.0.242`).

> [!note] Como recordarlo
> Es el espejo del ataque anterior: antes `-l` + `-P` (un usuario, muchas contraseñas). Ahora `-L` + `-p` (muchos usuarios, una contraseña).

## Caso Practico

Sigo en el laboratorio de la maquina **friendly3**. En el reconocimiento del puerto 80 ya habia encontrado el usuario `juan`, pero esta vez asumo que **no conozco el usuario** y solo tengo la contraseña `alexis`. Pruebo a descubrirlo por fuerza bruta.

### Paso 1: Fuerza Bruta a SSH

Ataco el servicio SSH con la lista de usuarios de Metasploit y la contraseña conocida.

```bash
hydra -L /usr/share/wordlists/metasploit/unix_users.txt -p alexis ssh://192.168.0.242
```

### Paso 2: Fuerza Bruta a FTP

Reutilizo la misma logica contra el servicio FTP, ya que la contraseña puede pertenecer a un usuario valido en varios servicios.

```bash
hydra -L /usr/share/wordlists/metasploit/unix_users.txt -p alexis ftp://192.168.0.242
```

## Comandos Utiles

### Ataque a usuarios (contraseña conocida) — SSH

```bash
hydra -L /usr/share/wordlists/metasploit/unix_users.txt -p alexis ssh://192.168.0.242
```

### Ataque a usuarios — FTP

```bash
hydra -L /usr/share/wordlists/metasploit/unix_users.txt -p alexis ftp://192.168.0.242
```

### Reducir tareas en paralelo (recomendado para SSH)

```bash
hydra -L /usr/share/wordlists/metasploit/unix_users.txt -p alexis -t 4 ssh://192.168.0.242
```

## Flujo Resumido

> [!example] Pasos tipicos
> 1. Conseguir una contraseña valida (web, documentos, filtraciones...).
> 2. Elegir una lista de usuarios probables (`unix_users.txt` u otra).
> 3. Lanzar Hydra con `-L lista -p contraseña` contra el servicio objetivo.
> 4. Anotar el usuario descubierto.
> 5. Repetir contra otros servicios (SSH, FTP...) para confirmar y ampliar el acceso.

## Checklist Rapido

- [ ] Confirmar que tengo permiso para atacar la maquina.
- [ ] Tener una contraseña valida pero sin usuario asociado.
- [ ] Elegir una lista de usuarios (`unix_users.txt` u otra).
- [ ] Lanzar Hydra con `-L` y `-p`.
- [ ] Reducir tareas con `-t 4` si es SSH.
- [ ] Repetir el ataque en otros servicios para confirmar la credencial.
- [ ] Guardar el usuario y la contraseña descubiertos.
