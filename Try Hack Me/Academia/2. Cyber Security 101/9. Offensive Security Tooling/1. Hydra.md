# TryHackMe: Hydra

Este documento es un resumen detallado de la sala "Hydra" de TryHackMe. Hydra es una de las herramientas más rápidas y flexibles para realizar ataques de fuerza bruta en línea (online password cracking) contra servicios de autenticación como SSH, FTP, HTTP, etc.

## Task 1: Introduction (Introducción)

Hydra es una herramienta de fuerza bruta paralelizada que soporta numerosos protocolos. A diferencia de herramientas como John the Ripper (que crackean hashes offline), Hydra ataca servicios en ejecución enviando credenciales y analizando la respuesta.

## Task 2: Using Hydra (Uso Básico)

La sintaxis general de Hydra es:
`hydra [opciones de usuario] [opciones de contraseña] [IP] [servicio] [opciones extra]`

### Parámetros Clave:
- **`-l <user>`**: Prueba un único nombre de usuario.
- **`-L <archivo>`**: Prueba una lista de usuarios (wordlist).
- **`-p <pass>`**: Prueba una única contraseña.
- **`-P <archivo>`**: Prueba una lista de contraseñas (wordlist, ej: `rockyou.txt`).
- **`-t <número>`**: Define el número de hilos (threads) o tareas paralelas. Por defecto es 16. Útil para acelerar el ataque o reducirlo para no saturar el servidor.
- **`-vV`**: Modo "Very Verbose". Muestra cada intento de usuario/contraseña en tiempo real (útil para depurar si la conexión funciona).
- **`-s <puerto>`**: Especifica un puerto no estándar (ej: SSH en 2222).

## Task 3: Hydra - SSH (Secure Shell)

El protocolo SSH se usa para acceso remoto seguro. Por defecto corre en el puerto **22**.

**Comando Típico:**
```bash
hydra -l usuario -P /usr/share/wordlists/rockyou.txt ssh://<IP_OBJETIVO>
```
1.  **`-l usuario`**: Sabemos el usuario objetivo (ej: `molly`).
2.  **`-P rockyou.txt`**: Usamos el diccionario RockYou para probar contraseñas.
3.  **`ssh://...`**: Especificamos el protocolo y la IP.

## Task 4: Hydra - FTP (File Transfer Protocol)

El protocolo FTP se usa para transferencia de archivos. Por defecto corre en el puerto **21**.

**Comando Típico:**
```bash
hydra -l usuario -P /usr/share/wordlists/rockyou.txt ftp://<IP_OBJETIVO>
```
> **Nota:** Si el servidor FTP es lento o limita conexiones, reduce los hilos con `-t 4` para evitar errores de conexión.

## Task 5: Hydra - Web Forms (Formularios Web)

Esta es la parte más compleja. Para atacar un formulario de login web (HTTP POST), Hydra necesita saber 3 cosas:
1.  **La URL** del login (ej: `/login.php`).
2.  **Los parámetros** del cuerpo de la petición (ej: `user=admin&pass=1234&login=true`).
3.  **El mensaje de error** que devuelve la página cuando fallas (para saber cuándo ha tenido éxito).

### Pasos para construir el comando:
1.  Abre el navegador y las **Developer Tools (F12)** -> pestaña **Network**.
2.  Intenta loguearte con credenciales falsas.
3.  Busca la petición **POST** y copia el **Request Payload** (cuerpo de la petición).
4.  Identifica el mensaje de error en la página web (ej: "Invalid username").

### Sintaxis del Módulo `http-post-form`:
El argumento es una cadena entre comillas dividida por dos puntos (`:`):
`"<url>:<cuerpo_peticion>:<mensaje_error>"`

**Comando Completo:**
```bash
hydra -l user -P /usr/share/wordlists/rockyou.txt <IP_OBJETIVO> http-post-form "/login.php:username=^USER^&password=^PASS^&Login=Login:F=Username or password invalid"
```

**Desglose:**
- **`/login.php`**: La página donde se envían los datos.
- **`username=^USER^&...`**: Los parámetros del formulario. Hydra sustituirá `^USER^` y `^PASS^` en cada intento.
- **`F=Username or password...`**: Le dice a Hydra que si encuentra esa frase en la respuesta (`F` de Fail), el intento ha fallado. Si *no* la encuentra, asume que es la contraseña correcta.

## Task 6: Conclusion (Conclusión)

Hydra es una herramienta esencial en el arsenal de cualquier pentester.
- **Versatilidad:** Soporta `rdp`, `telnet`, `mysql`, `postgres`, `smb`, `snmp`, etc.
- **Optimización:** Ajustar el número de hilos (`-t`) es clave para el éxito.
- **Wordlists:** La lista más común en Kali Linux es `/usr/share/wordlists/rockyou.txt`.
