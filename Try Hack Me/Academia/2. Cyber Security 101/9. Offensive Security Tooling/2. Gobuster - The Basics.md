# TryHackMe: Gobuster - The Basics

Este documento es un resumen detallado de la sala "Gobuster: The Basics" de TryHackMe. Gobuster es una herramienta rápida y eficiente escrita en Go, utilizada para fuerza bruta de URIs, subdominios DNS y Virtual Hosts.

## Task 1: Introduction (Introducción)

Gobuster es una herramienta de enumeración esencial en la fase de reconocimiento. Su velocidad se debe a que utiliza "goroutines" (hilos ligeros de Go). Se usa principalmente para descubrir contenido oculto que no está enlazado en la aplicación web.

## Task 2: Environment and Setup (Configuración)

Antes de empezar, asegúrate de tener Gobuster instalado. Viene preinstalado en Kali Linux y en la AttackBox de TryHackMe.
- **Diccionarios (Wordlists):** Gobuster necesita un diccionario para funcionar. En Kali, suelen estar en `/usr/share/wordlists`.
    - `dirb/common.txt`
    - `dirbuster/directory-list-2.3-medium.txt`
    - `SecLists/Discovery/DNS/subdomains-top1million-5000.txt`

## Task 3: Gobuster: Introduction (Introducción a la Herramienta)

Gobuster tiene varios modos de operación:
- **`dir`**: Enumeración de directorios y archivos (Modo clásico).
- **`dns`**: Enumeración de subdominios DNS.
- **`vhost`**: Enumeración de Virtual Hosts.
- **`fuzz`**: Fuzzing genérico (reemplaza `FUZZ` en la URL).
- **`s3`**: Enumeración de buckets S3 de AWS.

Puedes ver la ayuda general con `gobuster help` o la ayuda de un modo específico con `gobuster dir --help`.

## Task 4: Use Case: Directory and File Enumeration (Enumeración de Directorios)

Este es el modo más utilizado. Sirve para encontrar directorios y archivos ocultos en un servidor web.

**Comando Básico:**
```bash
gobuster dir -u <URL> -w <WORDLIST>
```

### Flags Clave:
- `-u, --url`: La URL objetivo (ej. `http://10.10.10.10`).
- `-w, --wordlist`: Ruta al diccionario.
- `-t`: Número de hilos (Threads). Aumentarlo acelera el escaneo (ej. `-t 64`).
- `-x`: Extensiones de archivo a buscar (ej. `-x php,txt,html`).
- `-k`: Ignorar errores de certificado SSL/TLS.
- `-s`: Códigos de estado positivos (ej. `200,301,302`).
- `-b`: Códigos de estado a excluir (blacklist), útil para filtrar falsos positivos (ej. `-b 404`).

## Task 5: Use Case: Subdomain Enumeration (Enumeración de Subdominios)

Este modo enumera subdominios consultando un servidor DNS. Es útil para encontrar `admin.empresa.com`, `dev.empresa.com`, etc.

**Comando Básico:**
```bash
gobuster dns -d <DOMINIO> -w <WORDLIST>
```

### Flags Clave:
- `-d`: El dominio base (ej. `tryhackme.com`).
- `-i`: Mostrar las direcciones IP de los subdominios encontrados.
- `-r`: Especificar un servidor DNS personalizado (ej. `8.8.8.8`) para evitar bloqueos o usar uno interno.

## Task 6: Use Case: Vhost Enumeration (Enumeración de VHosts)

A diferencia del modo DNS, el modo `vhost` busca Virtual Hosts enviando peticiones HTTP con diferentes cabeceras `Host`. Esto es crucial cuando múltiples sitios web comparten la misma dirección IP y el servidor web (Nginx/Apache) decide cuál mostrar según el `Host header`.

**Comando Básico:**
```bash
gobuster vhost -u <URL> -w <WORDLIST>
```

**Diferencia DNS vs VHost:**
- **DNS:** Pregunta al servidor de nombres "¿Existe subdominio.dominio.com?".
- **VHost:** Pregunta al servidor web (IP) "Dame el contenido de subdominio.dominio.com".

**Ejemplo:**
```bash
gobuster vhost -u http://10.10.10.10 -w /usr/share/wordlists/subdomains.txt --append-domain
```
*(La flag `--append-domain` añade automáticamente el dominio base a las palabras del diccionario).*
