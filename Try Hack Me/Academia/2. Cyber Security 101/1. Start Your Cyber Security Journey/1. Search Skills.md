## 1. Introducción
La habilidad de buscar información de manera efectiva es fundamental en ciberseguridad. No se trata solo de usar Google, sino de saber filtrar el ruido, evaluar la credibilidad de las fuentes y utilizar herramientas especializadas para encontrar vulnerabilidades, documentación técnica o información sobre objetivos.

---

## 2. Evaluación de Resultados de Búsqueda
Internet está lleno de desinformación. Antes de confiar en un resultado, debes aplicar un pensamiento crítico.

### Criterios de Evaluación
* **Autoridad:** ¿Quién es el autor o la organización? ¿Es una fuente reputada (ej. documentación oficial, vendor) o un blog personal desconocido?
* **Evidencia:** ¿Las afirmaciones están respaldadas por datos, pruebas de concepto (PoC) o referencias fiables?
* **Objetividad:** ¿La información es imparcial o intenta vender un producto/agenda?
* **Actualidad:** ¿La información es reciente? En ciberseguridad, un artículo de hace 5 años puede ser obsoleto.
* **Corroboración:** ¿Otras fuentes fiables dicen lo mismo?

---

## 3. Motores de Búsqueda y Google Dorks
Aprender a usar **operadores de búsqueda** (Google Dorks) permite filtrar millones de resultados para encontrar archivos específicos, paneles de login o errores expuestos.

### Operadores Comunes
| Operador | Descripción | Ejemplo |
| :--- | :--- | :--- |
| `site:` | Limita la búsqueda a un dominio específico. | `site:microsoft.com` |
| `filetype:` | Busca tipos de archivo específicos (pdf, log, txt, conf). | `filetype:pdf "cyber warfare"` |
| `inurl:` | Busca términos dentro de la URL. | `inurl:admin` |
| `intitle:` | Busca términos en el título de la página. | `intitle:"index of"` |
| `""` | Búsqueda de frase exacta. | `"error de sintaxis SQL"` |
| `-` | Excluye un término de la búsqueda. | `site:github.com -site:gist.github.com` |
| `OR` / `|` | Busca uno u otro término. | `password OR clave` |

### Ejemplo Práctico (Reto de la sala)
* **Pregunta:** ¿Cómo limitarías tu búsqueda en Google a archivos PDF que contengan los términos "cyber warfare report"?
* **Respuesta:** `filetype:pdf cyber warfare report`

## 4. Motores de Búsqueda Especializados
Google indexa la web "visible", pero para ciberseguridad necesitamos buscadores que indexen dispositivos, código o malware.

### Herramientas Clave
1.  **Shodan / Censys:**
    * Motores de búsqueda para el **Internet de las Cosas (IoT)** y servidores.
    * Permiten buscar por banners de servicio, puertos abiertos, versiones de software, etc.
    * *Ejemplo:* Buscar servidores `Apache` en `Germany`.
2.  **VirusTotal:**
    * Plataforma para analizar archivos y URLs sospechosas.
    * Busca hashes de archivos para ver si otros motores antivirus los han detectado como maliciosos.
3.  **GreyNoise:**
    * Ayuda a distinguir entre tráfico de escaneo masivo (ruido de fondo) y ataques dirigidos.

### Ejemplo Práctico (Reto de la sala)
* **Pregunta:** ¿Cuál es el país principal con servidores `lighttpd` (según Shodan)?
* **Respuesta:** `United States` (Nota: Esto puede variar en tiempo real, pero es la respuesta típica en el contexto del ejercicio).

## 5. Vulnerabilidades y Exploits
Saber buscar si una versión de software tiene fallos de seguridad conocidos es vital para un pentester.

### Bases de Datos de Vulnerabilidades
* **CVE (Common Vulnerabilities and Exposures):**
    * Es una lista de registros de vulnerabilidades de seguridad registradas públicamente.
    * Formato: `CVE-AÑO-ID` (ej. `CVE-2017-0144`).
* **NVD (National Vulnerability Database):**
    * Base de datos del gobierno de EE.UU. que analiza los CVE y les asigna una puntuación de riesgo (CVSS).

### Bases de Datos de Exploits
* **Exploit-DB:**
    * Repositorio oficial de *The Exploit Database*. Contiene exploits verificados y Proof of Concepts (PoCs).
    * Herramienta de línea de comandos en Kali Linux: `searchsploit`.
    * *Uso:* `searchsploit apache 2.4`

## 6. Documentación Técnica
A menudo, la respuesta no está en un foro de hacking, sino en el manual oficial de la herramienta o sistema operativo.

### Fuentes Principales
* **Man Pages (Linux):**
    * El manual integrado en sistemas Linux/Unix.
    * Comando: `man <comando>` (ej. `man netstat`).
    * *Tip:* Si buscas un comando que reemplace a uno obsoleto (como `netstat`), las man pages o una búsqueda rápida suelen indicarlo.
* **Microsoft Docs (MSDN/Learn):**
    * La biblia para sistemas Windows, PowerShell y AD.
* **Documentación del Vendor:**
    * Cisco, Juniper, Oracle, etc., tienen sus propios repositorios de comandos y configuraciones.

### Ejemplo Práctico (Reto de la sala)
* **Pregunta:** ¿Qué comando reemplaza a `netstat` en sistemas Linux modernos (por ser más rápido y eficiente)?
* **Respuesta:** `ss` (Socket Statistics).
* **Pregunta:** ¿Qué significa el comando `cat`?
* **Respuesta:** `concatenate`.

## 7. Redes Sociales (OSINT)
Las redes sociales son una mina de oro para la ingeniería social y el perfilado de objetivos.

* **LinkedIn:** Ideal para estructura corporativa, tecnologías que usa la empresa (visto en ofertas de empleo o habilidades de empleados) y jerarquías.
* **Twitter (X) / Reddit:** Bueno para noticias de última hora sobre brechas de seguridad o discusiones técnicas informales.
* **Facebook / Instagram:** Información personal para respuestas a preguntas de seguridad (ej. "¿Nombre de tu primera mascota?" o "¿A qué escuela fuiste?").

### Ejemplo Práctico (Reto de la sala)
* **Escenario:** Estás intentando encontrar la respuesta a la pregunta de seguridad "¿A qué escuela fuiste de niño?". ¿Qué red social usarías?
* **Respuesta:** `Facebook` (Es donde la gente suele poner su historial académico personal/antiguo).
