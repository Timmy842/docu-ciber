# TryHackMe: Burp Suite - The Basics

Este documento es un resumen detallado de la sala "Burp Suite: The Basics" de TryHackMe. Burp Suite es la herramienta estándar de facto para pruebas de seguridad en aplicaciones web, actuando como un proxy que intercepta el tráfico entre el navegador y el servidor.

## Task 1: Introduction (Introducción)

Burp Suite es un framework basado en Java para realizar pruebas de penetración en aplicaciones web. Permite mapear, analizar y explotar vulnerabilidades.

## Task 2: What is Burp Suite? (¿Qué es?)

Es una colección de herramientas integradas en una sola interfaz.
- **Proxy:** Intercepta y modifica el tráfico.
- **Repeater:** Permite reenviar peticiones manualmente.
- **Intruder:** Automatiza ataques (fuerza bruta, fuzzing).
- **Decoder:** Codifica/Decodifica datos.
- **Comparer:** Compara diferencias entre respuestas.
- **Extender:** Añade funcionalidades extra mediante plugins.

## Task 3: Features of Burp Community (Versiones)

- **Community Edition:** Gratuita. Incluye las herramientas esenciales pero tiene el Intruder limitado en velocidad y no incluye el escáner de vulnerabilidades.
- **Professional Edition:** De pago. Incluye escáner automatizado, Intruder sin limitaciones, Burp Collaborator (para detectar interacciones fuera de banda) y guardar proyectos.

## Task 4: Installation (Instalación)

Generalmente viene preinstalado en Kali Linux y Parrot OS. Si no, se puede descargar el instalador `.sh` o `.jar` desde la web de PortSwigger.

## Task 5: The Dashboard (El Panel)

Es la vista principal al abrir Burp (en versiones modernas). Muestra:
- **Tasks:** Escaneos activos (solo Pro) o tareas de crawling.
- **Event Log:** Registro de errores o advertencias del sistema.
- **Issue Activity:** Vulnerabilidades detectadas en tiempo real (solo Pro).

## Task 6: Navigation (Navegación)

La interfaz se divide en pestañas superiores para cada herramienta (Proxy, Repeater, etc.). Los atajos de teclado son vitales:
- `Ctrl + R`: Enviar a Repeater.
- `Ctrl + I`: Enviar a Intruder.
- `Ctrl + Shift + D`: Cambiar al Dashboard.

## Task 7: Options (Opciones)

Configuración global del proyecto y usuario.
- **User Options:** Preferencias de la interfaz, conexiones upstream, atajos.
- **Project Options:** Configuración específica de la sesión actual (alcance, autenticación).

## Task 8: Introduction to the Burp Proxy (El Proxy)

El corazón de Burp. Actúa como un "Man-in-the-Middle" (MitM).
- **Intercept:**
    - `Intercept is on`: Detiene cada petición para revisarla/editarla.
    - `Intercept is off`: Deja pasar el tráfico pero lo registra.
    - `Forward`: Envía la petición detenida al servidor.
    - `Drop`: Descarta la petición.
- **HTTP History:** Historial completo de peticiones/respuestas. Vital para análisis post-mortem.

## Task 9: Connecting through the Proxy (FoxyProxy)

Para que el navegador envíe tráfico a Burp, debes configurar el proxy en `127.0.0.1:8080`.
- **FoxyProxy:** Extensión recomendada para Firefox/Chrome que permite cambiar el proxy con un clic.

## Task 10: Site Map and Issue Definitions (Mapa del Sitio)

- **Target > Site Map:** Muestra una estructura de árbol de todos los sitios visitados y su contenido.
- **Target > Scope:** Define qué dominios quieres analizar/atacar. Configura esto para evitar atacar sitios externos por error.

## Task 11: The Burp Suite Browser (Navegador Integrado)

Burp incluye un navegador Chromium preconfigurado que ya tiene el certificado CA de Burp instalado y el proxy configurado.
- Pestaña **Proxy > Intercept > Open Browser**.
- Evita tener que configurar FoxyProxy y certificados manualmente.

## Task 12: Scoping and Targeting (Alcance)

Definir el **Scope** es crucial.
1.  Ve a `Target > Scope`.
2.  Añade la URL del objetivo (ej. `http://10.10.10.10`).
3.  En `Proxy > HTTP History`, puedes filtrar para mostrar solo elementos "In Scope".

## Task 13: Proxying HTTPS (Certificados)

Para interceptar tráfico HTTPS, el navegador debe confiar en la Autoridad de Certificación (CA) de Burp.
1.  Visita `http://burp` en el navegador con el proxy activo.
2.  Descarga el certificado (`CA Certificate`).
3.  Importa el certificado en el navegador como "Trusted Root Certification Authority".

## Task 14: Example Attack (Ataque de Ejemplo)

Un flujo típico podría ser:
1.  Navegar a la página de login.
2.  Interceptar la petición de login (`POST /login`) en el **Proxy**.
3.  Enviarla al **Repeater** (`Ctrl + R`) para probar inyecciones SQL manualmente.
4.  O enviarla al **Intruder** (`Ctrl + I`) para hacer fuerza bruta.

## Task 15: Conclusion

Burp Suite es una herramienta indispensable. Dominar el Proxy y el Repeater es el primer paso para cualquier pentester web.
