# TryHackMe: SQL Fundamentals

Este documento es un resumen detallado de la sala "SQL Fundamentals" de TryHackMe, cubriendo desde conceptos básicos hasta operaciones complejas esenciales para entender inyecciones SQL.

## Task 1: Introduction (Introducción)

SQL (Structured Query Language) es el lenguaje estándar para gestionar bases de datos relacionales. Aprenderlo es fundamental para entender vulnerabilidades web críticas como **SQL Injection**.

## Task 2: Databases 101 (Bases de Datos)

Una base de datos es una colección organizada de información estructurada.
- **Relational Databases (RDBMS):** Organizan datos en tablas interconectadas. Ejemplos: MySQL, PostgreSQL, Microsoft SQL Server.
- **Estructura:**
    - **Database:** El contenedor principal.
    - **Tables (Tablas):** Estructuras tipo hoja de cálculo (ej. `users`, `products`).
    - **Columns (Columnas):** Definen el tipo de dato (ej. `id`, `username`, `password`).
    - **Rows (Filas):** Los registros individuales de datos.

## Task 3: SQL (El Lenguaje)

SQL permite realizar tareas como consultar, insertar, actualizar y borrar datos. Es un lenguaje declarativo: le dices a la base de datos *qué* quieres, no *cómo* conseguirlo.

## Task 4: Database and Table Statements (Sentencias DDL)

Estas sentencias definen la estructura (Data Definition Language).
- **CREATE DATABASE:** Crea una nueva base de datos.
    ```sql
    CREATE DATABASE shop;
    ```
- **CREATE TABLE:** Crea una nueva tabla definiendo sus columnas y tipos de datos.
    ```sql
    CREATE TABLE users (
        id INT,
        username VARCHAR(30),
        password VARCHAR(30)
    );
    ```
- **DROP DATABASE / DROP TABLE:** Elimina bases de datos o tablas enteras (¡Cuidado!).

## Task 5: CRUD Operations (Operaciones CRUD)

CRUD se refiere a las 4 operaciones básicas en datos: **C**reate, **R**ead, **U**pdate, **D**elete.

### 1. Create (INSERT)
Agrega nuevos registros.
```sql
INSERT INTO users (username, password) VALUES ('admin', '12345');
```

### 2. Read (SELECT)
Recupera datos. Es el comando más usado.
```sql
SELECT * FROM users; -- Selecciona todas las columnas
SELECT username FROM users; -- Selecciona solo la columna username
```

### 3. Update (UPDATE)
Modifica registros existentes. **IMPORTANTE:** Siempre usa `WHERE` o actualizarás toda la tabla.
```sql
UPDATE users SET password = 'newpass' WHERE username = 'admin';
```

### 4. Delete (DELETE)
Elimina registros. **IMPORTANTE:** Siempre usa `WHERE`.
```sql
DELETE FROM users WHERE username = 'invitado';
```

## Task 6: Clauses (Cláusulas)

Las cláusulas refinan las consultas SQL.
- **WHERE:** Filtra registros que cumplen una condición.
    ```sql
    SELECT * FROM products WHERE price > 100;
    ```
- **ORDER BY:** Ordena los resultados (ASCendente o DESCendente).
    ```sql
    SELECT * FROM users ORDER BY username ASC;
    ```
- **GROUP BY:** Agrupa filas con los mismos valores (útil para contar).
- **LIMIT:** Restringe el número de filas devueltas.
    ```sql
    SELECT * FROM users LIMIT 5;
    ```

## Task 7: Operators (Operadores)

Permiten realizar comparaciones y lógica en la cláusula `WHERE`.
- **Comparación:** `=`, `>`, `<`, `>=`, `<=`, `!=` (o `<>`).
- **Lógicos:**
    - `AND`: Ambas condiciones deben ser verdaderas.
    - `OR`: Al menos una condición debe ser verdadera.
    - `NOT`: Niega una condición.
- **LIKE:** Búsqueda de patrones (con `%` como comodín).
    ```sql
    SELECT * FROM users WHERE username LIKE 'a%'; -- Empieza con 'a'
    ```
- **UNION:** Combina los resultados de dos consultas `SELECT`. **Crucial para SQL Injection**.
    - Reglas: Mismo número de columnas y tipos de datos compatibles.
    ```sql
    SELECT name FROM products UNION SELECT username FROM users;
    ```

## Task 8: Functions (Funciones)

SQL tiene funciones integradas para manipular datos.
- **String Functions:**
    - `CONCAT(str1, str2)`: Une cadenas.
    - `SUBSTRING(str, start, length)`: Extrae parte de una cadena.
- **Aggregate Functions:**
    - `COUNT(*)`: Cuenta el número de filas.
    - `SUM(columna)`: Suma valores numéricos.
    - `MIN(columna)` / `MAX(columna)`: Valor mínimo o máximo.
    ```sql
    SELECT COUNT(*) FROM users;
    ```

## Task 9: Conclusion

Has aprendido los fundamentos de SQL: estructura de BD, CRUD, cláusulas, operadores y funciones. Estos conocimientos son la base para detectar y explotar vulnerabilidades de inyección SQL, donde un atacante manipula estas consultas para acceder a datos no autorizados.
