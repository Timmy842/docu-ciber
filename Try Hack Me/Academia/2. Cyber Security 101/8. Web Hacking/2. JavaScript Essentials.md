# TryHackMe: JavaScript Essentials

Este documento es un resumen detallado de la sala "JavaScript Essentials" de TryHackMe. Cubre los fundamentos de JavaScript, desde su sintaxis básica hasta cómo manipular el flujo de control y analizar código minificado, habilidades esenciales para el hacking web (XSS, análisis de código fuente).

## Task 1: Introduction (Introducción)

JavaScript (JS) es uno de los lenguajes más populares del mundo y el motor de la interactividad en la web.
- Mientras HTML da la estructura y CSS el estilo, **JavaScript aporta la lógica y el dinamismo**.
- Se ejecuta en el lado del cliente (navegador), lo que significa que el código es visible y modificable por el usuario.

## Task 2: Essential Concepts (Conceptos Esenciales)

### Variables
Son contenedores para almacenar datos.
- `let`: Para variables cuyo valor puede cambiar.
- `const`: Para valores constantes que no deben reasignarse.
- `var`: Forma antigua (evitar por problemas de alcance/scope).

### Tipos de Datos
- **String:** Texto (`"Hola"`).
- **Number:** Números (`42`, `3.14`).
- **Boolean:** Lógica (`true`, `false`).
- **Array:** Listas ordenadas (`["user", "admin"]`).
- **Object:** Colecciones clave-valor (`{id: 1, role: "admin"}`).

### Operadores
- **Aritméticos:** `+`, `-`, `*`, `/`.
- **Comparación:** `==` (igual valor), `===` (igual valor y tipo), `!=` (no igual).
- **Lógicos:** `&&` (AND), `||` (OR), `!` (NOT).

## Task 3: JavaScript Overview (Visión General)

El código JS se puede incluir en una página web de tres formas:
1.  **Inline:** Dentro de etiquetas HTML (ej. `<button onclick="alert('Hola')">`). No recomendado.
2.  **Internal:** Dentro de etiquetas `<script>...</script>` en el HTML.
3.  **External:** En un archivo separado `.js` vinculado con `<script src="archivo.js"></script>`.

## Task 4: Integrating JavaScript in HTML

Para interactuar con la página, JS utiliza el **DOM (Document Object Model)**, que es una representación en árbol de la estructura HTML.

**Métodos comunes:**
- `document.getElementById('id')`: Selecciona un elemento por su ID.
- `document.querySelector('.clase')`: Selecciona el primer elemento que coincida con el selector CSS.
- `element.innerHTML`: Lee o modifica el contenido HTML interno de un elemento.
- `element.style.property`: Modifica el estilo CSS (ej. `color`, `display`).

## Task 5: Abusing Dialogue Functions (Funciones de Diálogo)

JS tiene funciones integradas para interactuar con el usuario mediante pop-ups. Son útiles para debugging pero también vectores comunes de XSS (Cross-Site Scripting).

- `alert("Mensaje")`: Muestra una alerta con un botón de Aceptar.
- `prompt("Pregunta")`: Pide al usuario que ingrese texto.
- `confirm("¿Seguro?")`: Pide confirmación (Aceptar/Cancelar) y devuelve `true` o `false`.

## Task 6: Bypassing Control Flow Statements (Control de Flujo)

El control de flujo permite tomar decisiones en el código.

### Condicionales (If/Else)
```javascript
if (password === "admin123") {
    login();
} else {
    error();
}
```
**Vulnerabilidad:** Como JS corre en el cliente, un atacante puede manipular las variables o usar el depurador del navegador para saltarse estas comprobaciones.

### Bucles (Loops)
- **For Loop:** Se repite un número específico de veces.
- **While Loop:** Se repite mientras una condición sea verdadera.

## Task 7: Exploring Minified Files (Archivos Minificados)

En producción, el código JS suele estar **minificado** para reducir el tamaño del archivo y mejorar la velocidad de carga.
- **Minificación:** Elimina espacios, saltos de línea y comentarios, y acorta nombres de variables (ej. `function calcularTotal()` -> `function a()`).
- **Problema:** Hace el código ilegible para humanos.

### Cómo analizar código minificado (De-minify / Beautify)
Para entender qué hace un script minificado (y buscar vulnerabilidades o lógica oculta):
1.  **Browser DevTools (F12):**
    - Pestaña **Sources** (Chrome) o **Debugger** (Firefox).
    - Selecciona el archivo `.js`.
    - Haz clic en el icono **`{}` (Pretty Print)**. Esto reformatea el código automáticamente.
2.  **Herramientas Online:** [Beautifier.io](https://beautifier.io/), [JSNice](http://jsnice.org/).
3.  **Editores:** Plugins como "Prettier" en VS Code.

## Task 8: Best Practices (Buenas Prácticas)

- **Validación en el Servidor:** Nunca confíes solo en la validación del lado del cliente (JS), ya que es fácilmente manipulable.
- **Evitar `eval()`:** Esta función ejecuta texto como código y es un riesgo masivo de seguridad.
- **Uso de `const` y `let`:** Evita `var` para prevenir errores de alcance.

## Task 9: Conclusion

JavaScript es poderoso pero introduce riesgos si la lógica de seguridad se implementa solo en el cliente. Como atacante, tu objetivo es leer, entender y manipular este código para eludir controles.
