# REMnux: Getting Started

Este módulo es una introducción práctica a **REMnux**, una distribución de Linux especializada en ingeniería inversa y análisis de malware. Proporciona un entorno "sandbox" seguro con herramientas preinstaladas para diseccionar software malicioso sin arriesgar el sistema principal.

## Task 1: Introduction (Introducción)

**¿Qué es REMnux?**
Es una distribución de Linux (basada en Ubuntu) mantenida por Lenny Zeltser. Actúa como un laboratorio "todo en uno" para analistas de malware.
- **Herramientas incluidas:** Volatility, YARA, Wireshark, oledump, INetSim, entre muchas otras.
- **Objetivo:** Analizar malware de forma estática y dinámica en un entorno controlado.

## Task 2: Machine Access (Acceso a la Máquina)

## Task 3: File Analysis (Análisis de Archivos)

Esta tarea se centra en el análisis estático de documentos maliciosos (Office) utilizando la herramienta `oledump.py`.

**Herramienta: oledump.py**
- Es un script en Python para analizar archivos OLE2 (Structured Storage), formato usado por documentos de Microsoft Office (Word, Excel) para incrustar macros y otros objetos.
- **Comandos clave:**
    - `oledump.py <archivo>`: Lista los "streams" (flujos de datos) del archivo.
    - `M`: Si aparece una "M" mayúscula junto a un stream, indica que contiene una Macro (VBA).
    - `-s <número>`: Selecciona un stream específico para analizar.
    - `--vbadecompress`: Descomprime el código VBA ofuscado para hacerlo legible.

**Caso de Estudio (AgentTesla):**
1.  Se identifica un stream con macro.
2.  Al descomprimirlo, se encuentra código ofuscado.
3.  Se revela un script de PowerShell que usa `Invoke-WebRequest` para descargar un ejecutable (`.exe`) desde una IP y guardarlo en una carpeta temporal.

**Ejemplo de análisis de `possible_malicious.docx`:**
- Se escanea el archivo para ver cuántos streams tiene.
- Se identifica el número del stream que contiene la macro maliciosa.

## Task 4: Fake Network to Aid Analysis (Red Falsa para Análisis)

Para el análisis dinámico, es crucial observar cómo el malware intenta comunicarse con el exterior (C2 servers) sin dejar que realmente salga a internet.

**Herramienta: INetSim**
- Simula servicios de internet comunes (DNS, HTTP, HTTPS, SMTP, FTP, etc.) en la máquina local.
- Engaña al malware haciéndole creer que está conectado a internet y que los servidores que busca están disponibles.
- **Configuración:** Archivo `/etc/inetsim/inetsim.conf` (e.g., configurar `dns_default_ip` a la IP de REMnux).
- **Ejecución:** `sudo inetsim`.
- **Logs:** Los reportes de conexión se guardan en `/var/log/inetsim/report/`. Aquí se puede ver qué URLs solicitó el malware y qué método usó (GET, POST).

**Ejercicio:**
- Simular una descarga de `flag.txt` usando `wget` contra la IP de INetSim y analizar el reporte generado para ver el método HTTP usado.

## Task 5: Memory Investigation: Evidence Preprocessing (Investigación de Memoria)

Introducción al análisis forense de memoria RAM utilizando **Volatility 3**.

**Herramienta: Volatility 3**
- Framework para extracción de artefactos digitales de muestras de memoria volátil (RAM dumps).
- **Plugins comunes mencionados:**
    - `windows.pstree.PsTree`: Lista procesos en forma de árbol (padre-hijo).
    - `windows.pslist.PsList`: Lista todos los procesos activos.
    - `windows.malfind.Malfind`: Busca código inyectado en procesos (técnica común de malware).
    - `windows.dlllist.DllList`: Lista las DLLs cargadas por un proceso.
    - `linux.strings` (comando `strings` de Linux): Extrae cadenas de texto legibles (ASCII/Unicode) de un archivo binario o dump.

**Automatización:**
- Se muestra cómo usar bucles en bash para ejecutar múltiples plugins de Volatility secuencialmente y guardar la salida en archivos de texto para su posterior análisis ("Preprocessing").

**Caso de Estudio (WannaCry - wcry.mem):**
- Identificar procesos sospechosos con código inyectado (`csrss.exe`, `winlogon.exe`).
- Localizar la ruta de binarios maliciosos (e.g., `@WanaDecryptor@.exe`).

## Task 6: Conclusion (Conclusión)

REMnux es una herramienta indispensable que centraliza utilidades de análisis estático (oledump), dinámico (INetSim) y forense (Volatility), permitiendo a los analistas diseccionar amenazas de manera eficiente y segura.
