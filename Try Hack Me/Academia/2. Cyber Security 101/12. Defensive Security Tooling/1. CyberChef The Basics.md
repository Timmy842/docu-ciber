# CyberChef: The Basics

Este módulo introduce **CyberChef**, una herramienta web versátil conocida como la "Navaja Suiza" para analistas de seguridad, desarrolladores y entusiastas de la tecnología. Permite realizar operaciones de codificación, decodificación, compresión, análisis y extracción de datos de manera sencilla y visual.

Enlace a la room: [TryHackMe | CyberChef: The Basics](https://tryhackme.com/room/cyberchefbasics)

---

## Task 1: Introduction (Introducción)

**¿Qué es CyberChef?**
Es una aplicación web simple e intuitiva desarrollada por GCHQ (Government Communications Headquarters del Reino Unido). Está diseñada para ayudar con diversas tareas de "ciber operaciones" directamente en el navegador.

- **Funcionalidad:** Permite manipular datos mediante una serie de operaciones encadenadas (llamadas "Recetas" o *Recipes*).
- **Usos comunes:**
  - Decodificación de Base64, Hex, URL, etc.
  - Descompresión de archivos.
  - Extracción de direcciones IP, correos electrónicos y URLs.
  - Cifrado y descifrado (AES, DES, RSA, etc.).
  - Análisis de archivos y formatos.

## Task 2: Accessing The Tool (Accediendo a la Herramienta)

Existen dos formas principales de utilizar CyberChef:

1.  **Online:** A través del navegador web en [https://gchq.github.io/CyberChef/](https://gchq.github.io/CyberChef/). Es la forma más rápida y no requiere instalación.
2.  **Offline (Local):** Descargando la última versión desde el repositorio de GitHub. Se descarga un archivo HTML que puede ejecutarse localmente sin conexión a internet. Esto es útil para entornos seguros o sin acceso a la red.

## Task 3: Navigating the Interface (Navegando por la Interfaz)

La interfaz de CyberChef se divide en cuatro áreas principales:

1.  **Operations (Operaciones):**
    - Panel izquierdo. Contiene todas las herramientas disponibles categorizadas (e.g., *Encryption*, *Encoding*, *Data Format*, *Networking*).
    - Incluye una barra de búsqueda para encontrar operaciones rápidamente.
    - Al pasar el ratón sobre una operación, muestra una descripción de lo que hace.

2.  **Recipe (Receta):**
    - Panel central. Es el "corazón" de la herramienta.
    - Aquí se arrastran y sueltan las operaciones desde el panel izquierdo.
    - Las operaciones se ejecutan en orden secuencial (de arriba a abajo). La salida de la primera operación se convierte en la entrada de la segunda, y así sucesivamente.
    - Permite configurar los parámetros de cada operación.

3.  **Input (Entrada):**
    - Panel superior derecho. Donde se pega o carga el texto/archivo que se desea procesar.
    - Soporta arrastrar y soltar archivos.

4.  **Output (Salida):**
    - Panel inferior derecho. Muestra el resultado final del procesamiento de la receta.
    - El resultado se actualiza automáticamente si la opción "Auto Bake" está activada (por defecto).

## Task 4: Before Anything Else (Antes de Empezar)

Antes de usar la herramienta, se sugiere seguir un proceso de pensamiento de 4 pasos:

1.  **Objetivo:** ¿Qué quiero lograr? (e.g., "Tengo una cadena extraña y quiero ver si es un mensaje oculto").
2.  **Input:** Introducir los datos en el panel de entrada.
3.  **Operaciones:** Seleccionar las operaciones basándose en el análisis inicial (e.g., si parece Base64, usar "From Base64").
4.  **Output:** Verificar si el resultado tiene sentido. Si no, ajustar la receta y repetir.

## Task 5: Practice, Practice, Practice (Práctica)

Esta tarea explora categorías comunes de operaciones:

### 1. Extractors (Extractores)
Utilizan expresiones regulares (Regex) para encontrar patrones específicos dentro de un texto grande.
- **Extract IP addresses:** Encuentra direcciones IPv4 e IPv6.
- **Extract URLs:** Encuentra enlaces web (HTTP, FTP, etc.).
- **Extract email addresses:** Encuentra direcciones de correo electrónico.

### 2. Date and Time (Fecha y Hora)
Operaciones para convertir formatos de tiempo.
- **From UNIX Timestamp:** Convierte un timestamp UNIX (segundos desde el 1 de enero de 1970) a una fecha legible.
- **To UNIX Timestamp:** Convierte una fecha legible a formato UNIX.

### 3. Data Format (Formato de Datos)
Operaciones para codificar y decodificar datos.
- **Base64:**
  - Codificación muy común que usa 64 caracteres (A-Z, a-z, 0-9, +, /) y '=' como relleno (padding).
  - **Conversión Manual:** La tarea explica cómo convertir texto a Base64 manualmente:
    1. Convertir caracteres ASCII a binario (8 bits).
    2. Concatenar los bits.
    3. Dividir en grupos de 6 bits.
    4. Convertir cada grupo de 6 bits a decimal.
    5. Mapear el decimal a la tabla de índice Base64.
- **URL Encode/Decode:** Convierte caracteres especiales en formato `%HH` (e.g., espacio es `%20`, `/` es `%2F`) para que sean seguros en URLs.
- **Otras Bases:**
  - **Base85:** Más eficiente que Base64.
  - **Base58:** Similar a Base64 pero elimina caracteres confusos (0, O, I, l). Usado en Bitcoin.
  - **Base62:** Solo alfanumérico (A-Z, a-z, 0-9).

## Task 6: Your First Official Cook (Tu Primera Receta Oficial)

Ejercicios prácticos utilizando un archivo descargable.

**Ejemplos de soluciones a las preguntas planteadas:**
1.  **IP que empieza y termina con "10":**
    - Usar `Extract IP addresses`.
    - Resultado: `10.10.2.101`.
2.  **Base64 de "Nice Room!":**
    - Input: `Nice Room!` -> Operación: `To Base64`.
    - Resultado: `TmljZSBSb29tIQ==`.
3.  **URL Decode:**
    - Input: `https%3A%2F%2Ftryhackme%2Ecom%2Fr%2Froom%2Fcyberchefbasics` -> Operación: `URL Decode`.
    - Resultado: `https://tryhackme.com/r/room/cyberchefbasics`.
4.  **UNIX Timestamp a Fecha:**
    - Input: `1725151258` -> Operación: `From UNIX Timestamp`.
    - Resultado: `Sun 1 September 2024 00:40:58 UTC`.
5.  **Base85 Decode:**
    - Input: `<+oue+DGm>Ap%u7` -> Operación: `From Base85`.
    - Resultado: `This is fun!`.

## Task 7: Conclusion (Conclusión)

CyberChef es una herramienta esencial para el análisis rápido de datos. Su capacidad de combinar múltiples operaciones en una receta permite automatizar tareas complejas de decodificación y extracción sin necesidad de escribir scripts personalizados.
