# FlareVM: Arsenal of Tools

Este módulo presenta **FlareVM**, una distribución de Windows personalizada y mantenida por el equipo FLARE de Mandiant (ahora Google Cloud). Está diseñada específicamente para ingeniería inversa, análisis de malware, respuesta a incidentes y análisis forense.

## Task 1: Introduction (Introducción)

**¿Qué es FlareVM?**
Es una colección curada de herramientas especializadas instaladas sobre Windows. A diferencia de REMnux (que es Linux), FlareVM proporciona un entorno nativo para analizar malware de Windows en su propio sistema operativo.
- **Público objetivo:** Ingenieros inversos, analistas de malware, forenses y pentesters.
- **Objetivo:** Facilitar la disección de binarios, entender el comportamiento del malware y recuperar evidencia digital.

## Task 2: Arsenal of Tools (Arsenal de Herramientas)

FlareVM agrupa sus herramientas en varias categorías clave. Aquí se detallan las más importantes:

### 1. Reverse Engineering & Debugging
Desarmar el software para entender cómo funciona.
- **x64dbg:** Debugger de código abierto para binarios de 32 y 64 bits. Esencial para análisis dinámico paso a paso.
- **Ghidra:** Suite de ingeniería inversa de la NSA (desensamblador y decompilador).
- **OllyDbg:** Debugger clásico para ensamblador (nivel bajo).
- **Radare2:** Framework de ingeniería inversa por línea de comandos.

### 2. Disassemblers & Decompilers
Traducir código máquina a un formato legible.
- **CFF Explorer:** Editor de archivos PE (Portable Executable). Permite ver y editar cabeceras, secciones y dependencias.
- **RetDec:** Decompilador de código máquina a código fuente (e.g., C).

### 3. Static & Dynamic Analysis
- **Process Hacker:** Visor de procesos avanzado y editor de memoria. Permite ver hilos, módulos y manipular procesos en ejecución.
- **PEview:** Visor de estructura de archivos PE.
- **Dependency Walker:** Muestra las DLLs que necesita un ejecutable.
- **DIE (Detect It Easy):** Detecta si un archivo está empaquetado (packed), cifrado o con qué compilador fue creado.

### 4. Forensics & Incident Response
- **Volatility:** Framework para análisis de memoria RAM.
- **FTK Imager:** Herramienta para crear y analizar imágenes de disco forenses.

### 5. Network Analysis
- **Wireshark:** Analizador de protocolos de red (captura de paquetes).
- **Nmap:** Escáner de redes y puertos.

### 6. File Analysis (Hex Editors)
- **HxD:** Editor hexadecimal rápido y eficiente. Permite ver los bytes crudos de un archivo.
- **FileInsight:** Editor de binarios con capacidades de scripting.

### 7. Sysinternals Suite
Herramientas avanzadas de Microsoft para monitoreo y diagnóstico.
- **Procmon (Process Monitor):** Monitorea en tiempo real el sistema de archivos, registro y actividad de procesos/hilos.
- **Process Explorer:** Muestra información detallada sobre los procesos en ejecución (árbol de procesos, DLLs cargadas, handles abiertos).
- **Autoruns:** Muestra qué programas están configurados para iniciarse automáticamente al arrancar el sistema.

## Task 3: Commonly Used Tools for Investigation: Overview (Herramientas Comunes)

Esta tarea profundiza en herramientas específicas para el triaje inicial:

- **FLOSS (FLARE Obfuscated String Solver):** Herramienta que extrae cadenas de texto (strings) de ejecutables, pero con la capacidad de desofuscar strings que el malware intenta ocultar. (Antes conocido como FireEye Labs Obfuscated String Solver).
- **PEStudio:** Herramienta de análisis estático "todo en uno". Muestra hashes, entropía, imports, exports, recursos y strings sospechosos sin ejecutar el archivo.
    - *Tip:* Un valor alto de entropía suele indicar que el archivo está empaquetado o cifrado.

**Ejercicios Prácticos:**
- Usar **PEStudio** para obtener el hash SHA256 de `cryptominer.bin` y contar sus funciones importadas.
- Usar **CFF Explorer** para verificar la firma de un archivo o su `e_magic` value (cabecera DOS, `5A4D` o "MZ").

## Task 4: Analyzing Malicious Files (Analizando Archivos Maliciosos)

Aplicación práctica de las herramientas en un escenario de análisis.

**Análisis Estático (windows.exe):**
1.  **PEStudio:** Se identifican indicadores sospechosos:
    - Metadatos falsos (dice ser "Windows Registry Editor" pero está en una ruta extraña).
    - Texto en ruso en los recursos.
    - Ausencia de "Rich Header" (indica posible packing).
    - Imports sospechosos: `CryptoStream`, `RijndaelManaged` (cifrado), `set_UseShellExecute`.
2.  **FLOSS:** Se extraen strings que confirman las funciones de cifrado y ejecución detectadas por PEStudio.

**Análisis Dinámico (cobaltstrike.exe):**
1.  **Process Explorer:** Se ejecuta el malware y se busca en el árbol de procesos. Se revisan sus propiedades TCP/IP para ver conexiones de red activas.
2.  **Procmon:** Se usa para capturar eventos del sistema (creación de archivos, modificaciones de registro) generados por el malware en tiempo real.

## Task 5: Conclusion (Conclusión)

FlareVM proporciona un arsenal completo para enfrentar amenazas en entornos Windows. La combinación de herramientas de análisis estático (PEStudio, FLOSS, CFF Explorer) y dinámico (x64dbg, Procmon, Process Explorer) permite a los analistas obtener una comprensión profunda de cualquier binario sospechoso.
