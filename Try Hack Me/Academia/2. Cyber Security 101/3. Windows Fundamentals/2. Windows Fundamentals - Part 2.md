# 🏁 Windows Fundamentals - Part 2

Esta sala se enfoca en las herramientas administrativas avanzadas que permiten configurar, monitorear y gestionar el comportamiento interno de Windows.

---

## 1. Configuración del Sistema (msconfig) y Opciones Avanzadas
### Configuración del Sistema (msconfig)
La utilidad "Configuración del sistema" requiere permisos de Administrador local y se orienta a **diagnosticar problemas de arranque**. Posee cinco pestañas clave:

- **General:** Permite elegir el tipo de inicio de Windows (Normal, Diagnóstico o Selectivo).
- **Arranque (Boot):** Define las opciones de arranque del sistema operativo.
- **Servicios (Services):** Despliega una lista completa de los servicios configurados en el equipo, tanto en ejecución como detenidos (útil para detectar demonios ocultos).
- **Inicio (Startup):** MSConfig ya *no gestiona* los programas de inicio en sistemas de cliente modernos (te derivará al Administrador de tareas). 
  - *Nota sobre Windows Server:* En servidores, el Administrador de tareas carece de pestaña de inicio. Para ver estas aplicaciones, se debe presionar `Win + R` y ejecutar `shell:startup`. Mostrará de forma fiable los ejecutables que se activan al iniciar sesión en el servidor.
- **Herramientas (Tools):** Ofrece accesos directos y los comandos exactos utilizados para ejecutar otras herramientas avanzadas de administración (visor de eventos, monitor de rendimiento, etc.).

### Configuración Avanzada del Sistema (Advanced System Settings)
Buscando en Inicio "Ver la configuración avanzada del sistema", abrimos las funciones vitales para administrar los fallos y el comportamiento a nivel núcleo.

- **Opciones de Rendimiento y Archivo de Paginación (Paging File):** 
  Desde *Opciones Avanzadas > Rendimiento > Configuración*, se puede gestionar el archivo de paginación o memoria virtual. Windows utiliza este archivo en el disco duro para mitigar cuelgues o ralentizaciones cuando la memoria RAM física se llena por completo. Permite definir sobre qué unidad asentar este archivo, su tamaño inicial, o el tamaño máximo (en MB).

- **Inicio y Recuperación (Crash Dumps):**
  Desde *Opciones Avanzadas > Inicio y recuperación > Configuración*. En ocasiones donde el núcleo sufre un error crítico irrecuperable (Pantallazo Azul de la Muerte o BSOD), Windows almacena un **archivo de volcado del fallo (crash dump file)**. Estos volcados son cruciales para que los analistas diagnostiquen por qué colapsó el sistema operativo. Windows puede generar volcados completos, pequeños (de 256 KB), de memoria automática, o del núcleo (Kernel).

### Cambiar la Configuración del UAC (Change UAC Settings)
Siguiendo con las herramientas disponibles dentro del panel de *Configuración del Sistema*, se puede ajustar el comportamiento del **Control de Cuentas de Usuario (UAC)**, el cual actúa alertándote cuando se intentan realizar cambios a nivel de sistema.

Esta configuración tiene un control deslizante (slider) con **cuatro niveles de seguridad** principales:
1. **Notificarme siempre (Always notify):** El nivel de seguridad más alto. Windows te avisa ante cualquier intento de cambio (tuyo o de aplicaciones) y la pantalla se oscurece protegiendo el escritorio (Escritorio Seguro).
2. **Notificarme solamente cuando una aplicación intente realizar cambios:** Windows solo alerta cuando *aplicaciones externas* intentan hacer cambios, no cuando tú mismo modificas las configuraciones de Windows. La pantalla también se oscurece. **(Opción habilitada por defecto)**.
3. **Notificarme sin oscurecer (Notify without dimming):** Igual que la anterior, pero la pantalla del escritorio no se oscurece/atenúa al mostrar el aviso.
4. **No notificarme nunca (Never notify):** Las notificaciones de seguridad están totalmente apagadas, dejando el equipo completamente expuesto a cambios silenciosos de malware. *(No recomendado)*.

## 2. Administración de Equipos (Computer Management)
La **Administración de equipos** es una utilidad del sistema (`compmgmt.msc`) que agrupa diversas herramientas en una única consola. Actúa como una verdadera "navaja suiza" dividida en tres secciones principales:

### 2.1 Herramientas del Sistema (System Tools)
- **Programador de tareas (Task Scheduler):** Permite crear y gestionar tareas automatizadas (ejecutar aplicaciones, scripts, etc.) que ocurren bajo ciertos desencadenantes (iniciar o cerrar sesión) o programadas a una hora/frecuencia exacta (ej. cada cinco minutos). Las tareas pueden ser recurrentes o de "una sola vez". En la *Biblioteca del Programador de tareas* se listan todas las configuraciones actuales.
- **Visor de eventos (Event Viewer):** Crea un rastro de auditoría crucial para diagnosticar problemas e investigar actividades en el equipo. Clasifica los sucesos en 5 niveles (Error, Advertencia, Información, Auditoría de éxito y Auditoría de error). Los registros estándar se dividen en Aplicación, Seguridad, Instalación y Sistema.
- **Carpetas compartidas (Shared Folders):** Lista los recursos y carpetas en red a los que otros pueden conectarse (como los administrativos ocultos `C$` o `ADMIN$`). Desde aquí puedes auditar directamente **quién** está conectado al equipo (*Sesiones*) y **qué** ficheros concretos tiene abiertos en uso (*Archivos abiertos*).
- **Usuarios y grupos locales (lusrmgr.msc):** Interfaz para la gestión integral de cuentas y grupos (vista en la Parte 1).
- **Rendimiento (Performance Monitor / perfmon):** Se utiliza para analizar datos de rendimiento del sistema en tiempo real o procedentes de un archivo de registro. Es la herramienta por excelencia para mitigar "cuellos de botella" y problemas de lentitud de forma local o remota.
- **Administrador de dispositivos (Device Manager):** Permite ver, modificar e incluso deshabilitar intencionadamente cualquier componente de hardware físico conectado.

### 2.2 Almacenamiento (Storage)
- **Administración de discos (Disk Management):** Una utilidad indispensable para realizar tareas avanzadas sobre el disco duro. Permite inicializar/preparar una nueva unidad de almacenamiento, extender o asilar (encoger) particiones, formatear, y asignar a tu voluntad las letras de la unidad (por ejemplo, cambiar D: a E:). *(En algunas versiones de Windows Server incluye funciones extendidas)*.

### 2.3 Servicios y Aplicaciones (Services and Applications)
- **Servicios:** Como vimos, las aplicaciones especiales en segundo plano del sistema operativo. Su estado se visualiza rápido desde la lista. Si haces clic derecho para abrir sus **Propiedades**, encontrarás su nombre interno, la ruta exacta del ejecutable (`.exe`) responsable, y un control importantísimo: el **Tipo de inicio**. Puede ser *Automático* (arranca con encender la PC), *Manual* (arranca solo si otro proceso/usuario lo pide) o *Deshabilitado*.
- **Control WMI:** Permite configurar y controlar el Instrumental de Administración de Windows (WMI). El protocolo WMI posibilita que lenguajes de scripting (como VBScript o PowerShell) modifiquen PCs remotamente y administren configuraciones. *(Nota: La antigua línea de comandos `WMIC` está obsoleta (deprecated) desde Windows 10 21H1; actualmente se sustituye de lleno por el uso avanzado de PowerShell)*.

## 3. Monitor de Recursos e Información del Sistema
Herramientas avanzadas para cuando el Administrador de Tareas se queda corto.

### 3.1 Monitor de Recursos (Resource Monitor / `resmon`)
El **Monitor de Recursos** es una utilidad orientada a usuarios avanzados para analizar minuciosamente qué ocurre bajo el capó de Windows. A diferencia del Administrador de tareas habitual, muestra información súper detallada (separada por procesos o de forma agregada) del uso de **CPU, Memoria, Disco y Red**.

- **Análisis avanzado:** Identifica qué proceso exacto está utilizando qué "handles" (identificadores) de archivos o módulos específicos en segundo plano.
- **Filtrado y Control:** Permite marcar módulos para aislar sus datos (ej. seguir solo la red de un proceso), así como detener, iniciar o pausar **servicios** desde la misma interfaz.
- **Resolución de conflictos (Deadlocks):** Destaca porque ayuda a detectar "procesos interbloqueados" o conflictos de archivos bloqueados, permitiendo que el administrador pueda intentar resolver el problema sin tener que matar forzosamente el programa (y perder datos sin guardar).

La consola se organiza en una pestaña principal de *Visión General* (Overview) y cuatro pestañas adicionales (CPU, Memoria, Disco, Red). A la derecha de la ventana, independientemente de la pestaña, se muestran siempre gráficos dinámicos en **tiempo real** de cada componente para detectar picos anómalos al instante.

### 3.2 Información del Sistema (System Information / `msinfo32.exe`)
Microsoft incluye esta herramienta para recopilar y mostrar un inventario profundo del hardware, los componentes y el entorno de software del equipo. Es vital para diagnosticar problemas (es de solo lectura, no permite realizar cambios directos). Se divide en tres categorías principales:

1. **Resumen del sistema (System Summary):** Es la pantalla inicial. Muestra especificaciones técnicas generales (versión de Windows, placa base, modelo del procesador, cantidad de RAM).
2. **Recursos de Hardware (Hardware Resources):** Información altamente técnica y avanzada sobre asignaciones como DMAs, E/S o interrupciones de hardware.
3. **Componentes (Components):** Datos específicos de los dispositivos de hardware internos y externos físicos instalados (como adaptadores de Pantalla, Red, Sonido o dispositivos de Entrada).
4. **Entorno de Software (Software Environment):** Registra el software y drivers integrados en el núcleo, programas instalados, conexiones de red y las imprescindibles **Variables de Entorno**.

> [!INFO] Variables de Entorno y Búsqueda
> Como se introdujo en la Parte 1, las variables de entorno almacenan rutas y datos vitales para que otros programas sepan dónde instalar componentes o cómo comportarse (ej. la variable de sistema `%WINDIR%`).
> - También se pueden consultar o modificar desde las **Opciones avanzadas** que vimos en el *Panel de Control > Sistema*.
> - Al final de la herramienta `msinfo32` encontrarás una práctica **barra de búsqueda** para encontrar rápidamente parámetros específicos (por ejemplo buscar `Dirección IP` dentro de *Componentes*).

## 4. Event Viewer (Visor de Eventos) 🕵️‍♂️
Crucial para la seguridad y el diagnóstico de errores. Registra "Eventos" en archivos `.evtx`.

### Categorías principales de logs:
1. **Application:** Eventos registrados por aplicaciones instaladas.
2. **Security:** Intentos de inicio de sesión, cambios en permisos (Auditoría).
3. **System:** Errores de drivers, fallos de hardware o actualizaciones del sistema.

> [!INFO] Event IDs
> Cada evento tiene un ID único. Por ejemplo, el **Event ID 4624** indica un inicio de sesión exitoso. En ciberseguridad, estos IDs son el "rastro de migas" que seguimos.

## 5. El Registro de Windows (Registry Editor)
El **Registro de Windows** (según Microsoft) es una inmensa base de datos central en formato jerárquico, utilizada para almacenar absolutamente toda la información necesaria para configurar el sistema para uno o varios usuarios, aplicaciones y dispositivos. La herramienta gráfica fundamental para verlo y editarlo se llama **Editor del Registro** (`regedit`).

Durante su funcionamiento regular, Windows consulta continuamente este registro y sus claves para saber:
- Los **Perfiles** y parámetros de cada usuario del sistema.
- Qué **aplicaciones** están instaladas en el equipo y qué tipo de documentos puede crear/abrir cada una de ellas (asociaciones).
- Las configuraciones subyacentes de las "hojas de propiedades" de las carpetas y los iconos de aplicaciones.
- Qué **hardware periférico e interno** existe en el sistema.
- Qué **puertos** están siendo utilizados.

### Sus 5 Raíces Principales (Hives):
- **HKEY_CLASSES_ROOT (HKCR):** Asociaciones de extensiones de archivos (qué app abre qué formato).
- **HKEY_CURRENT_USER (HKCU):** Configuración específica del usuario activo.
- **HKEY_LOCAL_MACHINE (HKLM):** Configuración global del núcleo, todo el sistema y hardware.
- **HKEY_USERS (HKU):** Perfiles y configuraciones base de todos los usuarios del equipo.
- **HKEY_CURRENT_CONFIG (HKCC):** Perfil de hardware exacto cargado en el arranque actual.

> [!WARNING] Precaución: Solo nivel avanzado
> El registro es el corazón del SO y está destinado exclusivamente a administradores y usuarios avanzados. Modificar, agregar o eliminar valores sin un conocimiento preciso puede afectar las operaciones normales del ordenador e incluso dejarlo totalmente inoperativo.

## 6. Símbolo del Sistema (Command Prompt / CMD)
Aunque la Interfaz Gráfica (GUI) domina en la actualidad por su facilidad de uso al hacer clics, la consola tradicional o **Símbolo del sistema (`cmd`)** sigue siendo una herramienta vital y rápida para obtener información y diagnosticar la red del equipo.

A continuación, algunos de los comandos fundamentales explorados en este módulo:

### Información Básica
- `hostname`: Devuelve el nombre del equipo en la red.
- `whoami`: Muestra el nombre exacto del usuario local o de dominio que tiene la sesión iniciada (muy útil para saber bajo qué contexto y privilegios estás operando).
- `cls`: Limpia todo el texto de la pantalla de la terminal.

### Diagnóstico de Red
- `ipconfig`: Muestra toda la configuración local de las direcciones de red (como IP, Máscara y Puerta de enlace) del adaptador.
- `netstat`: Muestra estadísticas de protocolo de red y las **conexiones TCP/IP activas actuales**. Permite multitud de parámetros adicionales agregando modificadores como `-a`, `-b` o `-e` para variar la salida u obtener métricas detalladas.

### Gestión de Recursos (Comando `net`)
El comando transversal `net` se usa exclusivamente en combinación con múltiples **sub-comandos** para administrar recursos de red. Algunos sub-comandos sumamente útiles en ciberseguridad son: `user`, `localgroup`, `use`, `share` y `session`.

> [!TIP] Consultar manuales y sintaxis (Ayuda)
> Casi cualquier comando tiene un manual de ayuda integrado para entender la sintaxis esperada y qué parámetros admite.
> - Para comandos estándar, simplemente añade `/?` al final (Ejemplo: `ipconfig /?` o `netstat /?`).
> - Para el comando **net**, la sintaxis universal `/?` no te servirá en sus sub-comandos. Allí deberás usar explícitamente la palabra `help`. (Ejemplo: `net help user` o `net help localgroup`).

## 7. Conclusión y Atajos
A lo largo de este módulo, muchas de las utilidades exploradas son exactamente aquellas que, tradicionalmente, se pueden lanzar y descubrir desde la pestaña **Herramientas (Tools)** de `msconfig` (Configuración del sistema). 

Al ir compartiendo los comandos directos y atajos a lo largo del documento, hemos comprobado que **no es necesario** abrir `msconfig` primero para poder ejecutar estas potentes utilidades.

**Vías de acceso alternativas:**
1. **Atajos (Ejecutar / Win+R):** La forma más veloz y directa para administradores.
2. **Menú de Inicio:** También puedes buscar o localizar todas estas herramientas navegando por el Menú de Inicio en carpetas nativas como *Herramientas de Windows* o *Sistema de Windows*.

*(Nota: Las utilidades listadas en MSConfig que no se mencionaron aquí, o bien se cubrieron en los Fundamentos 1, o quedan sugeridas para tu propia investigación).*

## 💡 Notas de Laboratorio y Comandos (Win+R)

> [!TIP] Ejecutar como Administrador
> Muchas de estas herramientas (como Regedit o Disk Management) exigen obligatoriamente privilegios elevados. Si algo no aparece, está bloqueado o da error de acceso denegado, verifica que abriste la herramienta o consola usando **"Ejecutar como Administrador"**.

### Cheatsheet de atajos comunes:
- `msconfig`: Configuración del sistema.
- `compmgmt.msc`: Administración de equipos (Navaja suiza).
- `eventvwr.msc`: Visor de eventos (Logs).
- `regedit`: Editor del Registro.
- `diskmgmt.msc`: Administración de discos nativa.
- `resmon`: Monitor de Recursos avanzado.
- `msinfo32`: Información del Sistema.
- `lusrmgr.msc`: Usuarios y grupos locales.
