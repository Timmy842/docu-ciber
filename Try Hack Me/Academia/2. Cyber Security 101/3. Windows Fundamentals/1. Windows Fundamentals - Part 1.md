# 🏁 Windows Fundamentals - Part 1

Este módulo introduce los conceptos básicos del sistema operativo Windows, su interfaz gráfica (GUI), la gestión de archivos y las herramientas de configuración esenciales.

---

## 1. Introducción a Windows
Windows es un sistema operativo de **código cerrado** desarrollado por Microsoft. A diferencia de Linux, donde la terminal es la reina, Windows está diseñado para ser operado principalmente a través de su **GUI (Graphical User Interface)**.

### Ediciones Comunes:
- **Windows Home:** Para usuarios domésticos (faltan funciones como RDP o BitLocker).
- **Windows Pro:** Para profesionales y pequeñas empresas (incluye gestión de dominios).
- **Windows Enterprise:** Para grandes corporaciones (seguridad avanzada).
- **Windows Server:** Optimizado para servicios de red y servidores.

---

## 2. El Escritorio de Windows (Windows Desktop)
El **Escritorio de Windows (GUI)** es la pantalla principal a la que se accede tras pasar la pantalla de **Inicio de sesión**, donde se introducen las credenciales del usuario (cuenta local o de entorno de dominio/Active Directory).

Componentes principales de la interfaz:

- **El Escritorio (Desktop):** Área principal para ubicar accesos directos a programas, carpetas y archivos para un acceso rápido.
  - **Clic derecho:** Abre un menú contextual para organizar iconos, crear nuevos elementos, acceder a la **Configuración de pantalla** (resolución, monitores) o **Personalizar** (fondo de pantalla, temas, colores).
- **El Menú de Inicio (Start Menu):** Accesible desde el logotipo de Windows, permite acceder a aplicaciones, archivos y configuraciones. Se divide en:
  1. **Accesos de cuenta y energía:** Atajos para la cuenta de usuario, cerrar sesión, Documentos, Imágenes, **Configuración** y opciones de Inicio/Apagado.
  2. **Lista de aplicaciones:** Aplicaciones instaladas (ordenadas alfabéticamente) y las añadidas recientemente.
  3. **Baldosas (Tiles):** Sección derecha con iconos de aplicaciones y utilidades. Haciendo clic derecho se pueden redimensionar, **Anclar a Inicio** o ver sus propiedades.
- **La Barra de tareas (Taskbar):** Muestra los programas, carpetas y archivos actualmente abiertos. Al pasar el cursor por encima ofrece una vista previa en miniatura. Permite anclar programas y gestionar componentes como la Búsqueda (Cortana) o la Vista de tareas (Task View) mediante clic derecho.
- **El Área de notificación (Notification Area):** Situada en la zona inferior derecha, muestra la fecha, la hora e iconos de estado del sistema (volumen, red, etc.). Se puede personalizar en la configuración de la Barra de tareas.

> [!TIP] Menú Contextual
> Puedes hacer clic derecho en cualquier carpeta, archivo, aplicación o icono de la interfaz para ver más información o realizar acciones adicionales sobre el elemento.

## 3. Explorador de Archivos (File Explorer)
Es la herramienta principal para gestionar datos. A diferencia de Linux (`/`), Windows utiliza **Letras de Unidad**.

### Estructura de Directorios Crítica:
- `C:\`: La unidad principal (Root).
- `C:\Windows`: Archivos del sistema operativo.
- `C:\Program Files` y `C:\Program Files (x86)`: Donde se instalan las aplicaciones.
- `C:\Users`: Contiene los perfiles de usuario (Escritorio, Documentos, Descargas).
- `C:\Users\<Usuario>\AppData`: Carpeta oculta donde las aplicaciones guardan configuraciones específicas del usuario.

> [!TIP] Archivos Ocultos
> En el Explorador de Archivos, ve a la pestaña **Vista** y marca **Elementos ocultos** para ver archivos críticos que suelen estar protegidos o escondidos.

### El Sistema de Archivos: NTFS vs FAT
El sistema de archivos utilizado en las versiones modernas de Windows es **NTFS (New Technology File System)**. Aunque sistemas anteriores como FAT16/FAT32 y HPFS existieron (y FAT se sigue usando en tarjetas MicroSD o memorias USB), NTFS es el estándar para discos duros y servidores Windows.

**Ventajas y características principales de NTFS:**
- **Registro por diario (Journaling):** En caso de fallo o caída del sistema, NTFS puede reparar automáticamente carpetas y archivos utilizando la información guardada en un archivo de registro (algo imposible con el sistema FAT).
- Soporta archivos de más de 4 GB.
- Permite establecer **Permisos** específicos en archivos y carpetas.
- Soporta **compresión** de carpetas y archivos.
- Soporta cifrado (mediante **EFS - Sistema de archivos de cifrado**).

*(Para comprobar qué sistema de archivos usas, asegúrate de estar en "Este equipo", haz clic derecho en la unidad, típicamente `C:\`, y selecciona **Propiedades**).*

### Permisos NTFS (Pestaña Seguridad)
En volúmenes NTFS, puedes conceder o denegar el acceso a carpetas y archivos. Los permisos en la interfaz de Windows son los siguientes:
- **Control total**
- **Modificar**
- **Lectura y ejecución**
- **Mostrar el contenido de la carpeta**
- **Lectura**
- **Escritura**

**¿Cómo ver los permisos de un archivo o carpeta?**
1. Haz clic derecho sobre el archivo o carpeta que deseas revisar.
2. En el menú contextual, selecciona **Propiedades**.
3. En la ventana de Propiedades, haz clic en la pestaña **Seguridad**.
4. En la lista **Nombres de grupos o usuarios**, selecciona el usuario, equipo o grupo cuyos permisos deseas ver en la sección inferior.

### Flujos de y Datos Alternativos (ADS - Alternate Data Streams)
Los Flujos de datos alternativos (ADS) son un atributo de archivo específico de NTFS en Windows. Todo archivo cuenta con al menos un flujo de datos principal (`$DATA`), y la función ADS permite que los archivos contengan múltiples flujos adicionales ocultos.

- El **Explorador de archivos** de Windows de forma nativa no muestra los ADS al usuario. Existen ejecutables de terceros y métodos en **PowerShell** que permiten visualizar estos datos ocultos.
- **Uso en Seguridad:** Desde una perspectiva de ciberseguridad, los desarrolladores de malware y atacantes suelen aprovechar los ADS para esconder datos e información maliciosa en el equipo.
- **Usos legítimos:** No todos los usos son malos. Por ejemplo, al descargar un archivo de Internet, Windows escribe un identificador oculto en un flujo ADS (conocido como *Zone.Identifier*) que indica al sistema que ese archivo proviene de la web para añadir protecciones de advertencia.

## 4. Las Carpetas Windows y System32
La carpeta **Windows** (típicamente `C:\Windows`) es conocida tradicionalmente como el directorio que contiene el sistema operativo Windows. Sin embargo, no tiene por qué residir obligatoriamente en la unidad C o llamarse así. 

Aquí entran en juego las **variables de entorno**, específicamente las variables del sistema como `%windir%`, que apuntan directamente al directorio de Windows. Según Microsoft, "las variables de entorno almacenan información sobre el entorno del sistema operativo", lo cual incluye detalles como "la ruta del sistema operativo, el número de procesadores utilizados o la ubicación de las carpetas temporales".

Dentro de la carpeta `Windows` se encuentran múltiples subcarpetas, y una de las más críticas es **System32**:
- Contiene los archivos importantes y componentes esenciales para el correcto funcionamiento del sistema operativo.
- **Precaución extrema:** Eliminar accidentalmente archivos o carpetas dentro de `System32` puede inutilizar por completo el sistema operativo Windows.
- *Nota:* Muchas de las herramientas que se exploran en esta serie de fundamentos de Windows residen dentro de esta carpeta.

## 5. Cuentas de Usuario, Perfiles y Permisos
En un sistema local de Windows, las cuentas de usuario suelen ser principalmente de dos tipos:
- **Administrador:** Tiene el control total del equipo. Puede realizar cambios en todo el sistema, como instalar programas, añadir o eliminar usuarios, modificar grupos y editar configuraciones globales.
- **Usuario Estándar:** Tiene permisos limitados. Solo puede realizar cambios en los archivos y carpetas que le pertenecen, y no tiene autorización para realizar modificaciones a nivel de sistema.

**Gestión Básica de Usuarios (Configuración)**
Si accedes al **Menú de Inicio** y buscas "Otros usuarios" (*Configuración > Cuentas > Otros usuarios*), podrás ver las opciones de gestión. 
- *Solo los administradores* verán la opción de **Agregar a otra persona a este equipo**, así como los botones de **Quitar** o **Cambiar el tipo de cuenta** (por ejemplo, para promover un usuario estándar a administrador).

**Perfiles de Usuario**
Cuando se crea una cuenta y el usuario inicia sesión por primera vez en el sistema local, el **Servicio de perfiles de usuario** genera un entorno de trabajo personalizado.
- La ruta predeterminada de este perfil será `C:\Users\<Nombre_Usuario>`.
- Todos los perfiles recién creados contienen una misma estructura de carpetas: Escritorio, Documentos, Descargas, Música, Imágenes, etc.

**Gestión Avanzada: Usuarios y Grupos Locales (`lusrmgr.msc`)**
Para una administración más profunda, se puede utilizar el cuadro de diálogo **Ejecutar** (`Windows + R`) y escribir el comando `lusrmgr.msc`. Esto abrirá una consola con dos carpetas principales:
- **Usuarios:** Permite administrar las cuentas locales.
- **Grupos:** Enumera todos los grupos locales del sistema junto con una breve descripción.
  - El sistema asigna **permisos o privilegios específicos** a cada grupo.
  - El administrador es el responsable de asignar a los usuarios a uno o más grupos. Cuando esto ocurre, el usuario **hereda automáticamente todos los permisos** asignados a dicho grupo.

## 6. Control de Cuentas de Usuario (UAC) 🛡️
La mayoría de los usuarios domésticos inician sesión utilizando cuentas de tipo **Administrador local**. Aunque es más cómodo, operar siempre con altos privilegios incrementa el riesgo de compromiso del sistema; si entra algún malware, este se ejecutará con el mismo nivel de permisos del usuario conectado (es decir, como administrador).

Para proteger a los usuarios con privilegios administrativos, Microsoft introdujo el **Control de Cuentas de Usuario (UAC)**, originado desde Windows Vista.
*(Nota: De forma predeterminada, el UAC no se aplica a la cuenta de Administrador integrada oculta o "Built-in Administrator").*

**¿Cómo funciona el UAC?**
Incluso si el usuario tiene una cuenta de tipo Administrador, su sesión en curso *no* se ejecuta continuamente con privilegios elevados. Cuando el usuario requiere ejecutar una operación que necesita privilegios superiores (como instalar programas o modificar el registro), el UAC salta a la pantalla y muestra una **ventana de aviso o confirmación**.

**El Escudo del UAC y Usuarios Estándar**
- **Usuario Estándar:** Si este tipo de usuario intenta ejecutar un instalador o un proceso restringido, notará que el icono de la aplicación tiene un pequeño **escudo**. 
- Al hacer doble clic sobre un programa con este escudo, el UAC emergente requerirá obligatoriamente que se introduzca un **nombre de usuario y contraseña de Administrador** para poder continuar. Si las credenciales no se facilitan a tiempo, la ventana de UAC desaparece y el programa no se instala ni ejecuta.

Esta característica está diseñada con el propósito principal de reducir drásticamente las probabilidades de que un malware comprometa silenciosamente tu equipo.

## 7. Configuración (Settings) y el Panel de Control
En un sistema Windows moderno, las dos ubicaciones principales para realizar modificaciones son el menú de **Configuración** y el **Panel de Control**. Ambas herramientas se pueden encontrar fácilmente desde el Menú de Inicio.

- **Configuración (Settings):** Introducida originalmente en Windows 8 para pantallas táctiles, hoy en día (en Windows 10 y posteriores) es la principal herramienta moderna e interactiva a la que debes acudir cuando buscas personalizar o ajustar elementos habituales del sistema operativo.
- **Panel de Control:** Ha sido históricamente el lugar predeterminado para hacer cambios en el sistema (por ejemplo, agregar impresoras o herramientas avanzadas). Sigue estando presente y es donde se alojan los ajustes y operaciones algos más complejos.
  - *Ejemplo de uso:* Para consultar, auditar y desinstalar el software legítimo añadido (nombre, editor y versión), debes acceder al Panel de Control > **Programas > Programas y características**.

**Transición y colaboración de ambos menús**
Actualmente, los menús están interconectados y Windows todavía se encuentra en una transición. A veces inicias un ajuste en *Configuración* (como *Red e Internet > Cambiar opciones del adaptador*) y descubrirás que se despliega una ventana del veterano *Panel de Control*.

> [!TIP] Usa el buscador
> Si en algún momento no tienes claro si una opción reside en *Configuración* o en el *Panel de Control*, lo más directo es usar la barra de **Búsqueda del Menú de Inicio** (por ejemplo, buscar "fondo de pantalla"). Windows buscará en la base de datos y te dirigirá a la herramienta correcta.

## 8. Administrador de Tareas (Task Manager)
El último tema crucial de estos fundamentos básicos es el **Administrador de tareas**.

Esta herramienta nos proporciona un panel informativo sobre las **aplicaciones y procesos** que se están ejecutando actualmente en segundo plano y en primer plano en todo el sistema. Además, nos brinda datos clave sobre el **Rendimiento** (Performance) del equipo, permitiéndonos observar en tiempo real el porcentaje de uso de CPU, memoria RAM, disco y red.

**Cómo acceder y expandir la herramienta:**
1. Puedes abrirlo rápidamente haciendo **clic derecho en una zona vacía de la Barra de tareas** y seleccionando "Administrador de tareas". *(O mediante el clásico atajo `Ctrl + Shift + Esc`).*
2. Por defecto, puede que se abra en una **"Vista simplificada"** (Simple View) que apenas muestra los programas básicos en ejecución sin estadísticas.
3. Para revelar todo su potencial analítico, debes hacer clic en el botón inferior que dice **"Más detalles"** (More details). Al hacerlo, la interfaz cambiará para mostrar todas sus pestañas avanzadas.

## 💡 Notas Adicionales y Resumen (Tips)

Para concluir esta primera parte de los Fundamentos de Windows, quédate con estos puntos vitales desde la perspectiva de un administrador y de ciberseguridad:

> [!TIP] El poder del Clic Derecho
> En la interfaz de Windows, el menú contextual (clic derecho) es tu mejor amigo. Si necesitas saber quién instaló algo, revisar permisos, cambiar configuraciones de pantalla o acceder a herramientas avanzadas, todo comienza haciendo clic derecho sobre el elemento y yendo a **Propiedades**.

> [!IMPORTANT] NTFS y los permisos son la Ley
> A diferencia de Linux, aquí rige NTFS. Si un usuario no puede hacer algo o un proceso falla, el 90% de las veces se debe a que no cuenta con los **Permisos de Seguridad** adecuados, o a restricciones heredadas del Grupo al que pertenece.

> [!WARNING] Cuidado con lo que no ves
> En Windows existen elementos críticos invisibles a simple vista formados por diseño. Desde el vital y peligroso directorio **System32**, los archivos protegidos/ocultos del sistema, hasta los flujos de datos alternativos (**ADS**) nativos de NTFS que el malware utiliza frecuentemente para esconder su rastro.

> [!TIP] Ante la duda, usa el Buscador
> Microsoft sigue en una transición eterna entre el viejo **Panel de Control** y el moderno menú de **Configuración**. Si no encuentras una opción de administración, no navegues a ciegas: abre el Menú de Inicio y simplemente teclea lo que buscas para que Windows te redirija.
