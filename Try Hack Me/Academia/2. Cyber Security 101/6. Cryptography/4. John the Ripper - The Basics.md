# TryHackMe: John the Ripper - The Basics

Este documento es un resumen detallado y estructurado de la sala "John the Ripper: The Basics" de TryHackMe. John the Ripper (JtR) es una de las herramientas de craqueo de contraseñas más populares y versátiles, capaz de detectar automáticamente cientos de tipos de hashes.

## Task 1: Introduction (Introducción)

John the Ripper es una herramienta de código abierto diseñada para auditar la seguridad de contraseñas y realizar ataques de fuerza bruta o diccionario contra hashes.
- **Versión Community (Jumbo):** Es la versión que se suele usar en pentesting (y la que viene en Kali/Parrot), ya que soporta muchos más formatos de hash que la versión "core".
- **Objetivo:** Recuperar la contraseña en texto plano a partir de un hash, probando millones de combinaciones hasta encontrar una coincidencia.

## Task 2: Basic Terms (Términos Básicos)

Antes de empezar, es crucial entender cómo funcionan los ataques de JtR:

1.  **Wordlists (Diccionarios):** Archivos de texto que contienen miles o millones de contraseñas comunes. JtR prueba cada una de ellas contra el hash.
    - La más famosa es **RockYou**: `/usr/share/wordlists/rockyou.txt`.
2.  **Hashes:** La representación cifrada (unidireccional) de una contraseña.
3.  **Salts:** Valores aleatorios añadidos a la contraseña antes de hashearla para evitar ataques de Rainbow Tables. JtR maneja sales automáticamente si el formato lo soporta.

## Task 3: Setting Up Your System

Si usas Kali Linux o la AttackBox de THM, JtR ya está instalado.
- **Verificar instalación:** `john` (debería mostrar la ayuda).
- **Identificar Hash:** Antes de usar John, a veces necesitas saber qué tipo de hash tienes. Herramientas útiles:
    - [Hash Identifier](https://gitlab.com/kalilinux/packages/hash-identifier)
    - [TunnelsUp Hash Analyzer](https://www.tunnelsup.com/hash-analyzer/)

## Task 4: Cracking Basic Hashes (MD5, SHA, etc.)

El comando básico para crackear un hash cuando tienes un diccionario es:

```bash
john --format=[formato] --wordlist=[ruta_diccionario] [archivo_hash]
```

### Ejemplo con MD5
Supongamos que tienes un archivo `hash1.txt` con un hash MD5:
1.  **Identificar:** `hash-identifier` te dice que es MD5.
2.  **Crackear:**
    ```bash
    john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt hash1.txt
    ```
3.  **Ver resultado:** JtR mostrará la contraseña en pantalla. Si ya la ha crackeado antes, no la mostrará de nuevo. Para verla:
    ```bash
    john --show --format=raw-md5 hash1.txt
    ```

> **Nota:** `--format` es opcional si John puede detectar el hash automáticamente, pero especificarlo hace el proceso mucho más rápido.

## Task 5: Cracking Windows Authentication Hashes (NTLM)

Windows almacena las contraseñas de usuario en formato **NTLM** (New Technology LAN Manager) en la base de datos SAM.
- **Formato en JtR:** `nt`
- **Comando:**
    ```bash
    john --format=nt --wordlist=/usr/share/wordlists/rockyou.txt ntlm_hash.txt
    ```

## Task 6: Cracking /etc/shadow Hashes (Linux)

En Linux, las contraseñas hasheadas (generalmente SHA-512 con salt) están en `/etc/shadow`, y la información de usuarios en `/etc/passwd`. John necesita combinar ambos archivos para realizar el ataque correctamente (para usar el salt y el nombre de usuario).

### Pasos:
1.  **Unshadow:** Usar la utilidad `unshadow` para combinar los archivos.
    ```bash
    unshadow passwd.txt shadow.txt > unshadowed.txt
    ```
2.  **Crackear:**
    ```bash
    john --wordlist=/usr/share/wordlists/rockyou.txt unshadowed.txt
    ```
    *(John detectará automáticamente `sha512crypt`)*.

## Task 7: Single Crack Mode (Modo "Single")

Este modo es ideal cuando **no tienes un diccionario** o quieres probar variaciones del nombre de usuario.
- **¿Qué hace?** Genera contraseñas candidatas basándose en la información del usuario (campo GECOS en `/etc/passwd`).
- **Ejemplo:** Si el usuario es "Joker", probará: `Joker1`, `Joker!`, `rekoJ`, `J0ker`, etc.
- **Requisito:** El formato de entrada debe incluir el nombre de usuario (ej: `usuario:hash` o formato unshadowed).

```bash
john --single --format=[formato] [archivo]
```

## Task 8: Custom Rules (Reglas Personalizadas)

John permite definir reglas complejas en su archivo de configuración (`john.conf` o `john.ini`) para modificar las palabras del diccionario.
- **Ejemplo:** "Añadir un número al final", "Poner en mayúsculas", "Reemplazar a por @".
- Esto es avanzado, pero muy potente para generar diccionarios dinámicos.

## Task 9 & 10: Cracking Archives (ZIP / RAR)

John no puede crackear directamente un archivo `.zip` o `.rar`. Primero debemos **extraer el hash** del archivo a un formato de texto que John entienda. Para esto usamos las herramientas `*2john`.

### ZIP Files
1.  **Extraer Hash:**
    ```bash
    zip2john archivo_protegido.zip > zip_hash.txt
    ```
2.  **Crackear:**
    ```bash
    john --wordlist=/usr/share/wordlists/rockyou.txt zip_hash.txt
    ```

### RAR Files
1.  **Extraer Hash:**
    ```bash
    rar2john archivo_protegido.rar > rar_hash.txt
    ```
2.  **Crackear:**
    ```bash
    john --wordlist=/usr/share/wordlists/rockyou.txt rar_hash.txt
    ```

## Task 11: Cracking SSH Keys

Si obtienes una clave privada SSH (`id_rsa`) que está protegida por una frase de contraseña (passphrase), no podrás usarla para loguearte hasta que averigües esa frase.

1.  **Convertir a Hash:** Usamos `ssh2john.py` (script en Python incluido con JtR).
    ```bash
    python3 /usr/share/john/ssh2john.py id_rsa > ssh_hash.txt
    # O simplemente si está en el PATH:
    ssh2john id_rsa > ssh_hash.txt
    ```
2.  **Crackear la Passphrase:**
    ```bash
    john --wordlist=/usr/share/wordlists/rockyou.txt ssh_hash.txt
    ```

## Cheatsheet de Comandos Comunes

| Acción | Comando |
| :--- | :--- |
| **Crackear con diccionario** | `john --wordlist=/usr/share/wordlists/rockyou.txt [archivo]` |
| **Especificar formato** | `john --format=[formato] [archivo]` |
| **Ver contraseñas (Show)** | `john --show [archivo]` |
| **Listar formatos** | `john --list=formats` |
| **Unshadow (Linux)** | `unshadow [passwd] [shadow] > [salida]` |
| **ZIP a Hash** | `zip2john [zip] > [hash]` |
| **RAR a Hash** | `rar2john [rar] > [hash]` |
| **SSH a Hash** | `ssh2john [key] > [hash]` |

### Formatos Útiles (`--format=`)
*   `raw-md5`
*   `raw-sha1`
*   `raw-sha256`
*   `nt` (Windows)
*   `sha512crypt` (Linux /etc/shadow)
*   `crypt` (Linux antiguo)
