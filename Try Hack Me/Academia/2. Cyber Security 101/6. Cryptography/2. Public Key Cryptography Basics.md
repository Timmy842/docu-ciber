# TryHackMe: Public Key Cryptography Basics

Este documento resume los conceptos clave y tareas de la sala "Public Key Cryptography Basics" de TryHackMe. La criptografía de clave pública (asimétrica) es fundamental para la seguridad moderna, permitiendo autenticación, integridad y confidencialidad sin necesidad de compartir una clave secreta previamente.

## Task 1: Introduction (Introducción)

La criptografía asimétrica utiliza un par de claves matemáticamente relacionadas:
- **Clave Pública (Public Key):** Se puede compartir libremente.
- **Clave Privada (Private Key):** Debe mantenerse en secreto absoluto.

A diferencia de la criptografía simétrica (donde se usa la misma clave para cifrar y descifrar), la asimétrica permite:
1. **Confidencialidad:** Cualquiera puede cifrar con la clave pública, pero solo el dueño de la privada puede descifrar.
2. **Autenticidad e Integridad (Firmas Digitales):** El dueño firma con su clave privada, y cualquiera puede verificar la firma con la pública.

## Task 2: Common Use of Asymmetric Encryption (Uso Común)

El uso más extendido de la criptografía asimétrica no es cifrar grandes cantidades de datos (ya que es computacionalmente costosa y lenta), sino **intercambiar claves simétricas**.

### El proceso híbrido:
1. **Negociación:** Se usa criptografía asimétrica para establecer un canal seguro o intercambiar una "clave de sesión" (simétrica).
2. **Comunicación:** Una vez compartida la clave de sesión, se usa criptografía simétrica (como AES) para cifrar los datos reales, ya que es mucho más rápida.

### Analogía del Candado y la Llave:
- La **Clave Pública** es como un **candado abierto**. Puedes enviárselo a cualquiera.
- Cualquiera puede meter un mensaje en una caja y cerrarla con ese candado (cifrar).
- Solo tú, que tienes la **Clave Privada (la llave)**, puedes abrir el candado y leer el mensaje (descifrar).

## Task 3: RSA (Rivest–Shamir–Adleman)

RSA es uno de los primeros y más utilizados sistemas de criptografía de clave pública. Su seguridad se basa en la dificultad de factorizar el producto de dos números primos grandes.

### Variables Clave en RSA:
- **$p$ y $q$:** Dos números primos grandes y secretos.
- **$n$ (Módulo):** El producto de $p \times q$. Parte de la clave pública.
- **$\phi(n)$ (Función Totiente de Euler):** Calculada como $(p-1)(q-1)$. Esencial para generar las claves.
- **$e$ (Exponente Público):** Usualmente un número pequeño (comúnmente 65537). Parte de la clave pública.
- **$d$ (Exponente Privado):** Calculado a partir de $e$ y $\phi(n)$. Es la clave privada.

### Fórmulas Básicas:
- **Cifrado:** $C = M^e \pmod n$
- **Descifrado:** $M = C^d \pmod n$

> **Nota:** La seguridad de RSA depende de que sea computacionalmente inviable obtener $d$ a partir de $n$ y $e$, lo cual requiere factorizar $n$ en $p$ y $q$.

## Task 4: Diffie-Hellman Key Exchange (Intercambio de Claves DH)

Diffie-Hellman no se usa para cifrar mensajes, sino para **acordar una clave secreta compartida** a través de un canal inseguro.

### Funcionamiento Simplificado:
1. **Parámetros Públicos:** Se acuerdan un número primo $p$ y una base $g$.
2. **Claves Privadas:**
   - Alice genera un secreto $a$.
   - Bob genera un secreto $b$.
3. **Valores Públicos (Intercambio):**
   - Alice calcula $A = g^a \pmod p$ y se lo envía a Bob.
   - Bob calcula $B = g^b \pmod p$ y se lo envía a Alice.
4. **Cálculo del Secreto Compartido ($S$):**
   - Alice calcula $S = B^a \pmod p$.
   - Bob calcula $S = A^b \pmod p$.
   - Matemáticamente, $B^a \equiv (g^b)^a \equiv g^{ab} \equiv (g^a)^b \equiv A^b \pmod p$.

Ambos obtienen el mismo valor $S$ sin haberlo transmitido nunca por la red. Este valor $S$ se usa entonces como clave para cifrado simétrico.

## Task 5: SSH (Secure Shell)

SSH utiliza criptografía asimétrica para autenticar usuarios en servidores remotos de forma segura, reemplazando a Telnet y rlogin.

### Componentes:
- **`id_rsa` (Clave Privada):** Se guarda en la máquina del cliente (`~/.ssh/id_rsa`). ¡Nunca debe compartirse!
- **`id_rsa.pub` (Clave Pública):** Se copia al servidor, en el archivo `~/.ssh/authorized_keys`.

### Proceso de Conexión:
1. El cliente le dice al servidor "Quiero entrar como usuario X".
2. El servidor busca la clave pública de X y envía un desafío cifrado con ella.
3. El cliente descifra el desafío con su clave privada y responde.
4. Si la respuesta es correcta, el servidor permite el acceso.

> **Importante:** Las claves privadas SSH a menudo se protegen con una "passphrase" (frase de contraseña) para añadir una capa extra de seguridad si el archivo es robado.

## Task 6: Digital Signatures and Certificates (Firmas Digitales y Certificados)

### Firmas Digitales
Invierten el uso de las claves para probar autenticidad e integridad.
- **Firmar:** Se usa la **Clave Privada** sobre un hash del mensaje.
- **Verificar:** Cualquiera usa la **Clave Pública** del remitente para confirmar que el hash coincide.
- Garantiza que el mensaje vino de quien dice ser (Autenticidad) y no fue modificado (Integridad).

### Certificados Digitales (X.509)
Un problema de la clave pública es la confianza: "¿Cómo sé que esta clave pública realmente pertenece a mi banco y no a un atacante?".
- **Certificado:** Un archivo que vincula una clave pública a una identidad (dominio web, organización, persona).
- **CA (Certificate Authority):** Una entidad de confianza (como Let's Encrypt, DigiCert) que firma digitalmente el certificado, avalando su legitimidad.
- **Cadena de Confianza:** Tu navegador confía en la CA, la CA confía en el certificado del sitio web -> Tú confías en el sitio web.

> **Let's Encrypt** es una CA que proporciona certificados TLS/SSL gratuitos y automatizados para habilitar HTTPS en sitios web.

## Task 7: PGP and GPG (Pretty Good Privacy)

Herramientas para cifrar y firmar correos electrónicos, archivos y directorios.

- **PGP:** El protocolo original (propietario inicialmente).
- **GPG (GNU Privacy Guard):** Implementación libre y de código abierto del estándar OpenPGP.

### Comandos Comunes de GPG:
- **Importar claves:** `gpg --import clave.asc`
- **Listar claves:** `gpg --list-keys` o `gpg --list-secret-keys`
- **Cifrar un archivo:** `gpg --recipient "Bob" --encrypt archivo.txt` (Usa la pública de Bob).
- **Descifrar un archivo:** `gpg --decrypt archivo.gpg` (Usa tu privada).

## Task 8: Conclusion

La criptografía de clave pública es un pilar de la ciberseguridad.
- **RSA y Elliptic Curve (ECC):** Algoritmos principales.
- **Usos:** Intercambio de claves (DH), Autenticación (SSH), Web segura (HTTPS/TLS), Correo seguro (PGP).
- **Seguridad:** Depende de proteger la clave privada y de la robustez de los algoritmos matemáticos frente a la capacidad de cómputo actual.
