# 🐧 Linux Fundamentals - Part 2

Esta segunda parte se centra en la gestión de archivos, permisos de usuario, comandos comunes para la administración del sistema y la jerarquía de directorios avanzada.

---

## 1. Introducción y Acceso
A diferencia de la parte 1, aquí se profundiza en cómo interactuar con el sistema de forma más eficiente y cómo manejar la seguridad básica (permisos).

### Comandos de Ayuda
Antes de ejecutar comandos desconocidos, Linux ofrece manuales internos:
- `man <comando>`: Abre el manual completo del comando (ej. `man ls`).
- `<comando> --help`: Muestra una guía rápida de opciones en la misma terminal.

---

## 2. Gestión de Archivos y Directorios
Comandos esenciales para organizar el sistema de archivos:

| Comando | Descripción | Ejemplo |
| :--- | :--- | :--- |
| `touch` | Crea un archivo vacío. | `touch nota.txt` |
| `mkdir` | Crea un nuevo directorio. | `mkdir notas_hacking` |
| `cp` | Copia archivos o directorios. | `cp archivo.txt copia.txt` |
| `mv` | Mueve o **renombra** archivos/directorios. | `mv viejo.txt nuevo.txt` |
| `rm` | Elimina archivos. | `rm basura.txt` |
| `rm -r` | Elimina directorios y su contenido (recursivo). | `rm -r carpeta_vieja/` |

## 3. Permisos de Archivos (Crucial) 🔐
Linux es un sistema multiusuario, por lo que los permisos son fundamentales. Al hacer `ls -l`, verás algo como:
`-rwxrw-r--`

### Estructura de los permisos:
1. **Tipo de archivo:** `-` (archivo) o `d` (directorio).
2. **Owner (Dueño):** Los primeros 3 caracteres (`rwx`).
3. **Group (Grupo):** Los siguientes 3 caracteres (`rw-`).
4. **Others (Otros):** Los últimos 3 caracteres (`r--`).

### Significado de las letras:
- `r` (Read): Leer.
- `w` (Write): Escribir/Modificar.
- `x` (Execute): Ejecutar (en carpetas permite entrar en ellas).

### Modificación de permisos (`chmod`):
Se puede usar el **modo octal** (números):
- **4**: Read
- **2**: Write
- **1**: Execute

> [!EXAMPLE] Ejemplo de chmod
> - `chmod 777 archivo`: Todos pueden hacer todo (Peligroso).
> - `chmod 644 archivo`: Dueño (rw), Grupo (r), Otros (r).
> - `chmod +x script.sh`: Da permiso de ejecución a todos.

### Cambio de dueño (`chown`):
- `chown usuario:grupo archivo`: Cambia quién es el dueño del archivo.

## 4. Usuarios y Privilegios
### Cambio de Usuario
- `su <usuario>`: (Switch User) Cambia a otro usuario (pide la contraseña de ese usuario).
- `sudo`: (SuperUser Do) Ejecuta un comando con privilegios de **root** (pide tu propia contraseña).

### Identificación
- `id`: Muestra tu UID (User ID) y los grupos a los que perteneces.
- `groups`: Muestra solo los grupos.

---

## 5. La Jerarquía de Directorios (FHS)
Entender dónde están las cosas es vital:

- `/bin` & `/sbin`: Binarios esenciales del sistema (comandos básicos).
- `/boot`: Archivos necesarios para el arranque de Linux.
- `/dev`: Archivos de dispositivos (hardware representado como archivos).
- `/etc`: **Archivos de configuración** del sistema (aquí están las claves, redes, etc.).
- `/home`: Carpetas personales de los usuarios.
- `/root`: El "home" del administrador (root).
- `/tmp`: Archivos temporales (se borran al reiniciar).
- `/var/log`: Archivos de registro del sistema (logs).

---

## 6. Operadores de Redirección (Repaso Avanzado)
- `>` : Sobrescribe un archivo con la salida de un comando.
- `>>` : Añade la salida al final de un archivo sin borrar lo anterior.
- `|` (Pipe): Pasa la salida de un comando como entrada al siguiente.
	- *Ejemplo:* `cat lista.txt | grep "objetivo"`

---

## 7. Notas de Interés para Pentesting
> [!TIP] Permisos SUID
> Si ves una `s` en lugar de una `x` en los permisos del dueño (ej: `-rwsr-xr-x`), significa que el archivo tiene el bit **SUID** activado. Esto permite que cualquier usuario ejecute ese archivo con los privilegios del dueño (normalmente root). Es un vector común para escalada de privilegios.

> [!INFO] Usuarios del sistema
> No todos los usuarios son personas. Servicios como `www-data` (servidor web) tienen sus propios usuarios limitados por seguridad.
