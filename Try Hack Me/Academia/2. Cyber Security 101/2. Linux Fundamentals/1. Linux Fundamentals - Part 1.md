# 🐧 Linux Fundamentals - Part 1

Este resumen cubre los conceptos básicos del sistema operativo Linux, su historia, estructura de archivos y los comandos esenciales para la navegación y manipulación de datos desde la terminal.

---

## 1. Introducción y Contexto
Linux es un sistema operativo de **código abierto (Open Source)**, lo que significa que cualquiera puede ver, modificar y distribuir su código fuente. Fue creado por **Linus Torvalds** en 1991.

### Características Principales:
- **Versatilidad:** Se usa en servidores, smartphones (Android), dispositivos IoT y supercomputadoras.
- **Distribuciones (Distros):** Son versiones personalizadas del núcleo Linux con diferentes herramientas.
	- *Ejemplos:* Ubuntu, Debian, Kali Linux, Fedora, CentOS.

---

## 2. Interacción con el Sistema
En Linux, la interacción principal (especialmente en ciberseguridad) se realiza a través de la **Terminal** (o Shell).

- **SSH (Secure Shell):** Protocolo para conectarse de forma remota y segura a una máquina Linux.
	- `ssh usuario@IP_del_servidor`

---

## 3. Comandos Básicos de Identidad
Estos comandos permiten saber quién eres y dónde estás en el sistema.

| Comando | Descripción |
| :--- | :--- |
| `whoami` | Muestra el nombre del usuario con el que has iniciado sesión. |
| `id` | Proporciona el ID de usuario (UID) y el ID de grupo (GID). |
| `hostname` | Muestra el nombre de la máquina en la que estás trabajando. |

---

## 4. Navegación del Sistema de Archivos
Linux organiza todo en un árbol jerárquico que comienza desde la raíz `/`.

### Comandos de Movimiento:
- `pwd` (Print Working Directory): Muestra la ruta completa del directorio actual.
- `ls`: Lista los archivos y carpetas del directorio actual.
	- `ls -a`: Muestra archivos ocultos (los que empiezan con punto `.`).
	- `ls -l`: Muestra detalles (permisos, tamaño, fecha).
- `cd` (Change Directory): Cambia de carpeta.
	- `cd ..`: Sube un nivel (directorio padre).
	- `cd ~`: Va al directorio *home* del usuario actual.

---

## 5. Manipulación de Archivos y Lectura
Comandos para interactuar con el contenido de los archivos.

- `cat`: Muestra todo el contenido de un archivo en la terminal.
- `echo`: Imprime un texto o variable en la terminal.
	- Ejemplo: `echo "Hola mundo"`

---

## 6. Búsqueda de Archivos y Texto
Herramientas cruciales para encontrar información o "flags" en auditorías.

### El comando `find`
Busca archivos basándose en nombres, permisos, tamaños, etc.
- `find . -name nombre_archivo`: Busca en el directorio actual (`.`) por nombre.
- `find / -type d -name "config"`: Busca directorios llamados "config" desde la raíz.

### El comando `grep`
Busca patrones de texto dentro de archivos.
- `grep "texto_a_buscar" archivo.txt`
- `ls /etc | grep "passwd"`: Lista archivos en /etc y filtra los que contienen "passwd".

---

## 7. Operadores de la Shell
Permiten encadenar comandos o redirigir entradas y salidas.

| Operador | Función |
| :--- | :--- |
| `&` | Ejecuta el comando en **segundo plano** (background). |
| `&&` | Ejecuta el segundo comando **solo si** el primero tuvo éxito. |
| `>` | **Redirige** la salida a un archivo (sobrescribe el contenido). |
| `>>` | **Añade** la salida al final de un archivo (sin borrar lo anterior). |

---

## 8. Resumen de Directorios Importantes en Linux
- `/`: La raíz del sistema.
- `/etc`: Archivos de configuración del sistema.
- `/var`: Datos variables, como archivos de registro (logs) de servicios.
- `/home`: Carpetas personales de los usuarios.
- `/tmp`: Archivos temporales (se suelen borrar al reiniciar).
- `/bin` y `/usr/bin`: Donde residen los ejecutables de los comandos.
