# 🐧 Linux Fundamentals - Part 3

Esta sección final aborda cómo editar archivos en la terminal, descargar contenido de la red, gestionar procesos del sistema, automatizar tareas mediante Cron y revisar logs para mantenimiento o forense básico.

---

## 1. Editores de Texto en la Terminal
Cuando no hay interfaz gráfica, necesitas editar archivos directamente en la Shell.

### **Nano**
Es el editor más sencillo y apto para principiantes.
- **Abrir:** `nano archivo.txt`
- **Guardar:** `Ctrl + O`
- **Salir:** `Ctrl + X`

### **Vim**
Es extremadamente potente pero tiene una curva de aprendizaje alta debido a sus "modos".
- **Modo Comando (por defecto):** Para navegar y usar atajos.
- **Modo Inserto:** Presiona `i` para empezar a escribir.
- **Guardar y Salir:** Presiona `Esc`, escribe `:wq` y pulsa `Enter`.
- **Salir sin guardar:** Presiona `Esc`, escribe `:q!` y pulsa `Enter`.

---

## 2. Utilidades Generales y Transferencia de Archivos
Herramientas para mover datos entre máquinas o descargarlos de internet.

### **Descarga de archivos**
- `wget <URL>`: Descarga un archivo directamente a la carpeta actual.
- `curl -O <URL>`: Similar a wget, pero muy versátil para interactuar con APIs.

### **Servidor HTTP rápido (Python)**
Útil para transferir archivos desde tu máquina de ataque a la víctima:
- `python3 -m http.server 8000` (Crea un servidor web instantáneo en el puerto 8000).

## 3. Gestión de Procesos ⚙️
Un proceso es un programa en ejecución. Cada proceso tiene un **PID** (Process ID).
### Comandos de monitoreo:
- `ps`: Muestra procesos de la sesión actual.
	- `ps aux`: Muestra **todos** los procesos de todos los usuarios.
- `top`: Monitor en tiempo real (similar al Administrador de Tareas de Windows).

### Finalización de procesos:
- `kill <PID>`: Envía una señal para cerrar el proceso de forma segura.
- `kill -9 <PID>`: Fuerza el cierre inmediato (SIGKILL).

---

## 4. Automatización con Cron (Crontab)
Cron es el servicio encargado de ejecutar scripts o comandos de forma programada.

- **Editar tareas:** `crontab -e`
- **Ver tareas:** `crontab -l`

### Formato de Crontab:
Se define con 5 asteriscos: `* * * * * <comando>`
1. **Minuto** (0-59)
2. **Hora** (0-23)
3. **Día del mes** (1-31)
4. **Mes** (1-12)
5. **Día de la semana** (0-6, donde 0 es domingo)

> [!EXAMPLE] Ejemplo de Cron
> `0 * * * * /home/user/backup.sh` 
> Ejecuta el script de backup cada hora en punto (minuto 0).

## 5. Gestión de Paquetes (Software)
En distribuciones basadas en Ubuntu/Debian, se utiliza `apt`.

- `sudo apt update`: Actualiza el índice de los repositorios.
- `sudo apt install <paquete>`: Instala un nuevo programa.
- `sudo apt remove <paquete>`: Desinstala un programa.
- `add-apt-repository <url>`: Añade fuentes de software de terceros.

---

## 6. Logs del Sistema 📜
Los logs (registros) son vitales para entender qué está pasando o qué falló. Casi todos residen en `/var/log`.

- `/var/log/syslog`: Registro general del sistema.
- `/var/log/auth.log`: Intentos de inicio de sesión y uso de `sudo`.
- `/var/log/apache2/` o `/var/log/nginx/`: Logs de servidores web.

> [!TIP] Monitoreo en vivo
> Usa `tail -f /var/log/auth.log` para ver los intentos de inicio de sesión en tiempo real mientras ocurren.
