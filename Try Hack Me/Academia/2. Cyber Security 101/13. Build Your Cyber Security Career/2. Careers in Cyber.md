# Careers in Cyber

La ciberseguridad es un campo en crecimiento con alta demanda y salarios competitivos. Existen diversos roles, desde la seguridad ofensiva (pentesting) hasta la defensiva (investigación y protección).

## Task 1: Introduction

**¿Por qué una carrera en ciberseguridad?**
*   **Alta remuneración**: Los trabajos en seguridad suelen tener salarios iniciales altos.
*   **Emocionante**: El trabajo puede incluir hackear sistemas legalmente o defenderse contra ciberataques.
*   **Alta demanda**: Hay millones de puestos de ciberseguridad sin cubrir.

## Task 2: Security Analyst (Analista de Seguridad)

Son integrales para construir medidas de seguridad en las organizaciones y protegerlas de ataques. Analizan y evalúan las redes de la empresa para descubrir datos accionables y recomendaciones.

**Responsabilidades:**
*   Trabajar con varios interesados (stakeholders) para analizar la ciberseguridad en toda la empresa.
*   Compilar informes continuos sobre la seguridad de las redes, documentando problemas de seguridad y medidas tomadas.
*   Desarrollar planes de seguridad, incorporando investigación sobre nuevas herramientas y tendencias de ataque.

**Learning Paths (Rutas de aprendizaje) recomendadas:**
*   Pre Security
*   Cyber Security 101
*   SOC Level 1

## Task 3: Security Engineer (Ingeniero de Seguridad)

Desarrollan e implementan soluciones de seguridad utilizando datos de amenazas y vulnerabilidades. Trabajan para prevenir una amplia gama de ataques, incluyendo ataques a aplicaciones web y amenazas de red.

**Responsabilidades:**
*   Probar y examinar medidas de seguridad en el software.
*   Monitorear redes e informes para actualizar sistemas y mitigar vulnerabilidades.
*   Identificar e implementar los sistemas necesarios para una seguridad óptima.

**Learning Paths recomendadas:**
*   Cyber Defense
*   Jr Penetration Tester
*   Offensive Pentesting

## Task 4: Incident Responder (Respondedor de Incidentes)

Responden de manera productiva y eficiente a las brechas de seguridad. Es una posición de alta presión que requiere respuestas en tiempo real mientras los ataques se desarrollan.
Las métricas clave incluyen:
*   **MTTD**: Mean Time to Detect (Tiempo medio para detectar).
*   **MTTA**: Mean Time to Acknowledge (Tiempo medio para reconocer).
*   **MTTR**: Mean Time to Recover (Tiempo medio para recuperarse).

**Responsabilidades:**
*   Desarrollar y adoptar un plan de respuesta a incidentes completo y accionable.
*   Mantener fuertes prácticas de seguridad y apoyar las medidas de respuesta a incidentes.
*   Reportes post-incidente y preparación para futuros ataques, considerando lecciones aprendidas.

**Learning Paths recomendadas:**
*   SOC Level 1
*   Cyber Defense

## Task 5: Digital Forensics Examiner (Examinador Forense Digital)

Utilizan la informática forense para investigar incidentes y crímenes. Pueden trabajar en fuerzas de seguridad (recopilando evidencia para crímenes) o defendiendo la red de una empresa (analizando incidentes como violaciones de políticas).

**Responsabilidades:**
*   Recopilar evidencia digital observando procedimientos legales.
*   Analizar evidencia digital para encontrar respuestas relacionadas con el caso.
*   Documentar hallazgos y reportar sobre el caso.

**Learning Paths recomendadas:**
*   SOC Level 1
*   Cyber Defense

## Task 6: Malware Analyst (Analista de Malware)

Analizan programas sospechosos para descubrir qué hacen. A menudo se les llama ingenieros inversos (reverse-engineers). Requiere un fuerte fondo en programación, especialmente en lenguajes de bajo nivel como C y Ensamblador.

**Responsabilidades:**
*   Realizar análisis estático de programas maliciosos (ingeniería inversa).
*   Realizar análisis dinámico de muestras de malware observando sus actividades en un entorno controlado.
*   Documentar y reportar todos los hallazgos.

**Learning Paths recomendadas:**
*   Malware Analysis
*   SOC Level 1

## Task 7: Penetration Tester (Pentester / Hacker Ético)

Su trabajo es probar la seguridad de los sistemas y software de una empresa mediante intentos de encontrar fallos y vulnerabilidades a través de hacking sistematizado. Explotan estas vulnerabilidades para evaluar el riesgo.

**Responsabilidades:**
*   Realizar pruebas de penetración en sistemas, aplicaciones web y redes.
*   Identificar y explotar vulnerabilidades de seguridad.
*   Documentar hallazgos y proporcionar recomendaciones para remediar las vulnerabilidades.

**Learning Paths recomendadas:**
*   Jr Penetration Tester
*   Offensive Pentesting
*   Web Fundamentals

## Task 8: Red Teamer

Similar a los pentesters pero con un rol más enfocado y sigiloso. Los Red Teamers prueban las capacidades de detección y respuesta de la compañía. Imitan las acciones de cibercriminales reales, emulando ataques maliciosos, manteniendo el acceso y evitando la detección.

**Responsabilidades:**
*   Emular Tácticas, Técnicas y Procedimientos (TTPs) de adversarios reales.
*   Evaluar los controles de seguridad de las organizaciones y los procedimientos de respuesta a incidentes.
*   Evaluar y reportar insights con datos accionables para evitar instancias del mundo real.

**Learning Paths recomendadas:**
*   Red Teaming
*   Jr Penetration Tester
*   Offensive Pentesting
