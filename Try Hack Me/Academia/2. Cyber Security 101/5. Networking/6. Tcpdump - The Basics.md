## Introducción
Este apunte resume la sala "Tcpdump: The Basics" de TryHackMe, parte del módulo *Cyber Security 101*. Tcpdump es un analizador de paquetes de red por línea de comandos (CLI), extremadamente potente y ligero, que se apoya en la biblioteca `libpcap`. Es la herramienta estándar para entornos sin interfaz gráfica (como servidores Linux) y resulta indispensable para administradores de red, analistas SOC y pentesters a la hora de procesar o capturar tráfico directamente desde la terminal.

## 1. Captura Básica de Paquetes
Para empezar a capturar tráfico, es esencial conocer los parámetros u opciones (*flags*) fundamentales de la herramienta:
* `tcpdump -i <interfaz>`: Especifica la interfaz de red a escuchar (ej. `-i eth0`, `-i tun0` o `-i any` para capturar en todas).
* `tcpdump -w <archivo.pcap>`: Guarda (escribe) los paquetes capturados en un archivo `.pcap` en lugar de mostrarlos por pantalla.
* `tcpdump -r <archivo.pcap>`: Lee los paquetes desde un archivo de captura previamente guardado.
* `tcpdump -c <número>`: Captura solo una cantidad específica de paquetes y luego se detiene automáticamente.
* `tcpdump -n`: Evita que tcpdump resuelva las direcciones IP a nombres de host (acelera enormemente la salida por pantalla).
* `tcpdump -nn`: Evita la resolución tanto de IPs como de puertos a nombres de servicios (ej. muestra el puerto `80` en lugar de `http`).

## 2. Expresiones de Filtrado (Filtros Básicos)
El verdadero poder de tcpdump reside en su capacidad para filtrar el ruido y mostrar solo los paquetes que nos interesan.
* **Por Protocolo:** Simplemente escribe el nombre del protocolo de Capa 3 o 4. Ej: `tcpdump icmp`, `tcpdump tcp` o `tcpdump udp`.
* **Por Host (IP):** `tcpdump host 192.168.1.10` (Filtra todo el tráfico desde o hacia esa IP).
    * *Solo Origen:* `tcpdump src host <IP>`
    * *Solo Destino:* `tcpdump dst host <IP>`
* **Por Puerto:** `tcpdump port 80` (o `src port` / `dst port`).
* **Por Red:** `tcpdump net 10.10.0.0/16` (Captura tráfico de toda una subred).

## 3. Filtrado Avanzado
Podemos combinar múltiples filtros usando operadores lógicos como `and` (`&&`), `or` (`||`) y `not` (`!`). 
Además, tcpdump permite un filtrado muy granular inspeccionando bytes específicos dentro de las cabeceras de los paquetes.
* **Filtrar por Flags TCP:** * Paquetes **solo** con el flag SYN activado: `tcpdump "tcp[tcpflags] == tcp-syn"`
    * Paquetes con el flag Reset (RST): `tcpdump "tcp[tcpflags] == tcp-rst"`
    * Paquetes con banderas combinadas (ej. SYN o ACK): `tcpdump "tcp[tcpflags] & (tcp-syn|tcp-ack) != 0"`
* **Aislamiento de Bytes:** Expresiones más complejas como `ether[0] & 1 != 0` (analiza el primer byte de la cabecera Ethernet para detectar tráfico multicast) o `ip[0] & 0xf != 5` (analiza la cabecera IP buscando opciones no estándar).
* **Filtrar por Tamaño:** `tcpdump greater 15000` (captura únicamente los paquetes que superen los 15000 bytes de longitud).

## 4. Visualización de Paquetes
Cuando estamos analizando el tráfico en vivo o leyendo desde un `.pcap`, podemos modificar la cantidad y el formato de la información que tcpdump nos muestra por cada paquete:
* `-q` (*Quick*): Salida rápida con información mínima (útil para un vistazo rápido del flujo).
* `-e`: Imprime la cabecera de enlace de datos, lo que significa que **muestra las direcciones MAC** de origen y destino.
* `-A`: Muestra el contenido (la carga útil o *payload*) del paquete en formato de texto ASCII. Es ideal para interceptar tráfico en texto plano y buscar credenciales en protocolos como HTTP, FTP o Telnet.
* `-xx`: Muestra los datos del paquete enteramente en formato hexadecimal.
* `-X`: Muestra los datos del paquete en formato hexadecimal y ASCII uno al lado del otro, facilitando el análisis profundo.



## Conclusión
A diferencia de Wireshark, que es excelente para el análisis visual profundo e interactivo de los flujos, Tcpdump brilla en la automatización de la terminal, en servidores de producción comprometidos donde no podemos exportar la interfaz gráfica, y en el filtrado de grandes masas de datos mediante tuberías (*pipes*) hacia otras utilidades de Linux como `grep` o `awk`.
