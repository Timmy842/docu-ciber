## Introducción
Este apunte resume los conceptos clave de la sala "Networking Core Protocols" de TryHackMe (la tercera parte de la serie de redes en la ruta *Cyber Security 101*). Esta sala se enfoca en los protocolos fundamentales de la capa de aplicación (Capa 7 del modelo OSI) que hacen posible el funcionamiento de la web, la transferencia de archivos y el correo electrónico, así como sus interacciones en texto plano a través de herramientas como `telnet`.

---

## 1. DNS (Domain Name System)
El protocolo DNS actúa como la "guía telefónica" de Internet, traduciendo nombres de dominio legibles para humanos (ej. `google.com`) a direcciones IP que las máquinas pueden enrutar. Utiliza principalmente el **puerto 53 (UDP/TCP)**.

**Tipos de registros DNS más comunes:**
* **Registro A (Address):** Mapea un nombre de dominio a una dirección **IPv4**.
* **Registro AAAA (Quad-A):** Mapea un nombre de dominio a una dirección **IPv6**.
* **Registro MX (Mail Exchange):** Especifica el servidor de correo responsable de aceptar mensajes de correo electrónico en nombre del dominio.
* **Registro CNAME (Canonical Name):** Crea un alias o apodo de un dominio hacia otro dominio.

## 2. WHOIS
WHOIS (que no es un acrónimo, se pronuncia *"who is"*) es un protocolo de consulta y respuesta que se utiliza para buscar información sobre el registro de nombres de dominio y direcciones IP. 
* **Uso práctico:** Permite saber quién es el propietario de un dominio, en qué registrador se compró y las fechas clave (ej. fecha de creación, actualización y expiración).
* *Nota:* Mucha de esta información hoy en día está oculta por leyes de privacidad (como el RGPD), pero sigue mostrando datos técnicos valiosos.

## 3. HTTP y HTTPS (Acceso a la Web)
* **HTTP (HyperText Transfer Protocol):** Opera por defecto en el **puerto TCP 80** (o alternativos como 8080).
* **HTTPS (HTTP Secure):** Versión cifrada mediante TLS/SSL, opera en el **puerto TCP 443** (o alternativos como 8443).
* **Métodos/Verbos principales:**
    * `GET`: Solicita un recurso (como leer una página web, ej. `GET /index.html HTTP/1.1`).
    * `POST`: Envía datos al servidor (como rellenar un formulario).
    * `PUT`: Crea o sobrescribe un recurso específico en el servidor.
    * `DELETE`: Elimina un recurso específico.
* En la práctica (usando `telnet IP 80` o `curl`), se evidencia que detrás de la interfaz gráfica del navegador ocurren intercambios de texto plano estructurados mediante cabeceras HTTP.

## 4. FTP (File Transfer Protocol)
Protocolo estándar para la transferencia de archivos entre un cliente y un servidor. Opera en el **puerto TCP 21** (para comandos/control). 
**Comandos FTP clave:**
* `USER`: Introduce el nombre de usuario (ej. `anonymous` permite entrar sin cuenta en servidores mal configurados).
* `PASS`: Introduce la contraseña.
* `ls`: Lista los archivos en el directorio actual del servidor.
* `type ascii` / `type binary`: Cambia el modo de transferencia dependiendo si el archivo es texto plano o un binario (imagen, ejecutable).
* `RETR <archivo>`: (Retrieve) Descarga un archivo del servidor al cliente.
* `STOR <archivo>`: (Store) Sube un archivo del cliente al servidor.

## 5. Protocolos de Correo Electrónico
El envío y recepción de correos se divide en tres protocolos distintos:

### A. SMTP (Simple Mail Transfer Protocol) - *Envío*
Utilizado exclusivamente para **enviar** correos electrónicos de un cliente a un servidor o entre servidores. Utiliza el **puerto TCP 25** (o 587 para conexiones seguras).
**Comandos SMTP clave:**
* `HELO` / `EHLO`: Identifica al cliente ante el servidor.
* `MAIL FROM`: Especifica la dirección de correo del remitente.
* `RCPT TO`: Especifica la dirección de correo del destinatario.
* `DATA`: Indica que comienza el cuerpo del mensaje.
* `.` (un punto solitario en una línea): Indica el final del mensaje.
* `QUIT`: Cierra la sesión.

### B. POP3 (Post Office Protocol v3) - *Recepción (Descarga)*
Utilizado para **recibir** correos. Opera en el **puerto TCP 110**. Su característica principal es que descarga los mensajes al dispositivo local y, por defecto, **los borra del servidor**. (Ejemplo de servidor POP3 común: *Dovecot*).
**Comandos POP3 clave:**
* `USER` / `PASS`: Autenticación de credenciales.
* `LIST`: Muestra todos los correos disponibles y sus tamaños.
* `RETR <número>`: Recupera y lee el mensaje especificado.
* `DELE <número>`: Marca un mensaje para ser eliminado.
* `QUIT`: Finaliza la sesión y aplica los cambios (ej. borrados físicos).

### C. IMAP (Internet Message Access Protocol) - *Recepción (Sincronización)*
Una alternativa más moderna a POP3 para **recibir** correos, operando en el **puerto TCP 143**. A diferencia de POP3, IMAP **sincroniza** los correos; es decir, los mensajes permanecen en el servidor, permitiendo acceder a ellos desde múltiples dispositivos a la vez.
**Comandos IMAP clave:**
* `LOGIN <usuario> <contraseña>`: Autenticación.
* `SELECT <carpeta>`: Selecciona el buzón a gestionar (ej. INBOX).
* `FETCH <número> body[]`: Recupera el contenido del mensaje especificado.
* `MOVE <secuencia> <carpeta>`: Mueve correos entre carpetas.

## Resumen de Puertos (Cheatsheet)
* **21 TCP:** FTP (Transferencia de archivos)
* **23 TCP:** Telnet (Acceso remoto inseguro)
* **25 TCP:** SMTP (Envío de correo)
* **53 UDP/TCP:** DNS (Resolución de nombres)
* **80 TCP:** HTTP (Web en texto plano)
* **110 TCP:** POP3 (Recepción de correo - Descarga)
* **143 TCP:** IMAP (Recepción de correo - Sincronización)
* **443 TCP:** HTTPS (Web segura)
