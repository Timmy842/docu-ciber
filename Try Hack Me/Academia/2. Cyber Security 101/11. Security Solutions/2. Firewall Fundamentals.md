## Tarea 1: ¿Cuál es el Propósito de un Firewall?

### Concepto: El Guardia de Seguridad Digital
Un firewall actúa como un guardia de seguridad para un dispositivo o red, inspeccionando el tráfico entrante y saliente para bloquear el acceso no autorizado mientras permite la comunicación legítima.
-   **Función:** Inspecciona el tráfico basado en un conjunto de reglas.
-   **Objetivo:** Prevenir el acceso no autorizado y proteger la red de actividades maliciosas.
-   **Analogía:** Un guardia en la entrada de un edificio revisando identificaciones contra una lista de visitantes permitidos.

**Preguntas:**
- **¿Qué solución de seguridad inspecciona el tráfico entrante y saliente de un dispositivo o red?**
  - `Firewall`

## Tarea 2: Tipos de Firewalls

Los firewalls han evolucionado para manejar diferentes capas del modelo OSI y ofrecer varios niveles de seguridad.

### 1. Firewall Sin Estado (Stateless)
-   **Operación:** Capas 3 (Red) y 4 (Transporte).
-   **Función:** Filtra paquetes basándose en reglas predefinidas (IP Origen/Destino, Puerto, Protocolo) *individualmente*.
-   **Limitación:** **No** rastrea el estado de la conexión. Cada paquete se trata de forma aislada, haciéndolo menos seguro contra ataques complejos pero más rápido/eficiente.

### 2. Firewall Con Estado (Stateful)
-   **Operación:** Capas 3 y 4.
-   **Función:** Rastrea el estado de las conexiones activas (ej. "Este paquete es parte de una sesión establecida").
-   **Beneficio:** Más seguro que el sin estado porque puede permitir automáticamente el tráfico de retorno para conexiones establecidas y bloquear paquetes no solicitados y no autorizados.

### 3. Firewall Proxy (Firewall de Aplicación)
-   **Operación:** Capa 7 (Aplicación).
-   **Función:** Actúa como un intermediario entre el cliente y el servidor. Inspecciona el *contenido* del tráfico (carga útil).
-   **Beneficio:** Puede filtrar datos específicos de la aplicación (ej. bloquear URLs específicas o comandos SQL), ofreciendo una inspección más profunda.

### 4. Firewall de Próxima Generación (NGFW)
-   **Operación:** Capas 3-7.
-   **Función:** Combina características de firewall tradicionales con capacidades avanzadas como Prevención de Intrusiones (IPS), Inspección Profunda de Paquetes (DPI), Control de Aplicaciones y a menudo descifrado SSL/TLS.
-   **Característica:** Ofrece **análisis heurístico** para identificar anomalías y nuevas amenazas.

**Preguntas:**
- **¿Qué tipo de firewall mantiene el estado de las conexiones?**
  - `stateful firewall`
- **¿Qué tipo de firewall ofrece análisis heurístico para el tráfico?**
  - `next-generation firewall`
- **¿Qué tipo de firewall inspecciona el tráfico que llega a una aplicación?**
  - `proxy firewall`

## Tarea 3: Reglas en Firewalls

### Concepto: Anatomía de una Regla
Para controlar el tráfico, los firewalls usan reglas definidas por varios componentes:
1.  **Dirección de Origen:** De dónde viene el tráfico (IP/Rango).
2.  **Dirección de Destino:** A dónde va el tráfico.
3.  **Puerto:** El número de puerto (ej. 80 para HTTP, 22 para SSH).
4.  **Protocolo:** El lenguaje (TCP, UDP, ICMP).
5.  **Dirección:**
    -   **Entrante (Inbound):** Tráfico entrando *a* la red/dispositivo.
    -   **Saliente (Outbound):** Tráfico saliendo *de* la red/dispositivo.
6.  **Acción:**
    -   **Permitir (Allow):** Permitir el tráfico.
    -   **Denegar/Bloquear (Deny/Block):** Detener el tráfico (a menudo enviando un paquete de reinicio o error ICMP).
    -   **Descartar (Drop):** Descartar silenciosamente el paquete (el remitente no recibe respuesta).

**Preguntas:**
- **¿Qué tipo de acción debe definirse en una regla para permitir cualquier tráfico?**
  - `allow`
- **¿Cuál es la dirección de la regla que se crea para el tráfico que sale de nuestra red?**
  - `outbound`

## Tarea 5: Práctica con Firewall de Linux (UFW)

### Concepto: UFW (Uncomplicated Firewall)
UFW es una interfaz fácil de usar para gestionar `iptables` (la herramienta de firewall estándar de Linux).

### Comandos Comunes
-   `sudo ufw status`: Verificar estado.
-   `sudo ufw enable`: Encender el firewall.
-   `sudo ufw allow <puerto>`: Abrir un puerto (ej. `sudo ufw allow 22`).
-   `sudo ufw deny <puerto>`: Bloquear un puerto.

## Conclusión
Los firewalls son la primera línea de defensa en la seguridad de la red. Entender la diferencia entre firewalls sin estado, con estado y proxy, así como cómo configurar reglas (Origen, Destino, Puerto, Acción), es fundamental para cualquier rol de seguridad defensiva.
