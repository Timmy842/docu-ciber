## 📝 Task 1: Introducción
Aprender a usar la interfaz de línea de comandos (CLI) nativa de Windows (`cmd.exe`) es fundamental para trabajar con mayor rapidez y eficiencia en comparación con las interfaces gráficas (GUI).

**Ventajas de usar el CLI:**
- **Menor consumo de recursos:** Funciona perfectamente en hardware antiguo, sistemas limitados o entornos de nube (abaratando costes).
- **Automatización:** Facilita la creación de scripts (archivos `.bat`) para tareas repetitivas.
- **Gestión remota:** Permite gestionar servidores, enrutadores o dispositivos IoT a través de conexiones como SSH sin depender de una red rápida ni de una GUI.

## 💻 Task 2: Información Básica del Sistema
Antes de lanzar comandos, es útil saber que el sistema solo los reconoce si están en el `Path` de Windows.

* **`set`**: Muestra todas las variables de entorno, incluyendo el `Path` donde Windows busca los ejecutables.
* **`ver`**: Muestra la versión del sistema operativo (OS).
* **`systeminfo`**: Muestra información detallada del sistema (arquitectura, compilación, procesador, memoria RAM, etc.).
* **`cls`**: Limpia la pantalla de la consola (Clear Screen).
* **`help`**: Proporciona información de ayuda general.
* **Tuberías (Piping) con `| more`**: Sirve para pausar la salida de un comando largo para leerla página por página con la barra espaciadora (ej. `driverquery | more`). Se sale con `CTRL + C`.

## 🌐 Task 3: Network Troubleshooting (Resolución de problemas de red)
Comandos esenciales para diagnosticar problemas de conectividad e inspeccionar configuraciones de red.

* **`ipconfig`**: Muestra la configuración de red básica (IPv4, máscara de subred, puerta de enlace predeterminada).
* **`ipconfig /all`**: Proporciona información extendida, incluyendo la Dirección Física (MAC address), servidores DNS y el estado del DHCP.
* **`ping <dominio/IP>`**: Envía paquetes ICMP al objetivo para verificar la conectividad (si recibimos respuesta, hay conexión).
* **`tracert <dominio/IP>`**: Muestra la ruta y los saltos (routers) que recorre el paquete hasta llegar al objetivo.
* **`nslookup <dominio>`**: Resuelve un nombre de dominio (URL) y devuelve su dirección IP asociada. Se le puede indicar un servidor DNS concreto, ej: `nslookup example.com 1.1.1.1`.
* **`netstat`**: Muestra conexiones de red activas y puertos en escucha.
  * *Opciones combinadas útiles (`netstat -abon`):*
    * `-a`: Muestra todas las conexiones establecidas y los puertos en escucha.
    * `-b`: Muestra el programa/ejecutable asociado a cada conexión (requiere privilegios).
    * `-o`: Muestra el Identificador del Proceso (PID).
    * `-n`: Muestra las direcciones y los números de puertos en formato numérico (evita la resolución de nombres para mayor velocidad).

## 📁 Task 4: File and Disk Management (Gestión de Archivos y Directorios)

### Navegación de Directorios
* **`cd`**: Sin parámetros, te dice en qué directorio te encuentras.
* **`cd <ruta>`**: Cambia al directorio especificado.
* **`cd ..`**: Sube un nivel en la jerarquía de directorios (hacia el directorio padre).
* **`dir`**: Lista los archivos y subdirectorios de la ubicación actual.
  * `/a`: Muestra los archivos ocultos y del sistema.
  * `/s`: Lista los archivos del directorio actual y de todos sus subdirectorios recursivamente.
* **`tree`**: Muestra el árbol de directorios de manera muy visual.
* **`mkdir <nombre_carpeta>`**: Crea un nuevo directorio.
* **`rmdir <nombre_carpeta>`**: Elimina un directorio existente.

### Gestión de Archivos
* **`type <archivo>`**: Muestra todo el contenido de un archivo de texto por pantalla.
* **`more <archivo>`**: Muestra el contenido de archivos largos paginados de forma legible.
* **`copy <origen> <destino>`**: Copia un archivo a una nueva ubicación.
* **`move <origen> <destino>`**: Mueve un archivo a una nueva ubicación.
* **`del <archivo>`** o **`erase <archivo>`**: Elimina un archivo.
* **Comodín asterisco (`*`)**: Se usa para referirse a múltiples archivos con un patrón común. Ej: `copy *.md C:\Markdown` (copia todos los archivos con extensión `.md`).

## ⚙️ Task 5: Task and Process Management (Gestión de Tareas y Procesos)
La alternativa por línea de comandos al Administrador de Tareas gráfico.

* **`tasklist`**: Enumera todos los procesos en ejecución con su respectivo PID y uso de memoria.
  * **Filtros (`/FI`)**: Se usa para encontrar procesos específicos. 
  * *Ejemplo:* `tasklist /FI "imagename eq sshd.exe"` filtrará y mostrará solo los procesos que se llamen "sshd.exe".
* **`taskkill /PID <numero>`**: Mata o termina un proceso en ejecución basándose en su ID de proceso (PID). Ej: `taskkill /PID 1516`.

## 🔚 Task 6: Conclusión y Comandos Adicionales
Recuerda que con añadir **`/?`** después de cualquier comando podrás ver su manual de ayuda (ej. `taskkill /?`).

**Otros comandos de mantenimiento mencionados:**
* **`chkdsk`**: Revisa el sistema de archivos y los volúmenes de disco en busca de errores y sectores defectuosos.
* **`driverquery`**: Lista todos los controladores (drivers) instalados en el equipo.
* **`sfc /scannow`**: Escanea los archivos base del sistema en busca de corrupción e intenta repararlos.

**Gestión de apagado:**
* **`shutdown /s`**: Apaga el sistema.
* **`shutdown /r`**: Reinicia el sistema.
* **`shutdown /a`**: Cancela o aborta un apagado/reinicio que haya sido programado previamente.
