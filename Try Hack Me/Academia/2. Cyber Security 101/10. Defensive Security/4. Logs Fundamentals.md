# Fundamentos de Logs

**Enlace:** [Sala de TryHackMe](https://tryhackme.com/room/logsfundamentals)

## Introducción a los Logs

### Concepto: La Huella Digital
Los atacantes a menudo intentan ocultar sus huellas, pero las acciones digitales dejan rastros.
-   **Analogía:** Al igual que las huellas en la nieve o una puerta rota pueden llevar a la policía a un ladrón en una cabaña, los logs digitales proporcionan la evidencia necesaria para rastrear ataques cibernéticos.
-   **Definición:** Los logs son las huellas digitales dejadas por *cualquier* actividad (normal o maliciosa) dentro de un sistema.
-   **Rol:** Permiten a los investigadores reconstruir eventos e identificar a los individuos o procesos detrás de ellos.

---

## Casos de Uso de Logs

Los logs juegan un papel integral en varias áreas de TI y Seguridad:

| Caso de Uso | Descripción |
| :--- | :--- |
| **Monitoreo de Eventos de Seguridad** | Detección en tiempo real de comportamiento anómalo. |
| **Investigación de Incidentes y Forense** | Rastrear actividades específicas y realizar análisis de causa raíz después de un incidente. |
| **Solución de Problemas (Troubleshooting)** | Diagnosticar y arreglar errores del sistema o de aplicaciones. |
| **Monitoreo de Rendimiento** | Obtener información sobre el rendimiento de la aplicación y cuellos de botella. |
| **Auditoría y Cumplimiento** | Establecer un rastro de actividades para requisitos regulatorios. |

---

## Tipos de Logs

Para evitar perderse en un mar de datos, los logs se segregan por el tipo de información que proporcionan.

| Tipo de Log | Uso | Ejemplos |
| :--- | :--- | :--- |
| **Logs del Sistema** | Actividades del SO y solución de problemas. | Inicio/Apagado, Carga de controladores, Eventos de hardware, Errores del sistema. |
| **Logs de Seguridad** | Detectar e investigar incidentes de seguridad. | **Autenticación** (Inicios de sesión), Autorización, Cambios de política, Cambios en cuentas de usuario. |
| **Logs de Aplicación** | Eventos específicos de la aplicación. | Interacciones de usuario, Actualizaciones de App, Errores/cierres inesperados de App. |
| **Logs de Auditoría** | Cambios detallados del sistema y cumplimiento. | Acceso a datos, Cambios de estado del sistema, Cumplimiento de políticas. |
| **Logs de Red** | Tráfico entrante y saliente. | Conexiones, Logs de Firewall, Flujo de tráfico. |
| **Logs de Acceso** | Detalles de acceso a recursos. | **Acceso al Servidor Web**, Acceso a Base de Datos, Acceso a API. |

## Análisis de Logs de Eventos de Windows

Windows almacena los logs en archivos específicos accesibles a través de la herramienta GUI **Visor de Eventos (Event Viewer)**.

### Categorías Clave de Logs en Windows
1.  **Aplicación:** Errores, advertencias e información del software instalado.
2.  **Sistema:** Operaciones del SO (controladores, hardware, servicios).
3.  **Seguridad:** *Más crítico para la seguridad.* Audita la autenticación de usuarios, cambios de privilegios, etc.

### Utilidad Visor de Eventos
-   **Acceso:** Inicio > Escribir 'Visor de Eventos'.
-   **Estructura:**
    -   **Registros de Windows:** Contiene las categorías principales (Aplicación, Seguridad, Sistema, etc.).
    -   **Detalles del Log:**
        -   **Descripción:** Información detallada sobre el evento.
        -   **Nombre del registro:** Archivo fuente.
        -   **Registrado:** Marca de tiempo.
        -   **Id. del evento:** Identificador único para el tipo de actividad específica.

### IDs de Eventos de Windows Cruciales
Recordar estos IDs ayuda a filtrar actividades específicas (ej. investigar un ataque de fuerza bruta).

| ID de Evento | Descripción |
| :--- | :--- |
| **4624** | Inicio de sesión exitoso |
| **4625** | Intento de inicio de sesión fallido |
| **4634** | Cierre de sesión exitoso |
| **4720** | Cuenta de usuario creada |
| **4722** | Cuenta de usuario habilitada |
| **4724** | Intento de restablecimiento de contraseña |
| **4725** | Cuenta de usuario deshabilitada |
| **4726** | Cuenta de usuario eliminada |

### Filtrado
Usa la función **"Filtrar registro actual"** en el Visor de Eventos para buscar IDs de Eventos específicos (ej. filtrar por `4624` para ver solo inicios de sesión exitosos).

## Análisis de Logs de Acceso al Servidor Web

Los servidores web registran cada solicitud procesada. Estos logs están basados en texto y típicamente se encuentran en `/var/log/apache2/access.log` (para Apache) o rutas similares para Nginx.

### Estructura de Campo del Log
Entrada de Ejemplo:
`172.16.0.1 - - [06/Jun/2024:13:58:44] "GET /products HTTP/1.1" 404 "-" "Mozilla/5.0 ..."`

1.  **Dirección IP:** `172.16.0.1` - Quién hizo la solicitud.
2.  **Marca de tiempo:** `[06/Jun/2024:13:58:44]` - Cuándo sucedió.
3.  **Método HTTP:** `GET` - Acción realizada.
4.  **URL:** `/products` - Recurso solicitado.
5.  **Código de Estado:** `404` - Respuesta del servidor (No Encontrado).
6.  **User-Agent:** `Mozilla/5.0 ...` - Información del navegador/SO del cliente.

### Herramientas de Análisis Manual (Linux CLI)
Dado que estos son archivos de texto, las herramientas de línea de comandos de Linux son eficientes para el análisis.

#### 1. `cat` (Concatenar)
-   **Uso:** Mostrar contenidos del archivo.
-   **Ejemplo:** `cat access.log`
-   **Unir:** `cat access1.log access2.log > combined_access.log`

#### 2. `grep` (Impresión de Expresión Regular Global)
-   **Uso:** Buscar cadenas o patrones específicos (como una IP o User-Agent).
-   **Ejemplo:** `grep "192.168.1.1" access.log` (Muestra todas las actividades de esta IP).

#### 3. `less`
-   **Uso:** Ver archivos grandes página por página.
-   **Navegación:**
    -   `Barra espaciadora`: Siguiente página.
    -   `b`: Página anterior.
    -   `/palabra_clave`: Buscar hacia adelante.
    -   `n` / `N`: Siguiente / Anterior ocurrencia de la búsqueda.
-   **Ejemplo:** `less access.log`

## Conclusión
Los logs son esenciales para:
-   Reconstruir incidentes.
-   Entender el "Quién, Qué, Dónde, Cuándo" de un ataque.
-   El análisis manual requiere familiaridad con **IDs de Eventos** (Windows) y **herramientas CLI** (Linux/Logs Web).
