## Tarea 1: Introducción a la Respuesta a Incidentes

### Concepto: ¿Qué es la Respuesta a Incidentes?
La Respuesta a Incidentes (IR) es el enfoque estructurado para manejar y gestionar las consecuencias de una violación de seguridad o ciberataque.
- **Objetivo:** Manejar la situación de una manera que limite el daño y reduzca el tiempo y los costos de recuperación.
- **Analogía:** Como tener un guardia de seguridad y CCTV para tu hogar (proactivo), pero también tener un plan de qué hacer si un ladrón realmente entra (reactivo/respuesta).

## Tarea 2: ¿Qué son los Incidentes?

### Concepto: Eventos, Alertas e Incidentes
1.  **Eventos:** Cualquier ocurrencia observable en un sistema o red (ej. un usuario conectándose a un recurso compartido de archivos).
2.  **Alertas:** Una notificación activada por una solución de seguridad cuando un evento o grupo de eventos parece sospechoso.
    -   **Falso Positivo:** Una alerta que parece peligrosa pero es realmente benigna (ej. un proceso de respaldo transfiriendo grandes datos).
    -   **Verdadero Positivo:** Una alerta que identifica correctamente actividad dañina (ej. un correo de phishing).
3.  **Incidentes:** Un verdadero positivo confirmado que representa una amenaza para la organización.

**Preguntas:**
- **¿Qué se activa después de que un evento o grupo de eventos apuntan a una actividad dañina?**
  - `Alert`
- **Si una solución de seguridad identifica correctamente una actividad dañina de un conjunto de eventos, ¿qué tipo de alerta es?**
  - `True Positive`
- **Si una alarma de incendio es activada por humo después de cocinar, ¿es un verdadero positivo o un falso positivo?**
  - `False Positive`

## Tarea 3: Tipos de Incidentes

### Tipos Comunes de Incidentes
-   **Infección de Malware:** Software dañino (virus, ransomware) comprometiendo un sistema.
-   **Denegación de Servicio (DoS):** Ataques con el objetivo de interrumpir la disponibilidad de un servicio o aplicación.
-   **Acceso No Autorizado:** Ganar entrada a un sistema sin permiso.
-   **Violación de Política:** Empleados rompiendo reglas de seguridad (ej. instalando software no aprobado).

**Preguntas:**
- **El sistema de un usuario fue comprometido después de descargar un archivo adjunto de un correo electrónico. ¿Qué tipo de incidente es este?**
  - `Malware Infection`
- **¿Qué tipo de incidente tiene como objetivo interrumpir la disponibilidad de una aplicación?**
  - `Denial of Service`

## Tarea 4: Proceso de Respuesta a Incidentes

### Concepto: Marcos de IR (NIST vs. SANS)
Los marcos proporcionan un ciclo de vida estándar para manejar incidentes.

**Marco SANS (6 Pasos):**
1.  **Preparación:** Prepararse (herramientas, políticas, equipo).
2.  **Identificación:** Detectar el incidente.
3.  **Contención:** Limitar el daño (ej. desconectar una máquina de la red).
4.  **Erradicación:** Eliminar la amenaza (ej. eliminar malware).
5.  **Recuperación:** Restaurar sistemas a operación normal.
6.  **Lecciones Aprendidas:** Documentar qué sucedió y mejorar para la próxima vez.

**Marco NIST (4 Pasos):**
1.  Preparación
2.  Detección y Análisis
3.  Contención, Erradicación y Recuperación
4.  Actividad Post-Incidente (equivalente a Lecciones Aprendidas)

**Preguntas:**
- **El equipo de Seguridad deshabilita la conexión a internet de una máquina después de un incidente. ¿Qué fase del ciclo de vida de IR de SANS se sigue aquí?**
  - `Containment`
- **¿Qué fase de NIST corresponde con la fase de lecciones aprendidas del ciclo de vida de IR de SANS?**
  - `Post Incident Activity`

## Tarea 5: Técnicas de Respuesta a Incidentes

### Herramientas y Documentos
-   **SIEM (Gestión de Eventos e Información de Seguridad):** Centraliza logs y correlaciona eventos.
-   **EDR (Detección y Respuesta en Endpoints):** Monitorea y responde a amenazas en endpoints.
-   **Playbooks:** Guías/procedimientos completos para manejar tipos específicos de incidentes (ej. "Playbook de Phishing").
-   **Runbooks:** Instrucciones de ejecución detalladas, paso a paso, para tareas específicas dentro de un playbook.

**Preguntas:**
- **¿Las guías completas paso a paso para la respuesta a incidentes se conocen como?**
  - `Playbooks`
