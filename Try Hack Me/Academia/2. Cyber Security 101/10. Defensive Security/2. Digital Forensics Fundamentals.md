## Tarea 1: Introducción a la Informática Forense

### Concepto: ¿Qué es la Informática Forense?
La informática forense es la aplicación de métodos científicos para investigar crímenes. **Informática Forense Digital** es la rama específica que investiga crímenes que involucran dispositivos digitales (computadoras, teléfonos inteligentes, etc.).
- **Escenario:** Un ladrón de bancos es atrapado y se incautan dispositivos (portátil, teléfono, USB).
- **Objetivo:** Recolectar, analizar y reportar de manera segura la evidencia encontrada en estos dispositivos (ej. mapas digitales, planes, fotos, registros de chat) para procedimientos legales.

**Preguntas:**
- **¿A qué equipo le entregó el caso la policía?**
  - `digital forensics`

## Tarea 2: Metodología de Informática Forense

### Concepto: El Proceso NIST
El Instituto Nacional de Estándares y Tecnología (NIST) define un proceso estándar de 4 fases para la informática forense digital:

1.  **Recolección:** Identificar, etiquetar, registrar y adquirir datos de todas las fuentes relevantes asegurando la integridad de los datos.
2.  **Examen:** Procesar los datos recolectados. Esto implica filtrar y extraer datos relevantes (ej. encontrar archivos específicos, recuperar datos eliminados).
3.  **Análisis:** Correlacionar los datos extraídos para sacar conclusiones. Aquí es donde el investigador conecta los puntos (ej. vincular la descarga de un archivo a una acción específica del usuario en un momento específico).
4.  **Informe:** Documentar el proceso y los hallazgos. El informe debe ser claro y comprensible para audiencias no técnicas (jueces, ejecutivos).

**Preguntas:**
- **¿Qué fase de la informática forense se encarga de correlacionar los datos recolectados para sacar conclusiones de ellos?**
  - `Analysis`
- **¿Qué fase de la informática forense se encarga de extraer los datos de interés de la evidencia recolectada?**
  - `Examination`

## Tarea 3: Adquisición de Evidencia

### Concepto: Integridad y Cadena de Custodia
-   **Cadena de Custodia:** Un documento crítico que registra la historia cronológica de la evidencia. Rastrea quién la manejó, cuándo y por qué. Si esta cadena se rompe, la evidencia puede ser inadmisible en la corte.
-   **Bloqueadores de Escritura (Write Blockers):** Herramientas de hardware o software utilizadas durante la adquisición de datos. Aseguran que el disco de evidencia sea de **solo lectura**, previniendo cualquier modificación accidental (incluso cambiar la marca de tiempo de "último acceso" de un archivo) durante el proceso de copia.

**Preguntas:**
- **¿Qué herramienta se utiliza para asegurar la integridad de los datos durante la recolección?**
  - `write blocker`
- **¿Cuál es el nombre del documento que tiene todos los detalles de la evidencia digital recolectada?**
  - `chain of custody`

## Tarea 4: Informática Forense en Windows

### Concepto: Artefactos y Herramientas
Windows es un sistema operativo común en investigaciones. La informática forense implica analizar tanto el disco como la memoria.

-   **Análisis Forense de Disco:** Analizar el disco duro.
    -   **Herramientas:** `FTK Imager` (para crear imágenes de disco), `Autopsy` (para analizar imágenes).
    -   **Artefactos Clave:** Registro (info de usuario), Logs de Eventos (actividad del sistema), MFT (estructura de archivos).
-   **Análisis Forense de Memoria:** Analizar la RAM (datos volátiles). Esto captura procesos en ejecución, conexiones de red abiertas y a veces contraseñas.
    -   **Herramientas:** `DumpIt` (para capturar memoria), `Volatility` (para analizar volcados de memoria).

**Preguntas:**
- **¿Qué tipo de imagen forense se toma para recolectar los datos volátiles del sistema operativo?**
  - `Memory Image`

## Tarea 5: Ejemplo Práctico de Informática Forense

### Escenario: El Caso de Secuestro
Estamos investigando un secuestro donde el criminal envió una nota de rescate (PDF) y una foto. Necesitamos extraer metadatos para encontrar pistas.

### Pasos de Investigación
1.  **Análisis de PDF (`ransom-letter.pdf`):**
    -   **Herramienta:** `pdfinfo ransom-letter.pdf`
    -   **Hallazgo:** Los metadatos revelan el campo "Author" (Autor).
    -   **Resultado:** `Ann Gree Shepherd`
2.  **Análisis de Foto (`PHOTO.jpg`):**
    -   **Herramienta:** `exiftool PHOTO.jpg`
    -   **Hallazgo (Cámara):** La etiqueta "Camera Model Name".
    -   **Resultado:** `Canon EOS R6`
    -   **Hallazgo (Ubicación):** Las coordenadas GPS incrustadas en los datos EXIF (`51°30’51.9”N 0°05’38.7”W`).
    -   **Acción:** Ingresar estas coordenadas en Google Maps señala una calle específica en Londres.
    -   **Resultado:** `milk street`

**Preguntas y Respuestas:**
- **Usando pdfinfo, averigua el autor del archivo PDF adjunto, ransom-letter.pdf.**
  - `Ann Gree Shepherd`
- **Usando exiftool o cualquier herramienta similar, intenta encontrar dónde tomaron los secuestradores la imagen que adjuntaron a su documento. ¿Cuál es el nombre de la calle?**
  - `milk street`
- **¿Cuál es el nombre del modelo de la cámara utilizada para tomar esta foto?**
  - `Canon EOS R6`
