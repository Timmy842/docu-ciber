## 🚪 1. Port Forwarding (Reenvío de Puertos)
El Port Forwarding permite que dispositivos externos accedan a servicios dentro de una red privada.

- **El problema:** Por defecto, tu router bloquea las conexiones entrantes por seguridad. Si tienes un servidor web en tu IP privada (`192.168.1.10`), nadie desde Internet puede verlo.
- **La solución:** Configuras el **Router** para que todo el tráfico que llegue a su IP pública por un puerto específico (ej. 80) se redirija automáticamente a la IP privada del servidor.
- **Dispositivo clave:** El Router es el encargado de gestionar esta tabla de redirección.

## 🛡️ 2. Firewalls 101 (Cortafuegos)
Un Firewall es la "policía de frontera" de tu red. Decide qué paquetes entran y cuáles salen basándose en reglas.

### Capas de operación (OSI):
Los firewalls operan principalmente en las **Capas 3 (Red)** y **4 (Transporte)**, analizando IPs y Puertos.

### Categorías Principales:
1.  **Stateless (Sin estado):**
    - Analiza cada paquete de forma aislada.
    - Usa una lista estática de reglas (ACL).
    - Es rápido pero menos seguro, ya que no entiende el contexto de la conversación.
2.  **Stateful (Con estado):**
    - **Analiza la conexión completa**, no solo paquetes sueltos.
    - Sabe si un paquete entrante es una respuesta legítima a una petición que tú hiciste antes.
    - Es mucho más inteligente y difícil de engañar.

## 🔒 3. VPN Basics (Redes Privadas Virtuales)
Una VPN crea un "túnel" seguro y cifrado sobre una red pública (Internet) para conectar dos redes o un dispositivo a una red.

- **Propósito:** Proporcionar **Privacidad**, **Anonimato** y **Seguridad** al enviar datos sensibles por cables públicos.
- **Tecnologías comunes:**
    - **PPP (Point-to-Point Protocol):** Solo cifra y autentica los datos (tecnología más antigua).
    - **IPsec (IP Security):** Utiliza el framework de IP para asegurar las comunicaciones. Muy común en conexiones oficina-a-oficina.

---

## ⚙️ 4. Dispositivos de Red Avanzados
Repaso de los componentes que permiten que la LAN crezca:

| Dispositivo | Función Principal | Capa OSI |
| :--- | :--- | :--- |
| **Router** | Conecta redes distintas y realiza el **Enrutamiento** (Routing). | Capa 3 |
| **Switch** | Conecta dispositivos dentro de una misma red. | Capa 2 / Capa 3 |

- **Tipos de Switches:** Existen switches de **Capa 2** (usan MACs) y switches de **Capa 3** (pueden realizar funciones básicas de enrutamiento mediante IPs).
