# 🌐 THM: The OSI Model

> **Sala:** [The OSI Model](https://tryhackme.com/room/osimodelzi)
> **Categoría:** Pre-Security / Networking
> **Concepto Clave:** Un marco estandarizado de 7 capas para que diferentes sistemas de red se comuniquen entre sí.

---

## 🏗️ Las 7 Capas del Modelo OSI
*Regla mnemotécnica (de arriba a abajo):* **A**ll **P**eople **S**eem **T**o **N**eed **D**ata **P**rocessing.

### 7. Capa de Aplicación (Application)
Es la capa con la que interactúa el usuario directamente.
- **Función:** Proporcionar protocolos para que el software del usuario envíe y reciba datos.
- **Protocolos:** HTTP/S (web), FTP (archivos), SMTP (email), DNS.

### 6. Capa de Presentación (Presentation)
El "traductor" de la red.
- **Función:** Se encarga del formato de los datos, el cifrado (encryption) y la compresión.
- **Ejemplo:** Asegura que si envías un archivo `.png` o un texto cifrado, el receptor sepa cómo interpretarlo.

### 5. Capa de Sesión (Session)
El "administrador" de la conversación.
- **Función:** Crea, mantiene y finaliza las sesiones entre dos dispositivos. Asegura que los datos de diferentes aplicaciones no se mezclen.

### 4. Capa de Transporte (Transport)
Elige cómo se envían los datos.
- **Unidad de datos:** Segmentos.
- **Protocolos clave:**
    - **TCP:** Conexión fiable (confirma que el dato llegó).
    - **UDP:** Conexión rápida (no confirma, ideal para streaming/gaming).

### 3. Capa de Red (Network)
El "GPS" de la red.
- **Unidad de datos:** Paquetes (Packets).
- **Función:** Direccionamiento lógico y enrutamiento. Aquí es donde viven las **Direcciones IP**.
- **Hardware:** Routers.

### 2. Capa de Enlace de Datos (Data Link)
Conexión directa entre dispositivos físicos.
- **Unidad de datos:** Tramas (Frames).
- **Función:** Direccionamiento físico mediante **Direcciones MAC**. Revisa errores en la transmisión física.
- **Hardware:** Switches.

### 1. Capa Física (Physical)
Los cables y las señales.
- **Unidad de datos:** Bits (0s y 1s).
- **Función:** Envío de señales eléctricas, ópticas o de radio a través de hardware físico.
- **Hardware:** Cables (fibra, cobre), Hubs, repetidores.

---

## 📦 Encapsulación vs De-encapsulación

1. **Encapsulación (Envío):** Los datos bajan de la Capa 7 a la 1. Cada capa añade un "header" (cabecera) con información necesaria (como si metieras una carta en varios sobres).
2. **De-encapsulación (Recepción):** Los datos suben de la Capa 1 a la 7. El receptor quita los sobres uno a uno hasta leer el mensaje original.
