## 📘 Task 1: ¿Qué es el Networking?
La base de todo es la comunicación entre dispositivos.

- **Definición:** Es el intercambio de información y recursos entre dos o más computadoras conectadas.
- **Escalabilidad:** Una red puede ser desde un par de laptops con un cable hasta miles de dispositivos conectados globalmente.
- **Importancia:** Entender cómo se "hablan" las máquinas es el paso #1 para cualquier aspirante a ciberseguridad.

## 📘 Task 2: ¿Qué es el Internet?
El Internet no es "la nube", es infraestructura física.

- **Red de redes:** Es una colección masiva de redes privadas y públicas conectadas entre sí.
- **Hitos clave:**
    - **ARPANET:** El abuelo del internet (fines de los 60).
    - **Protocolos:** Reglas que permiten que dispositivos de distintas marcas se entiendan.
- **Internet vs WWW:** El Internet es el hardware/infraestructura; la **World Wide Web** es solo un servicio que corre sobre él (páginas web).

## 📘 Task 3: Identificando Dispositivos (IP y MAC)
Para que un paquete de datos llegue a su destino, necesita "direcciones".

### 1. Dirección IP (Internet Protocol)
- **Lógica:** Es como tu dirección postal, pero puede cambiar si te mudas de red.
- **Pública:** Te identifica ante el mundo (la asigna tu proveedor de internet).
- **Privada:** Te identifica dentro de tu casa/oficina (la asigna tu router).
- **Formatos:** IPv4 (ej. `192.168.1.1`) e IPv6 (más larga, para cuando se acaben las IPv4).

### 2. Dirección MAC (Media Access Control)
- **Física:** Viene grabada de fábrica en tu tarjeta de red. No cambia.
- **Formato:** Hexadecimal (ej. `00:1A:2B:3C:4D:5E`). Los primeros 3 pares identifican al fabricante.

## 📘 Task 4: Ping (ICMP)
La herramienta de diagnóstico más básica y poderosa.

- **¿Qué hace?:** Envía un paquete "eco" a una dirección y espera a que regrese para ver si el dispositivo está encendido y cuánto tarda en responder.
- **Protocolo:** Usa **ICMP** (Internet Control Message Protocol).
- **Sintaxis:** `ping <ip_o_dominio>`
- **Métricas clave:**
    - **Latencia:** El tiempo que tarda el viaje (ida y vuelta).
    - **Pérdida de paquetes:** Si no regresan, hay un fallo en la red o un Firewall bloqueando el paso.

## 📘 Task 5: Conclusión y Siguientes Pasos
Networking es un campo profundo. Esta sala es el punto de partida para entender conceptos más avanzados como el **Modelo OSI**, **DNS** o **Puertos**.
