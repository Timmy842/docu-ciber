## 📘 Task 1: Topologías de Red (LAN Topologies)
Se explican las formas físicas y lógicas en que conectamos dispositivos.

- **LAN (Local Area Network):** Red de área local (casa, oficina).
- **Topologías principales:**
    - **Star (Estrella):** Todos se conectan a un switch central. Es la más común y escalable, pero si falla el switch, cae toda la red.
    - **Bus:** Todos usan un solo cable central ("backbone"). Si el cable se rompe, se acaba la red. Muy barata pero ineficiente.
    - **Ring (Anillo):** Los dispositivos forman un círculo. Los datos viajan en una dirección. Si un nodo falla, el anillo se rompe.
- **Hardware Clave:**
    - **Switch:** Conecta dispositivos en la misma red y envía los datos solo a quien los necesita (**Packet Switching**).
    - **Router:** Conecta redes diferentes y elige la mejor ruta para los datos (**Routing**).

## 📘 Task 2: Introducción al Subnetting
Dividir una red grande en trozos más pequeños (subredes).

- **¿Por qué hacerlo?:** Mejora la seguridad (separar departamentos) y la eficiencia del tráfico.
- **Máscara de subred:** Un número de 32 bits (ej. `255.255.255.0`) que le dice a la computadora qué parte de la IP es la "red" y qué parte es el "dispositivo".
- **Conceptos clave:**
    - **Network Address:** La primera dirección (identifica la red).
    - **Host Address:** Direcciones asignadas a dispositivos.
    - **Default Gateway:** La IP del router que nos permite salir a otras redes.

## 📘 Task 3: El Protocolo ARP
El puente entre la dirección lógica (IP) y la física (MAC).

- **ARP (Address Resolution Protocol):** Sirve para saber "¿Qué dirección MAC tiene esta dirección IP?".
- **Proceso:**
    1. **ARP Request:** Se envía un "grito" (broadcast) a toda la red preguntando por una IP.
    2. **ARP Reply:** El dueño de esa IP responde con su dirección MAC.
- **ARP Cache:** Una tabla donde el sistema guarda estas parejas (IP -> MAC) para no tener que preguntar cada vez.

## 📘 Task 4: El Protocolo DHCP
La forma en que tu dispositivo obtiene internet automáticamente al conectarse.

- **DHCP (Dynamic Host Configuration Protocol):** Asigna IPs dinámicas para que no tengas que configurarlas a mano.
- **El proceso DORA:**
    1. **Discover:** El cliente busca un servidor DHCP.
    2. **Offer:** El servidor ofrece una IP.
    3. **Request:** El cliente acepta la IP.
    4. **Acknowledgement (ACK):** El servidor confirma la asignación.
